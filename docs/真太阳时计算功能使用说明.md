# 真太阳时计算功能使用说明

## 📖 功能概述

**真太阳时**是根据太阳实际位置计算的时间，考虑了经度差异和地球轨道椭圆引起的均时差。在时柱计算中，必须使用真太阳时而非标准时间，才能准确对应当地实际的太阳位置。

### 为什么需要真太阳时？

1. **经度差异**：地球自转 360 度需要 24 小时，每度经度相差 4 分钟
   - 北京（东经 116.4°）：比东经 120°晚约 14 分钟
   - 成都（东经 104°）：比东经 120°晚约 64 分钟
   - 乌鲁木齐（东经 87.6°）：比东经 120°晚约 130 分钟

2. **均时差**：地球轨道是椭圆形，引起太阳视运动速度变化
   - 最大时差：+16 分钟（11 月初）
   - 最小时差：-14 分钟（2 月中旬）

3. **时辰准确性**：在时辰边界附近（如 9:00、11:00 等），几分钟的差异就可能导致时柱错误

## 🎯 核心功能

### 1. 精确均时差计算

使用天文算法精确计算每日的均时差：

```python
from src.engine.precise_calendar import PreciseCalendar
from datetime import date

calendar = PreciseCalendar()

# 计算 2026 年 9 月 4 日的均时差
test_date = date(2026, 9, 4)
eot = calendar._calculate_equation_of_time_precise(test_date)

print(f"2026 年 9 月 4 日均时差：{eot * 60:.2f}分钟")
# 输出：-1.14 分钟（真太阳时慢 1.14 分钟）
```

### 2. 真太阳时计算

根据经度和日期计算真太阳时：

```python
# 计算北京 2026 年 9 月 4 日 10:00 的真太阳时
beijing_longitude = 116.4074
true_solar = calendar._calculate_true_solar_time(
    10, 0, beijing_longitude, test_date
)

print(f"北京时间 10:00 的真太阳时：{true_solar:.2f}小时")
print(f"即：{int(true_solar)}:{int((true_solar % 1) * 60):02d}")
# 输出：9.74 小时，即 9:44
```

### 3. 时柱计算（使用真太阳时）

时柱地支严格对应真太阳时：

```python
# 计算时柱（日柱为辛巳）
day_ganzhi = '辛巳'
hour_ganzhi = calendar.get_hour_ganzhi(
    day_ganzhi, 
    hour=10,      # 北京时间 10 点
    minute=0, 
    longitude=116.4074,  # 北京经度
    date_obj=test_date
)

print(f"时柱：{hour_ganzhi}")
# 输出：癸巳（真太阳时 9:44，对应巳时）
```

### 4. 城市名称自动获取经纬度

内置 60+ 中国主要城市的经纬度：

```python
# 使用城市名称计算四柱
sizhu = calendar.get_sizhu_precise(
    2026, 9, 4, 10, 0, 
    city_name='成都'  # 自动使用成都的经纬度
)

print(f"成都 10:00 的四柱：{sizhu['年柱']} {sizhu['月柱']} {sizhu['日柱']} {sizhu['时柱']}")
# 输出：丙午 己酉 辛巳 壬辰（真太阳时 8:55，对应辰时）
```

## ⚠️ 重要注意事项

### 1. 必须使用真太阳时的情况

- **西部地区**：成都、重庆、昆明、西安、兰州、乌鲁木齐、拉萨等
- **时辰边界**：出生在 9:00、11:00、13:00 等时辰边界附近
- **精确择日**：风水择日、六壬排盘等专业应用

### 2. 影响较小的情况

- **东部地区**：上海、南京、杭州、福州等（接近东经 120°）
- **时辰中间**：出生在时辰中间时段（如 10:00-10:30）

### 3. 常见错误

❌ **错误 1**：直接使用北京时间计算时柱
```python
# 错误：成都 10:00 直接用北京时间
hour_ganzhi = '癸巳'  # 错误！
```

✅ **正确做法**：使用真太阳时
```python
# 正确：成都 10:00 使用真太阳时计算
sizhu = get_sizhu_accurate(2026, 9, 4, 10, 0, city_name='成都')
# 结果：壬辰时（真太阳时 8:55，辰时）
```

❌ **错误 2**：忽略均时差
```python
# 不精确：只考虑经度差
true_solar = beijing_time + (longitude - 120) * 4 / 60
```

✅ **正确做法**：同时考虑经度和均时差
```python
# 精确：使用完整算法
true_solar = calendar._calculate_true_solar_time(
    hour, minute, longitude, date_obj
)
```

## 🔧 技术细节

### 1. 真太阳时计算公式

```
真太阳时 = 平太阳时 + 经度时差 + 均时差

其中：
- 平太阳时：当地标准时间（北京时间）
- 经度时差：(当地经度 - 120°) × 4 分钟/度
- 均时差：地球轨道椭圆引起的时差（-14 到 +16 分钟）
```

| 卯时 | 卯 | 05:00-07:00 |
| 辰时 | 辰 | 07:00-09:00 |
| 巳时 | 巳 | 09:00-11:00 |
| 午时 | 午 | 11:00-13:00 |
| 未时 | 未 | 13:00-15:00 |
