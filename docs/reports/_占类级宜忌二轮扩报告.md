## 六、🔴🔴 顺手修复真 bug：`_build_zhanlei_tone` 三传天将**一个都收不到**

### 现象（生产探针 [D]）
「子时 · 官讼」只命中 **螣蛇**，**天后漏了** —— 天后明明在四课上神里。

### 根因
`result['sanchuan']` 实际是 **dict**，**不是 list**：

```python
{'三传': ['酉','亥','丑'], '三传天将': ..., '三传六亲': ...,
 '初传': ..., '中传': ..., '末传': ...,
 '课体': ..., '毕法赋命中': ..., '课格列表': [...]}
```

旧代码（S1 落地时引入）：

```python
for _c in (result.get('sanchuan') or []):   # ← 直接迭代 dict ⇒ 只拿到「键名」
    _j = _tjm.get(_c)                       # ← tianjiang_map.get('初传') 恒 None
```

⇒ **`tianjiang_map.get('初传')` 恒为 `None`** ⇒ **三传天将一个都收不到**。

### 修复

```python
_sc_raw = result.get('sanchuan')
_cs = []
if isinstance(_sc_raw, dict):
    _cs = list(_sc_raw.get('三传') or [])           # 与四课部分同口径
    if not _cs:                                     # 兜底：只给 初/中/末传 三键
        _cs = [_sc_raw.get(k) for k in ('初传', '中传', '末传')]
        _cs = [x for x in _cs if x]
elif isinstance(_sc_raw, (list, tuple)):
    _cs = list(_sc_raw)                             # 兼容
```

### 修复后实证
**「子时 · 官讼 → 螣蛇 : 忌用 ｜ 天后 : 宜用」** —— **同一占类两极**（bug 修复前不可能出现）。
