## 🎯 核心功能实现

### 1. 龙德课判断系统

**判断规则**:
```python
龙德课 = (太岁发用 OR 月将发用) AND 乘贵人

其中：
- 太岁发用：初传 = 年支（太岁）
- 月将发用：初传 = 月将
- 乘贵人：初传是日干贵人
```

**课体类型**:
- 太岁龙德课（权贵之象）- 力量最强
- 月将龙德课（光明之象）- 力量次强

**贵人查法**:
```
甲戊庚牛羊（丑未）
乙己鼠猴乡（子申）
丙丁猪鸡位（亥酉）
壬癸兔蛇藏（巳卯）
六辛逢马虎（午寅）
```

### 2. 到山到向分析系统

**二十四山禄马贵表**（完整实现）:

| 坐山 | 禄位 | 马位 | 贵人 |
|------|------|------|------|
| 壬山 | 亥 | 巳 | 巳卯 |
| 丙山 | 巳 | 亥 | 亥酉 |
| ... | ... | ... | ... |

**到山到向判断**:
```python
检查项目：
- 年禄、年马、年贵人
- 日禄、日马、日贵人
- 时禄、时马、时贵人

判断标准：
- 禄/马/贵到山 = 吉
- 禄/马/贵到向 = 吉
```

**课格等级评估**:
```python
6 个以上：上上大吉 ⭐⭐⭐
5 个：上吉 ⭐⭐
4 个：中吉 ⭐
3 个：小吉
少于 3 个：平
```

### 3. 智能筛选算法

**筛选流程**:
```
1. 遍历日期范围内的所有日期
   ↓
2. 对每个日期的 12 个时辰起六壬课
   ↓
3. 判断是否为龙德课
   ↓
4. 计算禄马贵到山到向数量
   ↓
5. 筛选达到最少数量要求的日期
   ↓
6. 按到山到向数量排序
   ↓
7. 生成课格结构和推荐指数
```

**性能指标**:
- 单日起课：~10ms
- 扫描 1 年（365 天）：1-2 分钟
- 扫描 10 年：10-20 分钟

5. 查看结果，点击任意日期查看详情
6. 导出结果（可选）

### 方法二：编程调用

```python
from datetime import datetime
from src.engine.long_de_ke_selector import LongDeKeSelector

# 创建选择器
selector = LongDeKeSelector()

# 执行择日
results = selector.select_long_de_dates(
    mountain='壬',
    direction='丙',
    start_date=datetime(2026, 3, 15),
    end_date=datetime(2027, 3, 14),
    min_arrival_count=3
)

# 查看结果
print(f"找到 {len(results)} 个日期")
for r in results[:5]:
    print(f"{r['date']} {r['shi']}时 - {r['long_de_type']}")

# 生成课格结构
kege = selector.generate_kege_structure(results[0])
print(kege)

# 保存结果
selector.save_results(results, '龙德课结果.json')
```

## ⚠️ 使用注意

### 1. 结合其他择日法

龙德课到山到向虽吉，但建议：
- 结合斗首择日法
- 避开三煞、五黄
- 考虑用事人年命
- 咨询专业风水师

### 2. 性能考虑

- 扫描范围越大，耗时越长
- 建议先小范围测试
- 批量处理时注意时间

### 3. 结果解读

- 到山到向数量不是唯一标准
- 需综合考虑课体组合
- 避开凶课（天狱、绝嗣等）
