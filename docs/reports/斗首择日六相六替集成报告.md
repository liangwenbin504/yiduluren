### 核心理论

#### 1. 三元理论
- **天元**：天干化气（明用）
- **地元**：四柱地支（暗用）
- **人元**：山家五行（根本）

#### 2. 六相（五星）
- 元辰（同我者）- 吉
- 武财（我克者）- 吉
- 贪狼（生我者）- 凶
- 廉贞（我生者）- 吉凶参半
- 破军（克我者）- 凶

#### 3. 六替（番化五行）
核心秘诀：
```
元元武化贪，官鬼子孙财

详解：
- 元辰化元辰（不变）
- 武财化贪狼
- 贪狼化破军
- 破军化廉贞
- 廉贞化武财
```

## 八、理论依据

### 番化诀详解

**原文**：
```
元元武化贪，官鬼子孙财

元辰番化是元辰、武化贪官须认清、
贪化破军真秘决、破军化出是廉贞、
廉子化武休重见、武化贪官受有情。
```

**解释**：
- 元辰的番化仍然是元辰（比和之气，专一不变）
- 武财番化为贪狼（财生官，官为贵气）
- 贪狼番化为破军（官生杀，杀为权柄）
- 破军番化为廉贞（杀生印，印为福寿）
- 廉贞番化为武财（印生财，循环不息）

### 三元应用

**原文**：
```
斗首论三元，以四天干在上曰天元，
四地支在下曰地元，遁五子遁遁元到山者名人元。

一般斗首择日家都是以天元为明用，地元为暗用。
```

**应用**：
- 天元（天干化气）：用于判断六相、格局
- 地元（地支）：用于判断生旺墓绝
- 人元（山家）：用于确定五行属性

### 课格要点

**原文**：
```
斗首择日说明，必需以年、月、日、时、配合山方，
柱中要重见三重元辰、称之（上述三元格）即为元辰会一家也，
或见三重武财（三武格）也即武财会一家。

还要山方得时令旺相，化气逢长生冠带临官帝旺墓库胎养之支，谓之得位。
```
