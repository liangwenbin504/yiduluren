# 月将计算修正说明

## 问题描述

在六壬排盘系统中，月将计算功能存在错误，当前实现错误地从月建进行计算，不符合《六壬大全》的规范要求。

## 修正内容

### 1. 修正依据

根据《六壬大全》卷三规范：
- **月将者，日所舍之辰也**
- **太阳过宫，以中气为界**
- 严格以中气时刻作为换将标准，非农历初一
- 中气时刻后换将，非交节当日

### 2. 中气换将规则

### 3. 核心算法改进

#### 修正前（错误）
```python
# 使用近似日期计算
zhong_qi_dates = {
    2: ('雨水', 19),   # 2 月 19 日左右雨水
    3: ('春分', 21),   # 3 月 21 日左右春分
}
```

#### 修正后（正确）
```python
# 使用精确天文算法计算节气时刻
self.calendar = PreciseCalendar()
jieqi_dates = self.calendar.get_jieqi_dates(year)

# 按时间顺序遍历中气，找到最后一个已经过去的气
for zhong_qi in self.ZHONG_QI_ORDER:
    if zhong_qi in jieqi_dates:
        qi_datetime = jieqi_dates[zhong_qi]
        if query_datetime >= qi_datetime:
            current_zhong_qi = zhong_qi
        else:
            break  # 找到第一个未来的气，停止
```
