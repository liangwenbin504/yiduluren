## 二、落码

### 1️⃣ 数据层 `engine/liuren_keti_bifa.py`
```python
ZHI_NUMBER = {'子': 9, '午': 9, '丑': 8, '未': 8, '寅': 7, '申': 7,
              '卯': 6, '酉': 6, '辰': 5, '戌': 5, '巳': 4, '亥': 4}
```

### 2️⃣ 叙事函数 `get_yingqi_text(ri_gan, ri_zhi, sanchuan_dizhi)`
- 三传取支数，取众数/初传之数断应期（年/月）
- 返回叙事文本「邵彦和应期法：X数N、Y数M → 约N年/月」；空三传返回 ''
- **不参与 valence**（记录层，调用方不注入 score）

### 3️⃣ 起课页接线 `zongmen/http_api_server.py` + `demo.html`
- GET/POST handler 各加 `应期` 字段（三传入参）
- demo.html 基本信息卡加「应期参考」显示行

## 四、定位说明（为什么不进 valence）
- 应期=「何时发生」，吉凶方向不因此改变 → 若入评分会污染方向判定
- 邵彦和应期是**附加信息**：课断凶 + 应期几年/月
- 正确用法：叙事层/教学层（起课页显示应期参考），供占断场景使用
