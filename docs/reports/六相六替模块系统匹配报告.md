### 3️⃣ 核心诀法模块 (HuaQiJueFa)

**匹配要点**：
- ✅ 化气六相诀
- ✅ 化气六替诀

**实现内容**：

#### 3.1 化气六相诀

```
生旺人财盛，冠带福禄昌。
临官功名显，胎养有喜孕。
六相外又取，墓库富丰盈。
廉贞年一位，生旺子孙昌。
三元三武吉，富贵永安康。
元辰和五气，三才仔细详。
```

**诀法解释**：
- `生旺人财盛` - 长生、帝旺主人丁和财富旺盛
- `冠带福禄昌` - 冠带可增加福禄
- `临官功名显` - 临官有利当官和名声
- `胎养有喜孕` - 胎和养有利婚姻和怀孕
- `六相外又取，墓库富丰盈` - 六相之外还可取墓库为用，墓库主财丰盈
- `廉贞年一位，生旺子孙昌` - 破鬼之年只得一位廉贞，生旺子孙
- `三元三武吉，富贵永安康` - 三元三武的局格最吉，主富贵永安康
- `元辰和五气，三才仔细详` - 要仔细参详日课的元辰、五气和表三元

#### 3.2 化气六替诀

```
沐浴风声露，衰病死祸侵。
贪破年月上，灾祥各半分。
元廉居墓绝，人才不得兴。
贪官墓绝上，庶吉仕凶评。
```

**诀法解释**：
- `沐浴风声露` - 沐浴主风流、名声不好
- `衰病死祸侵` - 衰、病、死主有祸害
- `贪破年月上，灾祥各半分` - 贪狼破军在年月，吉凶各半
- `元廉居墓绝，人才不得兴` - 元辰、廉子居在墓绝上，人丁和财富都不得兴旺
- `贪官墓绝上，庶吉仕凶评` - 贪官居在墓绝上，是吉无凶来评断

#### 3.3 斗首五行六相六替诀

```
三吉喜居六相支，二凶喜居六替支。
尤喜三吉在替支，二凶六替即三吉。
总求三元旺相主，四柱必透一元辰。
若不及透地支多，元辰六相妙谛真。
```

**核心方法**：
- `get_liuxiang_jue()` - 获取化气六相诀
- `get_liuti_jue()` - 获取化气六替诀
- `get_douhou_jue()` - 获取斗首五行六相六替诀
- `explain_juefa(juefa_name)` - 解释诀法
- `analyze_state_meaning(state)` - 分析状态含义

### 4️⃣ 应用策略模块 (RemedyStrategy)

**匹配要点**：
- ✅ 补救之法模块

**实现内容**：

#### 4.1 补救方法（按优先级排序）

**方法 1：以元补元（优先级 1）**
- **描述**：用元辰的时柱来补助，用元辰的年月柱来扶助
- **应用**：元辰衰弱时的首选补救方法
- **示例**：午山子向用癸亥日（火绝在亥），用癸丑、戊午二时补助元辰，再用戊寅、戊辰等年月扶助

**方法 2：以武补元（优先级 2）**
- **描述**：用武财之支来补助元辰
- **应用**：不能以元补元时的次选方法
- **示例**：用庚辰、庚午等武财之支来补助元辰

**方法 3：以廉补元（优先级 3）**
- **描述**：用廉子之支来补助元辰
- **应用**：不能以武补元时的再次方法
- **示例**：用甲辰、甲午等廉子之支来补助元辰

**方法 4：以贪破补元（优先级 4）**
- **描述**：用贪官或破鬼的临官、帝旺支来补助
- **应用**：最不得已的方法，需贪狼破鬼无气且到山到向发传
- **示例**：用丁巳、壬午等贪官病死之支（但为元辰临帝旺）补元

#### 4.2 补救原则

1. 凶宜在外（年月），吉宜在内（日时）
2. 贪狼和破鬼在外需居六替地支
3. 若居六相地支便生祸
4. 四柱必透一元辰
5. 若不及透，地支一定要多元辰六相之支

**核心方法**：
- `get_remedy_methods()` - 获取所有补救方法（按优先级排序）
- `get_best_remedy()` - 获取最佳补救方法
- `get_remedy_by_priority(priority)` - 根据优先级获取补救方法
- `analyze_remedy_case(shan, day_ganzhi, problem)` - 分析补救案例
- `print_remedy_guide()` - 打印补救指南

**数据结构**：
```python
RemedyPlan:
  - method: str           # 方法名称
  - priority: int         # 优先级（1 最高）
  - description: str      # 描述
  - application: str      # 应用场景
  - example: str          # 示例
```

- **到山到向**：用六壬盘将禄马贵吊到本山或本向
