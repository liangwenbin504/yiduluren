### ✅ 2. 创建 64 课课经规则库

**文件**: [`src/engine/daliuren_64ke_rules.py`](file:///d:/新建文件夹/仪度六壬择日/yiduluren/src/engine/daliuren_64ke_rules.py)

  - duanyu: 吉凶断语
  - te_zheng: 课体特征列表

### 基础使用

