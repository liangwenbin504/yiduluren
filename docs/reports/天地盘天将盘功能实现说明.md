## 一、天将盘排法原理

### 1.1 十二天将顺序
```
贵人 → 螣蛇 → 朱雀 → 六合 → 勾陈 → 青龙 → 天空 → 白虎 → 太常 → 玄武 → 太阴 → 天后
```

### 1.2 贵人起例口诀
```
甲戊庚牛羊（丑未）
乙己鼠猴乡（子申）
丙丁猪鸡位（亥酉）
壬癸蛇兔藏（巳卯）
六辛逢马虎（午寅）
```

### 1.3 排盘步骤

**第一步：起贵人**
- 根据日干确定贵人地支
- 甲日：丑（阳贵）、未（阴贵）
- 乙日：子（阳贵）、申（阴贵）
- 丙丁日：亥（阳贵）、酉（阴贵）
- 壬癸日：巳（阳贵）、卯（阴贵）
- 辛日：午（阳贵）、寅（阴贵）

**第二步：分昼夜**
```
昼时（阳贵）：卯、辰、巳、午、未、申
夜时（阴贵）：酉、戌、亥、子、丑、寅

口诀：卯至申为昼，酉至寅为夜
```

**第三步：贵人加临**
- 贵人加在**天盘地支**上（不是地盘）
- 查找天盘贵人地支落地盘的哪个位置

**第四步：判断顺逆**
```
阳位：亥、子、丑、寅、卯、辰
阴位：巳、午、未、申、酉、戌

规则：
- 天盘贵人落地盘阳位 → 顺行
- 天盘贵人落地盘阴位 → 逆行
```

**第五步：布十二天将**
- 从贵人地支开始布起
- 天将布在**天盘地支**上
- 顺行：按顺序顺时针排列
- 逆行：按顺序逆时针排列

#### 2.3.2 新增绘制天将盘方法

**方法名**：`_draw_tianjiang_layout(self, gui_ren_pan, tiandi_pan)`

**代码位置**：第 1466-1555 行

**核心功能**：
1. 绘制圆形地盘框架
2. 绘制方位标签（东左西右，北下南上）
3. 绘制地盘地支（内圈，蓝色）
4. 绘制天盘地支（中圈，橙色）
5. 绘制十二天将（外圈，绿色）
6. 显示贵人、顺逆信息

**坐标系统**：天文学视角（东左西右，北下南上）

```python
def _draw_tianjiang_layout(self, gui_ren_pan, tiandi_pan):
    """绘制天将盘方位图（天文学视角：东左西右）"""
    canvas = self.tianjiang_canvas
    canvas.delete("all")
    
    # 十二地支位置（天文学视角）
    dizhi_positions = {
        '子': (center_x, center_y + radius),      # 正北 (下方)
        '卯': (center_x - radius, center_y),      # 正东 (左方)
        '酉': (center_x + radius, center_y),      # 正西 (右方)
        '午': (center_x, center_y - radius),      # 正南 (上方)
        # ... 其他地支
    }
    
    # 获取天将映射
    tian_jiang_map = gui_ren_pan.get('天将映射', {})
    
    # 绘制三层信息
    for dizhi, (x, y) in dizhi_positions.items():
        # 内圈：地盘地支（蓝色）
        canvas.create_text(x, y, text=dizhi, font=font_dizhi, fill='#0066cc')
        
        # 中圈：天盘地支（橙色）
        tian = tiandi_pan.get(dizhi, '')
        if tian:
            offset_x = (x - center_x) * 0.3
            offset_y = (y - center_y) * 0.3
            canvas.create_text(x + offset_x, y + offset_y, text=tian, 
                             font=('Microsoft YaHei UI', 10), fill='#cc6600')
        
        # 外圈：天将（绿色）
        tianjiang = tian_jiang_map.get(tian, '')
        if tianjiang:
            offset_outer_x = (x - center_x) * 0.6
            offset_outer_y = (y - center_y) * 0.6
            canvas.create_text(x + offset_outer_x, y + offset_outer_y, 
                             text=tianjiang, font=font_tianjiang, fill='#009900')
```
