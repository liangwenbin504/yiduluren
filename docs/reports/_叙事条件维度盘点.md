## 一、结论先行：原文自己列了**四条**调节因子，我们只做了**一条**

**《通解》上卷 L2637**（十二将总论）：

> 「若**旺相相生比和**则吉；**休囚**则转灾；**空亡减半**；**披刑带杀**，灾病立至。」

| 原文因子 | 现状 |
|---|---|
| **旺相 / 休囚** | ✅ **已做**（`TIANJIANG_WANGSHUAI` 49＋4 条 ＋ 应人「有气/无气」） |
| **相生比和**（将／神五行关系） | ❌ **未做** |
| **空亡减半** | ❌ **未做**（现只有 `void_audit` **硬门**，非「减半」乘数） |
| **披刑带杀** | ❌ **未做** |

⇒ **憨爷此问的答案：除旺衰外，原文总纲里还剩 3 条，且都是全局通用条件。**

## 二、条件维度的类型学（便于定落地形态）

| 类型 | 语义 | 典型原文 |
|---|---|---|
| **乘数型** | 调节强弱（不换方向） | 「**空亡减半**」（L2637） |
| **加成型** | 追加一档凶 | 「**披刑带杀，灾病立至**」（L2637） |
| **翻转型** | 把吉翻成凶 | 「若**中末空亡**或**阴神制之**，或**末得日墓**，则**半空折翅**」（指南 L226 青龙） |
| **关系型** | 新维度：将 × 日干 / × 年命 | 「**天后克日干**，女贪男…**日干克天后**，男贪女」（通解上 L1952） |
| **状态型** | 前提条件（顺逆 / 昼夜） | 「**贵人顺逆，为吉凶之分**」（通解上 L2576） |

## 四、建议优先级（我的判断）

```
第一梯队（全局总纲 · 数据现成 · 一次做透）
 ① 空亡调节（乘数）    ← 原文「空亡减半」是总纲级，且现在只有硬门，落差最大
 ② 相生比和／刑克      ← 同为总纲级，五行表已现成
 ③ 披刑带杀（加成）    ← 与 ② 同源于 L2637，一起做最省

第二梯队（具体到将 · 需一条新计算）
 ④ 将 × 日干生克      ← 「关系型」新维度，白虎/天后/贵人三处原文
 ⑤ 翻转三条件（L226）  ← 阴神制 / 末得日墓 / 中末空亡，数据全现成

第三梯队（先数样本再定）
 ⑦ 贵人顺逆 ⑨ 德神天喜 ⑩ 三六合进列
```

**⛔ 明确不建议**：
- **「昼方/夜方」不要当新维度做** —— 它内蕴于宫位阴阳，做了就是**重复建维度**（撞「同一信息禁两处呈现」）。
- 任何**原文只一处、样本 <3 例**的条件，先积累语料、别急着结构化（守「不可推广」红线）。
