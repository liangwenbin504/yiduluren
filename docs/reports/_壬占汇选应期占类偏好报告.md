## 三、数字分布规律
- **年断 58% 是地支数**（8年27/4年21/6年20/9年18/16年13）——洛书地支数在年断里显著（4/6/8/16 均为地支数或其倍数）
- **日断 7日13 一枝独秀**（寅申数七）；失物日断 8日5（丑未数八）
- **月断均匀**（5月40/6月51/10月50 略高）——月断不走地支数，走**月建应期**（"未为六月建故讼起六月"、"巳为皇诏四月"）
- **月建应期**（"X为N月建"→断N月）：六月3/十月4/九月2/十二月2

## 四、落码（叙事层增强，不评分的合法用法）

```python
_unit_pref = {'家宅':'年','功名':'年','求财':'年','婚姻':'年',
              '疾病':'月','行人':'月','官讼':'月','失物':'日','天时':'日'}
```
输出尾部追加「（X占宜Y断）」提示——与现有运算候选（单支/相加/相乘）并存，不改变任何评分路径。
- 家宅(巳寅亥) → ★相加11=7+4 **（家宅占宜年断）**

- 失物(卯申丑) → 相加21/相乘56 **（失物占宜日断）**
- **A/B：M3=87.4% 混淆逐项不变，零回归** ✓
