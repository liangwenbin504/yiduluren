# 应期三法统一输出实施报告（2026-08-02）

## 一、目标
应期断法三支柱（支数法/月建法/太岁法）各自独立输出，整合为统一「应期总览」。

## 二、实现：`get_yingqi_unified`
- 位置：`engine/liuren_keti_bifa.py`
- 签名：`get_yingqi_unified(ri_gan, ri_zhi, sanchuan_dizhi, tiandi_pan, si_ke, shichen, tai_sui_zhi, zhanlei)`
- 逻辑：依次调用三法，非空则换行分块输出：
  ```
  ① 支数法（get_yingqi_text）：洛书数多候选 + 占类权重 + 单位偏好
  ② 月建法（get_yuejian_yingqi_text）：月建支在初传/干上/时上 → 应于该月
  ③ 太岁法（get_tai_sui_lin_shen_text）：太岁临身 → 当年应（需 tai_sui_zhi）
  ```
- **物数法（get_wushu_text）= 数量非时间，不混入应期**，独立输出
- 全部无可断 → 返回 ''；三法均叙事层，**不参与 valence**（铁律）
