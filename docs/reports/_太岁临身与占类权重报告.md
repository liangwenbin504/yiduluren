## 一、太岁临身应期（太岁法）

**原文依据**（219 案 duanyu）：
- 宅墓02·013「流年太岁在亥，太岁乘空临身，所谓当头立也。太岁即临身，而行年又入墓地，故主十六年而亡耳」
- 前程03·059「太岁来克身，当年可见不宁」
- 疾病13·163「四十一岁上，太岁到寅，死矣」

**判定逻辑**：`太岁支 == 日干寄宫上神`（干寄宫地盘→天盘对应支）→ 太岁临身，当年大凶"当头立"。
- 寄宫表：甲寅 乙辰 丙巳 丁未 戊巳 己未 庚申 辛戌 壬亥 癸丑
- 实测验证：013 壬子日卯将卯时（伏吟盘）+太岁亥 → 壬寄亥、亥上=亥 → **亥亥伏吟=太岁临身** ✓

**落码**：`get_tai_sui_lin_shen_text(ri_gan, tiandi_pan, tai_sui_zhi)` → 叙事文本；缺参安全 ''。
**接线**：起课页「太岁地支（可选）」下拉 + GET/POST `tai_sui` 参数 + `太岁临身` 响应字段 + demo 显示行。
