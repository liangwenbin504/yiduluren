## 一、五星定义（核心，山家五行 = 「我」）

| 星曜 | 五行关系 | 吉凶 | 说明 |
|---|---|---|---|
| **元辰** | **同我**（日干化气 = 山家五行） | 第一吉 | 本山得气，福力持久，根基稳固 |
| **武财** | **我克**（山家克日干化气） | 第一吉 | 主财富、产业、妻财 |
| **廉贞**（廉子） | **我生**（山家生日干化气） | 次吉 | 主子孙、泄秀 |
| **贪官** | **生我**（日干化气生山家） | 次凶 | 主官非、压力 |
| **破鬼** | **克我**（日干化气克山家） | 第一凶 | 主破败、血光 |

**吉凶排序**（ZR_02_ZS 原文）：「取元辰武财为第一吉，廉子次之，忌破鬼为第一凶，贪官次之」→ 元辰=武财 > 廉贞 > 贪官 > 破鬼。

**判定法**：以山家斗首五行为「我」，取日课天干**化气五行**与山家比较，按上表归类（同我=元辰 / 我克=武财 / 我生=廉贞 / 生我=贪官 / 克我=破鬼）。

**实例（知识库原文验证）**：
- ZR_09_01：甲山（水）四丙申课 → 丙辛化水 = 同我 = **丙为水元** ✅
- ZR_09_02：壬子山（土）见甲己二干 → 甲己化土 = **元辰** ✅（土山元辰=甲己两干）
