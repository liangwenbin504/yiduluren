# 占课干支年回填 + 太岁临身接入 实施报告（2026-08-02）

> 背景：憨爷"补 53 案干支年字段"——打通太岁临身古例回测
> 定位：year=占课干支年（如'戊申'），太岁=其地支；太岁临身作通用凶信号

## 一、占课干支年回填（47 案）

**方法**（docs/reports/_assign_year.py）：
1. **duanyu 定位法**（24 案）：duanyu 唯一子串定位 OCR 标题 → 提取标题占课年（"例X：戊申年X月X日X将X时"）
2. **课式三元组**（23 案）：(日干支, 月将) 双键匹配 OCR 标题，唯一候选回填
3. 生年/占课年甄别：标题"X年N月N日X时生"是**生年**，取后一个干支年（占课年）

**47 案分布**：己酉14/戊申13/己巳4/辛卯2/丁丑2/庚戌2/乙卯2 + 其余各1（建炎年间主占年合理）。

**数据备份**：`shuzheng_real_cases.json.bak_before_year`。

## 二、太岁临身（通用凶信号 -4）

**判定**：太岁支（占课年地支）== 日干寄宫上神 → 太岁临身"当头立"。

**古例回测（47 案）**：触发 **3 案全凶（3/3=100%）**：
- §前程仕进03·067（戊申年 壬寅日）功名凶
- §交易谋为10·147（庚戌年 乙巳日）求财凶
- §杂占17·213（己酉年 乙丑日）其他凶
3 案 duanyu 均无"太岁"原文 → **隐性太岁临身**（邵彦和未明说但课象存在），引擎自动检出，方向全对。

**落码**：
- `extract_tai_sui_valence(ri_gan, tiandi_pan, year)` → TS -4（需 year，缺省零触发）
- ancient_backtest 注入 `_tai_sui_valence` + fusion 消费 `('tai_sui', 4.0, False, 0.85)`
- `_honest_skill_all.py` clean dict 透传 year
