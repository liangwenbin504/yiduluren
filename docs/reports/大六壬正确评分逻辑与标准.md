# 大六壬正确评分逻辑与标准

**基于《六壬大全》《六壬指南》经典理论**

---

## 一、评分标准总纲

大六壬课格评分必须遵循以下**三大核心标准**：

1. **64 课课经吉凶**：按课经原文判断吉凶
2. **十三吉课**：必须是传统十三吉课之一
3. **禄马贵人到山到向**：禄马贵人必须全部到山或到向

**评分公式**：
```
最终评分 = 课体吉凶分 × 禄马贵人系数 × 十三吉课加成
```

### 2.2 十三吉课判断规则

#### 1. 三光课（大吉）
```
条件：
- 三传皆吉神（贵人、螣蛇、朱雀、六合、青龙、太常）
- 三传旺相有气
- 无凶煞冲破

断语：三光课大吉，百事亨通，万事如意
```

#### 2. 三阳课（大吉）
```
条件：
- 三传皆阳支（子寅辰午申戌）
- 三传生旺
- 无阴煞

断语：三阳开泰，诸事顺利，阳气充盈
```

#### 3. 龙德课（上吉）
```
条件：
- 太岁发用
- 或月建发用
- 或天乙贵人发用
- 三者居一即可

断语：龙德课贵人扶持，官运亨通
```

#### 4. 官爵课（上吉）
```
条件：
- 官星发用
- 或爵星发用
- 利求官求职

断语：官爵课利官职升迁，功名成就
```

#### 5. 富贵课（上吉）
```
条件：
- 财星发用
- 或禄神发用
- 利求财

断语：富贵课利求财，财源广进
```

### 2.3 非十三吉课处理

**如果课体不在十三吉课列表中**：
- 即使课体本身吉（如元首课、重审课）
- 也**不能直接评为上吉**
- 需要禄马贵人到山到向来补救

## 三、禄马贵人到山到向规则

### 3.1 禄马贵人查法

#### 1. 禄神（日禄）

**十干禄**：
```
甲禄在寅，乙禄在卯，丙禄在巳，丁禄在午，戊禄在巳
己禄在午，庚禄在申，辛禄在酉，壬禄在亥，癸禄在子
```

**查法**：
- 以**日干**为准
- 看三传、四课中是否有禄神
- 禄神到山（坐山）或到向（向首）为吉

#### 2. 驿马

**驿马查法**（按日支三合）：
```
申子辰日：马在寅
亥卯未日：马在巳
寅午戌日：马在申
巳酉丑日：马在亥
```

**查法**：
- 以**日支**为准
- 看三传、四课中是否有驿马
- 驿马到山或到向为吉

#### 3. 天乙贵人

**贵人查法**（按日干）：
```
甲日：丑、未
乙日：子、申
丙日：亥、酉
丁日：亥、酉
戊日：丑、未
己日：子、申
庚日：丑、未
辛日：午、寅
壬日：巳、卯
癸日：巳、卯
```

**查法**：
- 以**日干**为准
- 看三传、四课中是否有贵人
- 贵人到山或到向为大吉

### 3.2 到山到向判断

#### 到山
```
定义：禄马贵人出现在坐山的地支上

例：壬山（子山）
- 禄神到山：三传或四课见禄神且临子位
- 驿马到山：三传或四课见驿马且临子位
- 贵人到山：三传或四课见贵人且临子位
```

#### 到向
```
定义：禄马贵人出现在向首的地支上

例：壬山丙向（向首为午）
- 禄神到向：三传或四课见禄神且临午位
- 驿马到向：三传或四课见驿马且临午位
- 贵人到向：三传或四课见贵人且临午位
```

### 3.3 禄马贵人系数

根据禄马贵人到山到向的情况，设置系数：

| 情况 | 系数 | 说明 |
|------|------|------|
| **禄马贵人全到山/向** | **1.5** | 全吉，百事亨通 |
| **禄马到山/向** | **1.3** | 大吉，财官两旺 |
| **贵人到山/向** | **1.2** | 上吉，贵人扶持 |
| **禄或马到山/向** | **1.1** | 中吉，小利 |
| **禄马贵人皆不到** | **0.8** | 减分，有缺陷 |

## 四、完整评分逻辑

### 4.1 评分流程

```
1. 判断是否为十三吉课
   ↓
   是 → 取对应基础分
   否 → 进入下一步

2. 判断课体吉凶（64 课课经）
   ↓
   吉课 → 取基础分（70-95 分）
   平课 → 取基础分（50-69 分）
   凶课 → 取基础分（0-49 分）

3. 检查禄马贵人到山到向
   ↓
   全到 → 系数 1.5
   禄马到 → 系数 1.3
   贵人到 → 系数 1.2
   一到 → 系数 1.1
   皆不到 → 系数 0.8

4. 计算最终评分
   最终分 = 基础分 × 禄马贵人系数

5. 限制在 0-100 分
   最终分 = min(100, max(0, 最终分))
```

### 4.2 评分公式

```python
def calculate_final_score(ke_ti, lu_ma_gui_ren_status):
    """
    计算最终评分
    
    :param ke_ti: 课体名称
    :param lu_ma_gui_ren_status: 禄马贵人状态
    :return: 最终评分 (0-100)
    """
    # 1. 判断是否为十三吉课
    if ke_ti in 十三吉课列表:
        base_score = 十三吉课 [ke_ti]['base_score']
    else:
        # 2. 按 64 课课经判断
        base_score = 64 课课经 [ke_ti]['base_score']
    
    # 3. 禄马贵人系数
    if lu_ma_gui_ren_status == '全到':
        coefficient = 1.5
    elif lu_ma_gui_ren_status == '禄马到':
        coefficient = 1.3
    elif lu_ma_gui_ren_status == '贵人到':
        coefficient = 1.2
    elif lu_ma_gui_ren_status == '一到':
        coefficient = 1.1
    else:  # 皆不到
        coefficient = 0.8
    
    # 4. 计算最终分
    final_score = base_score * coefficient
    
    # 5. 限制在 0-100
    final_score = min(100, max(0, int(final_score)))
    
    return final_score
```

## 六、吉凶等级划分

### 6.1 最终评分与吉凶

| 分数范围 | 吉凶等级 | 描述 | 建议 |
|----------|----------|------|------|
| **90-100** | 上上大吉 | 十三吉课 + 禄马贵人全到 | ✅ 首选，百事亨通 |
| **80-89** | 上吉 | 十三吉课或禄马贵人到 | ✅ 次选，诸事顺利 |
| **70-79** | 中吉 | 吉课 + 禄马贵人一到 | ⚠️ 可用，小利 |
| **60-69** | 小吉 | 吉课但禄马贵人不到 | ⚠️ 斟酌用之 |
| **50-59** | 平 | 平课 | ❌ 慎用，吉凶参半 |
| **40-49** | 小凶 | 凶课 + 禄马贵人不到 | ❌ 不宜，有阻滞 |
| **30-39** | 中凶 | 凶课 | ❌ 忌用，多凶少吉 |
| **0-29** | 大凶 | 大凶课 | ❌ 绝对避免 |

### 6.2 关键判断

**必须同时满足以下条件才能评为上吉**：
1. ✅ 是十三吉课之一
2. ✅ 禄马贵人至少一到山或到向

**如果只满足课体吉，但禄马贵人不到**：
- 最高只能评为中吉
- 不可评为上吉

**如果课体非十三吉课，但禄马贵人全到**：
- 可以评为上吉
- 但不可评为上上大吉

## 七、推理过程详解

### 7.1 完整推理流程

```
1. 起课（月将加时）
   ↓
2. 排四课三传
   ↓
3. 判断课体（64 课课经）
   ↓
4. 检查是否为十三吉课
   ↓
   是 → 取十三吉课基础分
   否 → 取 64 课课经基础分
   ↓
5. 查禄马贵人
   - 以日干查禄神
   - 以日支查驿马
   - 以日干查贵人
   ↓
6. 判断禄马贵人是否到山到向
   - 看三传、四课
   - 看是否临山向
   ↓
7. 确定禄马贵人系数
   ↓
8. 计算最终评分
   ↓
9. 生成吉凶断语
```

### 7.2 禄马贵人到山到向判断

**判断步骤**：

1. **确定坐山和向首**
   ```
   壬山：山=子，向=午
   子山：山=子，向=午
   癸山：山=子，向=午
   等等
   ```

2. **查禄马贵人**
   ```
   例：丙子日
   - 禄神：丙禄在巳
   - 驿马：申子辰马在寅
   - 贵人：丙日贵人在亥、酉
   ```

3. **检查三传四课**
   ```
   例：三传为 寅→巳→亥
   - 初传寅：驿马 ✅
   - 中传巳：禄神 ✅
   - 末传亥：贵人 ✅
   
   结论：禄马贵人全到
   ```

4. **判断是否到山到向**
   ```
   例：壬山（子山）
   - 如果禄马贵人临子位 → 到山
   - 如果禄马贵人临午位 → 到向
   ```

## 八、总结

### 8.1 核心要点

1. **十三吉课优先**：必须是十三吉课之一才能评为上上大吉
2. **禄马贵人关键**：禄马贵人到山到向是吉凶的关键
3. **课体是基础**：64 课课经吉凶是基础分
4. **系数是加成**：禄马贵人系数决定最终吉凶程度

### 8.2 评分原则

- **严格性**：必须同时满足课体吉 + 禄马贵人到
- **权威性**：完全基于《六壬大全》《六壬指南》
- **准确性**：量化评分，避免主观判断
- **实用性**：便于实际操作和应用

### 8.3 使用建议

1. **首选**：十三吉课 + 禄马贵人全到（90-100 分）
2. **次选**：十三吉课或禄马贵人到（80-89 分）
3. **斟酌**：吉课 + 禄马贵人一到（70-79 分）
4. **避免**：凶课 + 禄马贵人不到（50 分以下）
