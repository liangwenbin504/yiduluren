# 天地盘图形化显示功能说明

## 功能概述

在大六壬排盘子程序中实现了天地盘的图形化显示功能，通过直观的可视化界面展示地盘十二地支的固定方位关系，帮助用户更好地理解大六壬排盘的基础结构。

---

## ✅ 实现的功能

### 1️⃣ 地盘方位图形化

**显示效果**：

西 卯          巳 东

### 2️⃣ 十二地支方位准确排列

**方位对应**：

| 地支 | 方位 | 角度 | 坐标位置 |
|-----|------|------|---------|
| 子 | 正北 | 0° | (中心 x, 中心 y - 半径) |
| 丑 | 东北 | 30° | (中心 x + 0.5r, 中心 y - 0.866r) |
| 寅 | 东北 | 60° | (中心 x + 0.866r, 中心 y - 0.5r) |
| 卯 | 正东 | 90° | (中心 x + r, 中心 y) |
| 辰 | 东南 | 120° | (中心 x + 0.866r, 中心 y + 0.5r) |
| 巳 | 东南 | 150° | (中心 x + 0.5r, 中心 y + 0.866r) |
| 午 | 正南 | 180° | (中心 x, 中心 y + r) |
| 未 | 西南 | 210° | (中心 x - 0.5r, 中心 y + 0.866r) |
| 申 | 西南 | 240° | (中心 x - 0.866r, 中心 y + 0.5r) |
| 酉 | 正西 | 270° | (中心 x - r, 中心 y) |
| 戌 | 西北 | 300° | (中心 x - 0.866r, 中心 y - 0.5r) |
| 亥 | 西北 | 330° | (中心 x - 0.5r, 中心 y - 0.866r) |

**坐标计算**：
```python
# 使用三角函数计算位置
x = center_x + radius * cos(角度)
y = center_y + radius * sin(角度)

# 简化计算（使用固定系数）
'子': (center_x, center_y - radius)  # 正北
'卯': (center_x + radius, center_y)  # 正东
'午': (center_x, center_y + radius)  # 正南
'酉': (center_x - radius, center_y)  # 正西
```

## 💡 技术实现

### 核心代码

```python
def _draw_dizhi_layout(self, tiandi_pan):
    """绘制地盘十二地支方位图"""
    canvas = self.dizhi_canvas
    canvas.delete("all")  # 清空画布
    
    # 中心点和半径
    center_x, center_y = 200, 200
    radius = 150
    
    # 十二地支位置（按方位角度）
    dizhi_positions = {
        '子': (center_x, center_y - radius),      # 正北
        '卯': (center_x + radius, center_y),      # 正东
        '午': (center_x, center_y + radius),      # 正南
        '酉': (center_x - radius, center_y),      # 正西
        # ... 其他地支
    }
    
    # 绘制外圆
    canvas.create_oval(...)
    
    # 绘制十字线
    canvas.create_line(...)
    
    # 绘制方位标签
    canvas.create_text(..., text="北", ...)
    
    # 绘制十二地支
    for dizhi, (x, y) in dizhi_positions.items():
        canvas.create_text(x, y, text=dizhi, ...)
        
        # 显示天盘
        if tiandi_pan:
            tian = tiandi_pan.get(dizhi, '')
            offset_x = (x - center_x) * 0.3
            offset_y = (y - center_y) * 0.3
            canvas.create_text(x + offset_x, y + offset_y, 
                             text=f"天:{tian}", ...)
```
