# 天将盘计算功能修复说明

## 修复日期
2026-03-16

## 问题描述
用户反馈：在排盘窗口的"天将盘"选项卡中显示"天将盘计算暂不可用"

## 问题分析

### 错误原因
`arrange_gui_ren_pan` 方法期望接收的参数格式为：
```python
tian_pan = {'天地对应': {...}}  # 嵌套字典
```

但 `get_tiandi_pan` 方法返回的格式为：
```python
tiandi_pan = {...}  # 直接的字典
```

导致在第 100 行访问 `tian_pan['天地对应']` 时抛出 `KeyError` 异常。

### 昼夜判断错误

原始代码使用了错误的昼夜判断逻辑：
```python
# 错误代码
shi_hour = int(shi_ganzhi[0]) if shi_ganzhi[0].isdigit() else 12
is_night = shi_hour < 6 or shi_hour >= 18
```

问题：
- `shi_ganzhi[0]` 是天干（如"庚"），不是数字
- 应该使用时支（如"午"）来判断昼夜

## 修复方案

### 修复 1：包装天地盘字典

**文件**：`天地盘.py`  
**位置**：第 1989 行

**修改前**：
```python
# 排贵人盘
gui_ren_pan = gui_ren_calc.arrange_gui_ren_pan(ri_gan, tiandi_pan, shi_ganzhi, is_night)
```

**修改后**：
```python
# 包装天地盘为正确格式
tiandi_pan_dict = {'天地对应': tiandi_pan} if isinstance(tiandi_pan, dict) else tiandi_pan

# 排贵人盘
gui_ren_pan = gui_ren_calc.arrange_gui_ren_pan(ri_gan, tiandi_pan_dict, shi_ganzhi, is_night)
```

### 修复 2：修正昼夜判断逻辑

**文件**：`天地盘.py`  
**位置**：第 1983-1985 行

**修改前**：
```python
# 判断昼夜（简化：默认昼占）
shi_hour = int(shi_ganzhi[0]) if shi_ganzhi[0].isdigit() else 12
is_night = shi_hour < 6 or shi_hour >= 18  # 简化判断
```

**修改后**：
```python
# 判断昼夜（根据时支）
# 昼时：卯、辰、巳、午、未、申
# 夜时：酉、戌、亥、子、丑、寅
zhou_hours = ['卯', '辰', '巳', '午', '未', '申']
is_night = shi_zhi not in zhou_hours
```

### 修复 3：增强错误提示

**文件**：`天地盘.py`  
**位置**：第 1993-1995 行

**修改前**：
```python
except Exception as e:
    print(f"天将盘计算错误：{e}")
    self.tianjiang_canvas.create_text(200, 175, text="天将盘计算暂不可用", 
                                     font=('Microsoft YaHei UI', 12), fill='#666')
```

**修改后**：
```python
except Exception as e:
    import traceback
    print(f"天将盘计算错误：{e}")
    traceback.print_exc()
    self.tianjiang_canvas.create_text(200, 175, text="天将盘计算暂不可用\n" + str(e), 
                                     font=('Microsoft YaHei UI', 10), fill='#666')
```
