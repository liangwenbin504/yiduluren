## 一、评分标准总纲

大六壬课格评分必须遵循以下**三大核心标准**：

1. **64 课课经吉凶**：按课经原文判断吉凶
2. **二十吉课**：必须是传统二十吉课之一
3. **禄马贵人到山到向**：禄马贵人必须全部到山或到向

**评分公式**：
```
最终评分 = 课体吉凶分 × 禄马贵人系数 × 二十吉课加成
```

### 3.2 到山到向判断

#### 到山
```
定义：禄马贵人出现在坐山的地支上

例：壬山（子山）
- 禄神到山：三传或四课见禄神且临子位
- 驿马到山：三传或四课见驿马且临子位
- 贵人到山：三传或四课见贵人且临子位
```

#### 到向
```
定义：禄马贵人出现在向首的地支上

例：壬山丙向（向首为午）
- 禄神到向：三传或四课见禄神且临午位
- 驿马到向：三传或四课见驿马且临午位
- 贵人到向：三传或四课见贵人且临午位
```

### 3.3 禄马贵人系数

| **禄马贵人全到山/向** | **1.5** | 全吉，百事亨通 |

## 四、完整评分逻辑

### 4.1 评分流程

```
1. 判断是否为二十吉课
   ↓
   是 → 取对应基础分
   否 → 进入下一步

2. 判断课体吉凶（64 课课经）
   ↓
   吉课 → 取基础分（70-95 分）
   平课 → 取基础分（50-69 分）
   凶课 → 取基础分（0-49 分）

3. 检查禄马贵人到山到向
   ↓
   全到 → 系数 1.5
   禄马到 → 系数 1.3
   贵人到 → 系数 1.2
   一到 → 系数 1.1
   皆不到 → 系数 0.8

4. 计算最终评分
   最终分 = 基础分 × 禄马贵人系数

5. 限制在 0-100 分
   最终分 = min(100, max(0, 最终分))
```

### 4.2 评分公式

```python
def calculate_final_score(ke_ti, lu_ma_gui_ren_status, shan_xiang):
    """
    计算最终评分
    
    :param ke_ti: 课体名称
    :param lu_ma_gui_ren_status: 禄马贵人状态
    :param shan_xiang: 坐山向首
    :return: 最终评分 (0-100)
    """
    # 1. 判断是否为二十吉课
    if ke_ti in 二十吉课列表:
        base_score = 二十吉课[ke_ti]['base_score']
    else:
        # 2. 按 64 课课经判断
        base_score = 64课课经[ke_ti]['base_score']
    
    # 3. 禄马贵人系数
    if lu_ma_gui_ren_status == '全到':
        coefficient = 1.5
    elif lu_ma_gui_ren_status == '禄马到':
        coefficient = 1.3
    elif lu_ma_gui_ren_status == '贵人到':
        coefficient = 1.2
    elif lu_ma_gui_ren_status == '一到':
        coefficient = 1.1
    else:  # 皆不到
        coefficient = 0.8
    
    # 4. 计算最终分
    final_score = base_score * coefficient
    
    # 5. 限制在 0-100
    final_score = min(100, max(0, int(final_score)))
    
    return final_score
```

## 七、总结

### 7.1 核心要点

1. **二十吉课优先**：必须是二十吉课之一才能评为上上大吉
2. **禄马贵人关键**：禄马贵人到山到向是吉凶的关键
3. **课体是基础**：64 课课经吉凶是基础分
4. **系数是加成**：禄马贵人系数决定最终吉凶程度

### 7.2 评分原则

- **严格性**：必须同时满足课体吉 + 禄马贵人到
- **权威性**：完全基于《六壬大全》《六壬指南》
- **准确性**：量化评分，避免主观判断
