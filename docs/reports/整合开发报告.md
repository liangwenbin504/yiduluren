# 大六壬排盘软件 - Skill 与龙德课整合开发报告

## 一、整合目标

将**大六壬排盘引用 SKILL 功能**与**集成龙德课功能**进行无缝整合，实现：

1. **数据交互**：排盘数据与龙德课判断数据共享
2. **逻辑衔接**：九宗门起课法则与龙德课判断逻辑统一
3. **功能互补**：排盘功能为龙德课提供基础，龙德课为排盘增加择日维度
4. **完整体系**：共同服务于大六壬排盘软件的整体功能

---

## 二、整合架构

### 2.1 核心模块

```
大六壬排盘软件 (DaLiuRenPaipanSoftware)
│
├── 排盘引擎模块（SKILL 功能）
│   ├── CompleteQiKeEngine - 完整起课引擎
│   ├── SiKeSanChuanEngine - 四课三传引擎（九宗门）
│   ├── KeTiJudgeCalculator - 课体判断（64 课经）
│   ├── GuiRenEngine - 贵人引擎
│   ├── ShenShaCalculator - 神煞计算器
│   └── PreciseCalendar - 精确历法
│
├── 龙德课模块
│   ├── LongDeKeSelector - 龙德课择日引擎
│   ├── 禄马贵到山到向分析
│   └── 二十四山家信息
│
└── 整合功能
    ├── full_paipan() - 完整排盘
    ├── paipan_with_lu_ma_gui() - 排盘 + 禄马贵分析
    └── select_best_dates() - 选择最佳日期
```

### 2.2 数据流

```
用户输入（日期时间）
    ↓
精确历法计算（四柱）
    ↓
排盘引擎（四课、三传、天地盘、天将、神煞）
    ↓
课体判断（64 课经）
    ↓
龙德课判断 ← 月将、三传、贵人
    ↓
禄马贵到山到向分析 ← 日干、时支、山向
    ↓
综合评分系统
    ↓
输出完整结果（排盘 + 龙德课 + 禄马贵 + 评分）
```

## 三、核心功能实现

### 3.1 完整排盘功能

**方法**：`full_paipan(year, month, day, hour, city_name)`

**整合内容**：

1. **精确四柱计算**
   - 使用 `PreciseCalendar.get_sizhu_accurate()`
   - 支持真太阳时（根据城市经纬度）
   - 精确节气计算

2. **四课三传（SKILL 九宗门）**
   - 贼克、比用、涉害、遥克、昴星、别责、八专、伏吟、反吟
   - 完整的九宗门起课法则
   - 依据 `core_rules.md` 核心规则

3. **天地盘排布**
   - 月将加时占
   - 地盘固定，天盘旋转
   - SKILL 地支排布生成器

4. **天将排布**
   - 贵人起法（甲戊庚牛羊...）
   - 顺逆排布（卯酉为日月之门）

5. **神煞计算**
   - 日辰神煞、月建神煞、年支神煞
   - 驿马、桃花、日禄、日德等

6. **课体判断**
   - 64 课经完整判断
   - 伏吟、反吟、三光、天福、玉堂等

7. **龙德课判断**
   - 太岁或月将发用
   - 乘贵人（初传为日干贵人）
   - 分为太岁龙德课和月将龙德课

8. **断语生成**
   - 综合课体、龙德课、神煞
   - 自动生成专业断语

**返回结果**：
```python

        '月将': '酉',

        '旬空': '午'
    },
    '四课': [...],

    '天地盘': {...},
    '天将': [...],
    '神煞': {'吉神': [...], '凶煞': [...]},

        '是龙德课': True,

    },

```

### 3.2 排盘 + 禄马贵分析

**方法**：`paipan_with_lu_ma_gui(year, month, day, hour, shan, city_name)`

**整合内容**：

1. **完整排盘**：调用 `full_paipan()`
2. **禄马贵到山到向**：
   - 根据日干查禄马贵
   - 根据山向查喜忌
   - 判断禄马贵是否到山到向

3. **综合评分**：
   ```
   总评分 = 课体评分×40% + 龙德课评分×30% + 禄马贵评分×30%
   ```

**返回结果**：
```python
{
    '排盘结果': {...},  # 完整排盘数据
    '禄马贵分析': {
        '到山到向详情': ['年禄到山到向', '日贵到山到向', ...],
        '总数': 7
    },
    '综合评分': 6.3,
    '推荐指数': '★★☆☆☆ 小吉'
}
```

### 3.3 选择最佳日期

**方法**：`select_best_dates(shan, start_date, end_date, min_score, only_long_de)`

**整合内容**：

1. **遍历日期范围**：逐日逐时计算
2. **排盘 + 龙德课判断**：每个时辰完整排盘
3. **禄马贵分析**：检查禄马贵到山到向
4. **综合评分筛选**：只保留符合条件的日期
5. **排序输出**：按评分从高到低排序

**使用示例**：
```python
from datetime import datetime

software = DaLiuRenPaipanSoftware()

# 选择壬山 2026 年 9 月的最佳日期
start = datetime(2026, 9, 1)
end = datetime(2026, 9, 30)
best_dates = software.select_best_dates(
    shan='壬',
    start_date=start,
    end_date=end,
    min_score=6.0,
    only_long_de=True  # 仅龙德课
)

# 输出前 5 个最佳日期
for i, item in enumerate(best_dates[:5], 1):
    print(f"{i}. {item['日期']} {item['时辰']}")
    print(f"   四柱：{item['四柱']}")
    print(f"   课体：{item['课体']}, 龙德课：{item['龙德课']}")
    print(f"   评分：{item['评分']:.1f}分")
```

## 五、龙德课功能整合

### 5.1 龙德课判断逻辑

**龙德课条件**：
1. **发用**：太岁或月将出现在初传
2. **乘贵人**：初传为日干的天乙贵人

**判断流程**：
```python
def is_long_de_ke(ri_ganzhi, yue_jiang, tai_sui, sanchuan):
    # 1. 检查是否太岁或月将发用
    if sanchuan['初传'] not in [tai_sui, yue_jiang]:
        return False, None
    
    # 2. 检查初传是否为日干贵人
    ri_gan = ri_ganzhi[0]
    gui_map = {...}  # 贵人映射表
    if sanchuan['初传'] in gui_map[ri_gan]:
        if sanchuan['初传'] == tai_sui:
            return True, "太岁龙德课（岁君赐福）"
        else:
            return True, "月将龙德课（光明之象）"
    
    return False, None
```

| 5-6 个 | 7.0 | 吉 |

- **一次排盘，多处使用**：排盘数据同时用于课体判断、龙德课判断、禄马贵分析
