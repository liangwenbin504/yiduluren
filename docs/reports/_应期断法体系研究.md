## 二、洛书数法（邵彦和实操核心，34 案最多）

### 数源（通解下卷原文）
> 后天五行数，甲己子午九，乙庚丑未八，丙辛寅申七，丁壬卯酉六，戊癸辰戍五，巳亥无干四。
> 除此外，更上下相因取数。如上见子为九，下见已为四，上下相乘得四九三十六数。

| 支 | 数 | | 支 | 数 |
|---|---|---|---|---|
| 子午 | 9 | | 丑未 | 8 |
| 寅申 | 7 | | 卯酉 | 6 |
| 辰戌 | 5 | | 巳亥 | 4 |

### 运算类型（219 案实测，17 条完整样本回测）
| 运算 | 实例 | 期望 | 回测 |
|---|---|---|---|
| 单支 | 卯数六故不出六年（宅墓02·005） | 6 | ✓ |
| 相加 | 亥数四寅数七乃十一年（宅墓02·004） | 4+7=11 | ✓ |
| 相加 | 戌加巳上五下四共九数（宅墓02·006） | 5+4=9 | ✓ |
| 三传连加 | 卯六辰五巳四共十五年（前程03·051） | 6+5+4=15 | ✓ |
| 相乘 | 子九申七七九共六十三（宅墓02·008） | 9×7=63 | ✓ |
| 相乘 | 申数七亥数四四七二十八（疾病13·162） | 7×4=28 | ✓ |
| 倍数 | 亥四数课中四个亥四四一十六年（宅墓02·013） | 4×4=16 | ✓（需课盘上下文）|
| 加半 | 酉六数更三年死酉增一半（宅墓02·040） | 6+3=9 | ✗ 特殊 |
| 支位计数 | 从酉数至辰八位故八年（前程03·085） | 8 | ✗ 特殊 |

**回测结论：核心运算（单支/相加/相乘）13/17=76% 可复现**；倍数/加半/支位计数需课盘上下文（支出现次数/行年位置），属进阶变体。

### ⚠️ 回测修正（2026-08-02 最终）
**邵彦和取数是「断句内特定支组合」，非三传全支运算**：
- 宅墓02·004 三传 巳寅亥，邵只用 亥4+寅7=11（**不用巳**）
- 若按三传全加（4+7+4=15）或全乘，与邵断不符
- 回测 76% 是「断句内支」验证（论文式），**不能直接推广为三传全支算法**
- 引擎 `get_yingqi_text` 已降级为保守模式：只报各支数+众数/初传提示，**不猜测运算组合**（诚实处理）

### ⚠️ 关键冲突与判定（邵彦和实操 vs 知识库）
1. **天干数实操罕见**：通解理论有天干数（甲己9乙庚8…），但 219 案断语**零处直接用天干数**——邵彦和实操只用支数
2. **乘法/加法选择冲突**：同一对支（申7亥4）在疾病13·162 用乘法（28），在宅墓02·004（亥4寅7）用加法（11）——取决于语义（相乘=物数/寿数，相加=年份）
3. **知识库 21 条偏股票**：knowledge_应期_完整规则.json 的"初长生末墓=先易后难"等 21 条多为股票应用口径，与古法应期语义有偏差，**不可直接作古法依据**，仅参考

## 三、非数法应期（各有专长）

### 太岁法（28 案）
- 「太岁乘空临身，所谓当头立也。太岁即临身，而行年又入墓地，故主十六年而亡」（宅墓02·013）
- 规则：太岁临身（日干）→ 当年有事；太岁+行年入墓 → 死期

### 行年法（14 案）
- 「行年又入墓地，故主十六年而亡」（宅墓02·013）
- 「行年在酉，因青龙在辰故也，从酉数至辰八位，故八年」（前程03·085）——**行年与数法结合**！

### 月建法（11 案）
- 「亥卯未三合，五月月建上得未，故五月有服」（宅墓02·020）——三合局找当月建

### 填实/出旬（9 案）
- 「必俟出旬乙巳日填实，方能得马」（下卷例）——空亡支出旬/值日方应

### 冲合法（5 案）
- 「被末传丑来冲破…子息花而不实」（胎产07·126）——合处逢冲破

## 四、引擎落码建议

### ✅ 已落（2026-08-02 前）
- `ZHI_NUMBER` 洛书地支数 + `get_yingqi_text` 叙事层（单支/众数，粗略版）

### 🔧 待升级（本报告依据）
1. **数法运算升级**：单支/相加/相乘三模式（乘=物数寿数、加=年份），区分语义
2. **行年数法**：行年支与课中支的支位计数（从酉数至辰八位）
3. **太岁临身**：太岁支临日干上神 → 当年应（需太岁参数）
4. **空亡填实**：传支空亡 → 出旬/值日应期
5. **月建三合**：三合局成 → 当月建支应期（需月份参数）

### ⚠️ 不进 valence 的铁律
应期=何时发生，非吉凶方向 → 全部走**叙事层**，严禁入评分（同 ZHI_NUMBER 处理）。
