## 🎯 使用流程

### 方法一：一键启动（推荐新手）

1. **双击** `启动 64 课经提取与匹配.bat`
2. 等待自动完成：
   - PDF 提取课经
   - 生成 720 课例
   - 测试匹配
   - 生成报告
3. 查看输出文件

### 方法二：Python 调用（推荐开发者）

```python
from engine.complete_ke_jing_system import CompleteKeJingSystem

# 初始化
system = CompleteKeJingSystem()

# 1. 提取 PDF
system.extract_from_pdf("白话大六壬全书.pdf")

# 2. 生成课例
system.generate_720_ke()

# 3. 匹配并生成报告
qi_ke = {
    '课体': '涉害课',
    '起法': '涉害法',
    '日干支': '甲子',
    '初传': '酉',
    '格局': '见机格'
}

report = system.generate_full_report(
    qi_ke, 2024, 3, 15, 10
)

print(report)
system.save_report(report, "output/报告.txt")
```

### 方法三：GUI 界面（推荐最终用户）

1. **双击** `start.bat` 启动主 GUI
2. 输入起课参数
3. 点击【验证起课】
4. 查看匹配的课经（集成后）

由于 PyMuPDF 可能未安装，系统提供了两种方式：

1. **自动提取**（需安装 PyMuPDF）
