# 月柱计算错误修正说明

## 问题描述

用户发现 2026 年 9 月 4 日的月柱计算错误：

**错误结果**：
```
四柱：丙午年 己酉月 辛亥日 癸巳时
```

**正确结果**（万年历验证）：
```
四柱：丙午年 丁酉月 辛巳日 癸巳时
```

**问题**：月柱应该是**丁酉**，而不是**己酉**

---

## 错误原因分析

### 1. 五虎遁年起月诀

传统五虎遁口诀：

> 甲己之年丙作首  
> **乙庚之岁戊为头**  
> **丙辛之岁从庚起**  
> 丁壬壬寅顺水流  
> 戊癸之年甲寅首

2026 年是**丙午年**，适用"丙辛之岁从庚起"：
- 正月（寅月）：**庚寅**
- 二月（卯月）：辛卯
- 三月（辰月）：壬辰
- 四月（巳月）：癸巳
- 五月（午月）：甲午
- 六月（未月）：乙未
- 七月（申月）：丙申
- **八月（酉月）：丁酉** ← 正确
- 九月（戌月）：戊戌
- 十月（亥月）：己亥
- 冬月（子月）：庚子
- 腊月（丑月）：辛丑

### 2. 原代码错误

原代码中的计算逻辑：

```python
month_zhi_index = self.DIZHI.index(month_zhi)  # 酉的索引是 9

if year_gan in ['丙', '辛']:
    month_gan_base = 6  # 庚

month_gan_index = (month_gan_base + month_zhi_index) % 10
# = (6 + 9) % 10 = 15 % 10 = 5
# 索引 5 对应天干：己 ❌ 错误！
```

**错误原因**：
- `month_zhi_index` 使用了地支在 DIZHI 数组中的绝对索引（酉=9）
- 但月干计算应该使用"从寅月开始计数的序号"（酉月应该是第 7 个月，序号=6）

---

## 修正方案

### 修正后的代码

```python
# 获取月支
month_zhi = self.JIEQI_MONTH[current_jieqi]

# 计算月支在寅卯辰巳午未申酉戌亥子丑中的序号（0-11）
# 寅=0, 卯=1, 辰=2, 巳=3, 午=4, 未=5, 申=6, 酉=7, 戌=8, 亥=9, 子=10, 丑=11
month_order = self.DIZHI.index(month_zhi) - 2  # 寅的索引是 2，减去 2 得到 0
if month_order < 0:
    month_order += 12  # 子丑月需要调整

# 五虎遁年起月法
year_ganzhi = self.get_year_ganzhi(year, month, day)
year_gan = year_ganzhi[0]

# 根据年干确定正月（寅月）的天干
if year_gan in ['甲', '己']:
    month_gan_base = 2  # 甲己之年丙作首（丙=2）
elif year_gan in ['乙', '庚']:
    month_gan_base = 4  # 乙庚之岁戊为头（戊=4）
elif year_gan in ['丙', '辛']:
    month_gan_base = 6  # 丙辛之岁从庚起（庚=6）
elif year_gan in ['丁', '壬']:
    month_gan_base = 8  # 丁壬壬寅顺水流（壬=8）
else:  # 戊、癸
    month_gan_base = 0  # 戊癸之年甲寅首（甲=0）

# 月干 = 正月天干 + 月份序号
month_gan_index = (month_gan_base + month_order) % 10

return f'{self.TIANGAN[month_gan_index]}{month_zhi}'
```

### 修正后的计算过程

2026 年 9 月（酉月）：

```python
month_zhi = '酉'
month_order = DIZHI.index('酉') - 2 = 9 - 2 = 7  # 酉月是第 8 个月，序号=7

year_gan = '丙'
month_gan_base = 6  # 丙辛之岁从庚起

month_gan_index = (6 + 7) % 10 = 13 % 10 = 3
TIANGAN[3] = '丁'  # 正确！✓

return '丁酉'
```
