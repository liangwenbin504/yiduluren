# 紧急修复说明 - 点击"开始择日"无反应

## 问题描述

**现象**：点击"开始择日"按钮后，没有任何反应，程序不执行择日计算。

**原因**：在 GUI 改进过程中，代码中仍保留了多处对旧组件（`current_shan_label`、`current_xiang_label`）的引用，导致获取山向参数失败。

---

## 问题分析

### 根本原因

在将山向选择从罗盘式改为下拉窗口后，以下 3 个关键方法仍在使用旧的组件引用：

1. **`_start_selection`** (第 693-694 行)
   ```python
   # ❌ 错误：使用旧组件
   shan = self.current_shan_label.cget('text')
   xiang = self.current_xiang_label.cget('text')
   ```

2. **`_save_config`** (第 1381-1382 行)
   ```python
   # ❌ 错误：使用旧组件
   'shan': self.current_shan_label.cget('text'),
   'xiang': self.current_xiang_label.cget('text'),
   ```

3. **`_load_config`** (第 1415-1416 行)
   ```python
   # ❌ 错误：使用旧组件
   self.current_shan_label.config(text=config.get('shan', '壬'))
   self.current_xiang_label.config(text=config.get('xiang', '丙'))
   ```

### 影响范围

- ❌ 点击"开始择日"无反应
- ❌ 无法保存配置
- ❌ 无法加载配置
- ✅ 山向选择功能正常
- ✅ 界面显示正常

---

## 修复方案

### 修复 1：`_start_selection` 方法

**修改位置**：第 693-694 行

**修改前**：
```python
# 获取参数
shan = self.current_shan_label.cget('text')
xiang = self.current_xiang_label.cget('text')
```

**修改后**：
```python
# 获取参数（使用新的下拉框组件）
shan = self.shan_combo.get()
xiang = self.xiang_combo.get()
```

### 修复 2：`_save_config` 方法

**修改位置**：第 1381-1382 行

**修改前**：
```python
config = {
    'shan': self.current_shan_label.cget('text'),
    'xiang': self.current_xiang_label.cget('text'),
    ...
}
```

**修改后**：
```python
config = {
    'shan': self.shan_combo.get(),
    'xiang': self.xiang_combo.get(),
    ...
}
```

### 修复 3：`_load_config` 方法

**修改位置**：第 1415-1416 行

**修改前**：
```python
# 应用配置
self.current_shan_label.config(text=config.get('shan', '壬'))
self.current_xiang_label.config(text=config.get('xiang', '丙'))
```

**修改后**：
```python
# 应用配置
self.shan_combo.set(config.get('shan', '壬'))
self.xiang_combo.set(config.get('xiang', '丙'))
```

### 修复 4：默认评分值

**修改位置**：第 1423 行

**修改前**：
```python
self.min_score_spin.insert(0, str(config.get('min_score', '7.0')))
```

**修改后**：
```python
self.min_score_spin.insert(0, str(config.get('min_score', '5.0')))
```

## 经验教训

### 问题根源

在进行组件重构时，没有全面搜索和更新所有引用点，导致：
1. 只修改了界面组件（`_create_shan_xiang_section`）
2. 遗漏了业务逻辑中的引用（`_start_selection` 等）
3. 没有进行完整的功能测试
