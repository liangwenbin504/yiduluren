## 二、关键教训（已入长期记忆）

1. **小样本方向正确 ≠ 可接评分**——太岁临身 47 案 3/3 全凶，全量后 73% 暴露误伤。**必须全量回测**。（对比 TY 天狱 8→16 案仍 100% 是真信号）
2. **别武断判 PDF**——只测第 1 页就说"扫描版"，错过 24.7 万字文本层。**测全量再下结论**。
3. **OCR 形近字变体**——生→牛/乍、申→中、未→末、壬→王 等，正则要容错。
4. **课式格式坑**——疏正"X将Y时"X=月将Y=时辰；日期双格式"干支日"+"X月X日干支"；标题停行断天将行。
5. **评估用 Python 3.12**——3.13 会得到不同数字（88.4% vs 86.6%）。
6. **M1-3 返回值不含 analysis**——诊断 valence 触发要看 build_result_from_ancient/fusion 信号。
7. **新字段透传 None 坑**——`ancient_case.get("year")` 返回 None 须 `or ''` 兜底。
