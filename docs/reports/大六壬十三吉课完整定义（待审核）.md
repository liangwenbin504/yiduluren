## 一、龙德课（上吉，95分）

### 定义
太岁、月将乘贵人发用，便是龙德课。太岁德被天下，太阳明照四方，贵人降福致祥，龙德课如龙行雨泽，德及万物，故名。

### 核心构成要素
1. **太岁**：一年之主宰，人君也，首出庶物而德被天下
2. **月将**：一月主宰之神，太阳也，悬象在空而明照四方
3. **天乙贵人**：吉将之首，降福致祥，消苦超贫

### 判断条件（必须同时满足）
```
条件一：太岁与月将同类（即太岁=月将）
条件二：太岁、月将乘贵人
条件三：太岁、月将发用

注：若太岁乘贵人发用，传中见月将亦是龙德课
```

### 特殊情形
1. **癸巳年七月癸酉日酉时巳将**：巳为太岁，又为月将，又为日贵加酉，上克下为用，龙德课也
2. 太岁乘太乙而发用，主朝迁恩命，仕宦升迁

### 吉凶断语
```
象曰："君恩及下，万姓欢忻。罪囚出狱，财喜临身。
       利名易萃，争讼休陈。官爵超擢，利见大人。"

占得龙德课：
- 君恩普及臣下，百姓欢欣
- 罪囚可获出狱
- 财喜临身
- 争讼休止
- 官爵得到升迁，利见大人
```

### 例外处理
1. 纵逢凶将，亦不为害
2. 惟尊贵求卑下不吉
3. 或带煞为日鬼，占讼则事干朝廷

### 从属课格及吉凶属性
| 从属格 | 吉凶 | 条件 |
|--------|------|------|
| 龙德本课 | 上吉 | 太岁=月将乘贵人发用 |
| 带煞为日鬼格 | 凶 | 龙德课带煞为日鬼，占讼事干朝廷 |

**龙德课判断要点**：
- 太岁乘太乙而发用，主朝迁恩命，仕宦升迁
- 纵逢凶将，亦不为害
- 应萃卦九四"大吉无咎"之象

### 对应卦象
对应六十四卦之萃卦，统"萃"卦之体，是云龙际会之课。
- 吉则应九四"大吉无咎"之象
- 凶则应初六"有孚不终，乃乱"之象

## 二、斫轮课（上吉，92分）

### 定义
斫轮课指的是卯加庚或加辛为用之课。卯木为车轮，庚辛金为刀斧，木被金斫而成器，故名。

### 核心构成要素
1. **卯（太冲）**：为车轮
2. **庚辛金**：为刀斧
3. **成器之象**：木就金斫，革故鼎新

### 判断条件
```
条件：
1. 初传为卯（太冲）
2. 卯临庚、辛、申、酉上发用

卯临庚申用四绝体盘
卯临辛用四墓覆生盘

卯加庚与申为上，加辛与酉次之
缘卯中乙木与申中庚金作合成器
```

### 特殊情形
1. **壬癸日见水神为舟楫**：初末有马引从为轩车，能任重致远，有除授官职之喜
2. **传中见太常、河魁**：作印绶尤妙
3. **传见本日墓神**：名曰旧轮再斫，来意主退官失职，再谋复兴之意

### 吉凶断语
```
象曰："木欲成器，须假金斫，孕病凶险，财喜欢跃，
       禄位加增，官职超擢，戌印常绶，遇之犹乐。"

占得斫轮课：
- 禄位高迁，革故鼎新
- 求财大获
- 占孕与病讼忌之（凶险之象）
```

### 例外处理
1. **木休囚，乘白虎**：为棺椁
2. **值空亡**：为朽木难雕，须另改业
3. **春季甲乙日寅卯时**：木太重，为伤斧
4. **秋季庚辛日申酉时**：金太重，为伤轮，反凶
5. **辛卯日干上卯**：为财就人象，宜急取之，缓则被卯木克其戊土，反有害也

### 五日吉凶
- 木日：艰难
- 火日：灾疾
- 金日：获福
- 水日：心不定，变易艰难中遂意
- 土日：流转

### 从属课格及吉凶属性
| 从属格 | 吉凶 | 条件 |
|--------|------|------|
| 斫轮本课 | 上吉 | 卯加庚申发用（四绝体盘） |
| 斫轮次吉 | 吉 | 卯加辛酉发用（四墓覆生盘） |
| 舟楫格 | 吉 | 壬癸日见水神，初末有马引从为轩车 |
| 印绶格 | 吉 | 传中见太常、河魁作印绶 |
| 财就人格 | 吉 | 辛卯日干上卯，宜急取财 |
| 旧轮再斫格 | 凶 | 传见本日墓神，主退官失职再谋复兴 |
| 朽木难雕格 | 凶 | 卯木值空亡，须另改业 |
| 伤斧格 | 凶 | 春季甲乙日寅卯时，木太重 |
| 伤轮格 | 凶 | 秋季庚辛日申酉时，金太重 |
| 棺椁格 | 凶 | 木休囚乘白虎 |

**斫轮课吉凶判断要点**：
- 卯加庚与申为上吉（卯中乙木与申中庚金作合成器）
- 卯加辛与酉次之
- 乘龙、常、阴、合吉将方成其体
- 求财大获

### 对应卦象
对应六十四卦之颐卦，统"颐"卦之体，是革故鼎新之课。
- 吉则应上九"利涉大川"之象
- 凶则应初九"观我朵颐"之象

## 三、华盖乘轩课（上吉，90分）

### 定义
占课得胜光为用，并与太冲、神后相遇，就是华盖课。胜光、太冲、神后三神相聚，如同乘坐驷马轩车，高张华盖，所以名为华盖课。

### 核心构成要素
1. **胜光（午）**：为天马
2. **太冲（卯）**：为天驷天车
3. **神后（子）**：为紫微华盖

### 判断条件（关键！）
```
核心条件：
1. 必须是正月或七月
2. 初传为午（胜光）
3. 三传见午、卯、子

【重要说明】
天马查法：正月起午，顺行六阳位
- 六阳位：子、寅、辰、午、申、戌
- 六阴位：丑、卯、巳、未、酉、亥

天马位置：
- 正月：天马在午
- 二月：天马在申
- 三月：天马在戌
- 四月：天马在子
- 五月：天马在寅
- 六月：天马在辰
- 七月：天马在午（循环）

只有正月和七月，天马才在午（胜光）！
午发用在三传中，午为天马，卯为天车，子为华盖
三神相聚，方成华盖乘轩课

三传午卯子：
- 午为胜光，天马（正七月）
- 卯为太冲，天车
- 子为神后，华盖
```

### 特殊情形
1. **胜光作月内天马**：仅正七月内是也（关键条件）
2. **太冲作月内天车**：仅正七月内是也
3. **卯乘天马或龙常**：为华盖轩车之象
4. **日用旺相，又为太岁月将**：德神上乘贵人、龙常后合吉将，当主出入见君

### 吉凶断语
```
象曰："课遇高轩，车马皆全，朱轮稳上，诏用荣宣，
       求财大获，疾病难延，干贵欢会，行者必旋。"

占得华盖课：
- 加官荣显，凡事吉庆
- 招摇过市，车马赫然
- 车马既动，出者必行，闻贼必来
```

### 例外处理
1. 余月轩盖又带三交，出军冲野，决防战斗
2. 论讼换司易衙
3. 病者魂游千里
4. 或年命有龙，出行大雨

### 从属课格及吉凶属性
| 从属格 | 吉凶 | 条件 |
|--------|------|------|
| 轩盖本课 | 上吉 | 正七月午发用，三传午卯子，天马在午 |
| 华盖轩车格 | 上吉 | 卯乘天马或龙常，日用旺相为太岁月将 |
| 三交格 | 凶 | 余月轩盖带三交，出军冲野决防战斗 |
| 乘轩落马格 | 大凶 | 三传带煞乘蛇虎死气克年命日辰，或空亡，或卯作丧车，身弱人衰 |
| 魂游千里格 | 凶 | 占病者魂游千里 |
| 换司易衙格 | 凶 | 论讼换司易衙 |

**乘轩落马格详解**：
- 三传带煞，乘螣蛇、白虎死气
- 克年命、日辰，或空亡
- 或卯作丧车
- 身弱人衰
- 主伤躬被脱，望事无成
- 应升卦上六"冥升，消不富"之凶象

### 对应卦象
对应六十四卦之升卦，统"升"卦之体，是仕子飞黄腾达之课。
- 吉则应初六"允升，大吉"之象
- 凶则应上六"冥升，消不富"之象

## 四、铸印乘轩课（上吉，88分）

### 定义
铸印课指的是戌加巳入传之课。戌是天魁，为印。巳是太乙，为铸炉。戌中辛金与巳中丙火相逢作合，经锻炼而铸成印，故名。

### 核心构成要素
1. **戌（天魁）**：为印
2. **巳（太乙）**：为炉
3. **卯（太冲）**：为车轮、印模

### 判断条件
```
条件：
1. 戌加巳入传（或发用）
2. 三传巳戌卯

巳为炉，戌为印，卯为印模
戌中辛金与巳中丙火作合，锻炼铸成符印
```

### 特殊情形
1. **戊己日**：又为生日之印
2. **遇太常为绶**：乃印绶双全
3. **传见太冲为车轮**：则铸印乘轩之象
4. **乘贵人龙常阴合吉将，日用旺相**：大利

### 吉凶断语
```
象曰："顽金铸篆，藉火功全，官职高擢，诏命重宣，
       产孕大吉，干谒良缘，庶人不吉，疾病官愆。"

占得铸印课：
- 符命入手，官增权柄
- 科举、求官爵、见君王、进策上书，主官爵高迁
- 庶人不吉，反主官灾刑害
```

### 例外处理
1. **春夏巳午日时火旺，戌值空亡、月破，日辰俱无气**：有破印损模之象
2. **遇神将凶**：主先成后破，徒劳心力，事终不济
3. **夏月巳午日时，值蛇雀，火太旺，戌卯或值空亡**：为破印损模，官必不迁
4. **末传得天后、元武，更临水乡，与日相破**：名曰铸印不成

### 从属课格及吉凶属性
| 从属格 | 吉凶 | 条件 |
|--------|------|------|
| 铸印本课 | 上吉 | 戌加巳入传，乘吉将日用旺相 |
| 铸印乘轩格 | 上吉 | 传见太冲为车轮，乘贵人龙常阴合吉将 |
| 印绶双全格 | 上吉 | 戊己日为生日之印，遇太常为绶 |
| 破印损模格 | 凶 | 春夏巳午日时火旺，戌值空亡月破日辰无气 |
| 铸印不成格 | 凶 | 末传得天后玄武临水乡与日相破 |
| 庶人凶格 | 凶 | 常人占得反主官灾刑害 |

**铸印课判断要点**：
- 须得驿马、太阳、六合，乃为真体
- 须有白虎、太阴、螣蛇、朱雀等金火之将入传
- 金少火多，或火少金多，为五行不备，必有所伤
- 惟利官，庶人不吉

### 对应卦象
对应六十四卦之鼎卦，统"鼎"卦之体，是炼药成丹之课。
- 吉则应上九"玉铉大吉"之象
- 凶则应九四"折足，覆公悚，其形渥"之象

## 五、合欢课（上吉，86分）

### 定义
占课得日辰遇天干作合，以及地支三合、六合发用，年命上神乘吉将，为合欢课。日辰年命见合，主和合，合则新，则人欢事成，故名。

### 核心构成要素
1. **天干合**：甲己中正合、乙庚仁义合、丙辛威权合、丁壬淫讹合、戊癸无情合
2. **地支六合**：子丑、寅亥、卯戌、辰酉、巳申、午未
3. **地支三合**：亥卯未、巳酉丑、寅午戌、申子辰

### 判断条件
```
条件（必须同时满足）：
1. 日上神遁干与日干作合
   或干支上神相合
2. 三传发用为三合或六合
3. 占人年命俱乘吉将

天干五合：
甲己合、乙庚合、丙辛合、丁壬合、戊癸合

地支六合：
子丑合、寅亥合、卯戌合、辰酉合、巳申合、午未合

地支三合：
申子辰水局、亥卯未木局、寅午戌火局、巳酉丑金局
```

### 特殊情形
1. **三合**：事关众，克应过月
2. **六合**：阴阳配，夫妇和顺
3. **六处逢吉将，四杀没**：合多吉多，凡事成就
4. **二阴神作合**：求婚独利

### 吉凶断语
```
象曰："乾坤匹配，奇偶交并，占孕迟生，行人荣省，
       名利乔迁，财喜欢称，婚姻天缘，万事佳庆。"

占得合欢课：
- 人情欢悦，相助成事
- 求名干贵皆宜
- 交易婚姻更吉
- 惟孕迟生，病迟愈
```

### 例外处理
1. **合带刑冲破害**：蜜里藏砒，合而藏祸，内吉外凶
2. **合空**：事费力难济
3. **传退连茹，合带暗鬼克日，乘蛇虎雀**：有害，不可意外狂图及托人干事
4. **占病讼忧疑难散**：占失脱，藏匿难获

### 从属课格及吉凶属性
| 从属格 | 吉凶 | 条件 |
|--------|------|------|
| 合欢本课 | 上吉 | 干支相合+三传六合+年命乘吉将 |
| 三合格 | 吉 | 三传三合，事关众，克应过月 |
| 六合格 | 吉 | 六合阴阳配，夫妇和顺 |
| 蜜里藏砒格 | 凶 | 合带刑冲破害，合而藏祸 |
| 合空格 | 凶 | 合逢空亡，事费力难济 |
| 暗鬼克日格 | 凶 | 传退连茹合带暗鬼克日乘蛇虎雀 |

**合欢课判断要点**：
- 六处逢吉将，四杀没，合多吉多，凡事成就
- 二阴神作合，求婚独利
- 占病讼忧疑难散，占失脱藏匿难获

### 对应卦象
对应六十四卦之井卦，统"井"卦之体，是婚姻团圆之课。
- 吉则应上六"井收勿幕，有孚元吉"之象
- 凶则应九二"井谷射鲋"之象

## 六、合美课（上吉，84分）

### 定义
占课得干支遇三合、六合，干支递合或互合，为和美课。合可使人情合悦真美，故名。

### 核心构成要素
1. **干支递合**：日干与支上神作合，日支与干上神作合
2. **干支互合**：日干与干上神作合，日支与支上神作合
3. **三合六合**：干支的上神与三传作三合

### 判断条件
```
条件（满足其一即可）：
1. 日干与支上神作合，日支与干上神作合（递合）
2. 日干与干上神作合，日支与支上神作合（互合）
3. 干支的上神与三传作三合

三六相呼，凡谋皆遂，全无障碍
中有人相助成合，行人喜忻而来
纵为鬼杀，事亦无阻可成
```

### 特殊情形
1. **三传三合，干支上见六合或生日作财**：三六相呼，凡谋皆遂
2. **上下交互相合，交关求财大利**
3. **传遇三合全脱，生干支上财神**：为取还魂债，利取财

### 吉凶断语
```
象曰："三合六合，上下欢悦，交易大通，财利不绝，
       婚吉事成，病危势拙，干贵相宜，占敌和决。"

占得合美课：
- 主客怡顺，办事必成
- 交易大通，财利不绝
- 婚吉事成
- 病危势拙，讼屈难伸
```

### 例外处理
1. **合多吉多，事急成；合少吉少，事迟成**
2. **三六合占解释忧疑及问病凶事，上乘凶将**：凶难散，逢冲可解
3. **合作六害及空亡**：好里朦暗，主合谋事有变换
4. **传逢寅午戌，干支上见午为自刑，丑为六害，子为正冲**：三合犯杀，为蜜中砒
5. **交合逢空**：交时和美，后成画饼
6. **交合盗气**：彼此怀脱
7. **交害**：主客各有嫉妒
8. **交刑**：主合致争竞
9. **交冲**：主先合后难
10. **交克**：主合而争讼，笑里藏刀

### 从属课格及吉凶属性
| 从属格 | 吉凶 | 条件 |
|--------|------|------|
| 合美本课 | 上吉 | 干支递合或互合，三传递相生合 |
| 递生格 | 吉 | 三传递生日干 |
| 取还魂债格 | 吉 | 传遇三合全脱生干支上财神 |

2. **四煞辰戌丑未没四维乾坤艮巽**：大吉，百事无碍，虽凶将无灾

### 吉凶断语
```
象曰："德神在位，诸杀潜藏，囚禁的释，病危无妨，
       婚成佳配，孕产贤郎。凡占谋望，事事吉昌。"

占得德庆课：
- 诸凶都潜藏起来
- 囚禁的人获得释放
- 病危的可转危为安
- 占婚姻可配得佳偶
- 占孕可生产得贤郎
- 各种事情谋望，均可吉昌
```

### 例外处理
1. **带杀乘虎**：不吉
2. **德空**：不吉
3. **神将外战被刑克**：不吉
4. **子日巳德归亥，乘元武夹克**：为减德事参商
5. **乙日申德加酉为用，酉来克乙，申化鬼**：乃君子为小人，四杀不没

**德庆课判断要点**：
- 四煞辰戌丑未没四维乾坤艮巽，大吉，百事无碍，虽凶将无灾

### 对应卦象

- 凶则应九三"致寇至"之象
