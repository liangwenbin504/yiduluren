# 月建应期函数实施报告（2026-08-02）

## 一、原文依据（壬占汇选挖掘）
| 案例 | 原文 | 月建支位置 | 应期 |
|---|---|---|---|
| 0012 | "讼起六月者未为六月建也" | **干上神**未 | 六月 |
| 0019 | "九月成就者归计戌为九月建也" | **末传**戌 | 九月 |
| 0077 | "发用大吉为财，为十二月建" | **初传**丑 | 十二月 |
| 0077 | "未为六月建，故于六月得钱" | **时辰**未 | 六月 |
| 0073 | "法用传送，为七月建" | 三传申 | 七月 |
| 0064 | "丑是十二月建亥是十月建，丑至寅三位，即三日" | 月建位差 | 三日 |

**判定逻辑**：月建支（正月建寅…十二月建丑）出现在课盘关键位（初传/干上神/时辰）→ 应期在该农历月。

## 二、函数实现：`get_yuejian_yingqi_text`
- 位置：`engine/liuren_keti_bifa.py`
- 取位收敛：**初传（发用）+ 日干上神（四课第一课上神）+ 时辰**——原文依据的 3 个关键位，避免全盘支过载
- 映射表：`_YUE_JIAN_MONTH = {寅:1, 卯:2, 辰:3, 巳:4, 午:5, 未:6, 申:7, 酉:8, 戌:9, 亥:10, 子:11, 丑:12}`
- **叙事层，不参与 valence**（应期=何时发生非吉凶方向，铁律）

## 三、验证
- 单元：0012 甲子日亥将午时 → 「初传子=11月建、**干上未=6月建**、时午=5月建」——干上未正是原文"讼起六月"的未 ✓
- **A/B：M3=87.4%（146/167）混淆逐项不变，零回归** ✓
- 端到端：起课页 GET/POST 均输出「月建应期」字段，demo.html 显示行已加

## 四、踩坑记录
1. **si_ke 结构**：`(课名, 上神, 下神, '')`——干上神在**第一课**（不是第四课），初版取错位致干上未丢失，修正后命中
2. **GET/POST 变量名**：月建调用初版误写 `shichen`，GET 分支实际是 `shi_chen` → `NameError` → 500。抓响应体 `{"error": "name 'shichen' is not defined"}` 定位，修正为 `shi_chen`
3. **过载问题**：初版取全部支（三传+四课+时）→ 0012 输出 5 个月，收敛为关键 3 位后正常
