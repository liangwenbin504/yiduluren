## 一、婚姻（3案：§06·122/123/124）

### 深读要点
三案共同结构：**婚必成，然婚后有凶**（先成后败）。
- §122「此课占婚，何必有媒？私情久已通矣……婚姻岂有不成之理？……主暗有退子」——
  后合入传=婚必成；返吟+玄武淫神=私情淫奔，女非贞良，暗有退子。
- §123「上方出墓寻生，其亲必成……但恐不久尊堂服动」——干上墓传中长生=亲必成，
  然中传太常=服动（娶来未十四个月母亡）。
- §124「此课必成，恐成亲后……兼难得子。子作蛇，名退子，纵生子不育」——先成后败。

### 新增/修改规则（engine/liuchen_engine.py 婚姻块）
1. 后合入传（天后+六合并见）→ 婚必成；**若返吟或玄武淫神入传 → 先成后败（凶）**
   出处：§06·122「后合占婚岂用媒……暗有退子」
2. 干上神=日墓 且 传中见长生（出墓寻生）→ 亲必成，**然恐尊堂服动，先成后败（凶）**
   出处：§06·123「上方出墓寻生其亲必成……但恐不久尊堂服动」；L544「自墓传生」

### 专项回测
§122（原判吉✗→现判凶✓）、§123✓、§124✓ = **3/3**。

## 二、求财（14案：§08·132~143 + §10·147/148）

### 深读要点（刘评§134「求财视财爻乃通法常理」）
- §132「日上见财主进田庄……三传全财化为鬼……传财太旺反财亏」（先得后失）
- §133「独足无足，不利陆行，若船行加倍得利」（船行利）
- §134「癸以午为财，又为妻，旬空，故未得」（财空先未得；中传长生再借必得）
- §135「末传逢禄、逢旺，诸事遂意，尽在末也」（转业大发）
- §136「干支上皆盗气，其家世店业十退五六矣」（人宅受脱）
- §137「日上见贵财，支上见财库，日上财神又归财库，此大利」（财入库）
- §139「反吟始可将本求利……讨得此财，下梢必被他扰害」（返吟反复）
- §141「三传虽鬼，只是少阻无妨……必主喜兆，非鬼兆也」（传鬼化财）
- §142「此乃反复争夺之财，甚薄」（返吟财薄，末禄不作吉断）
- §148「三传四课皆阴，岂宜进干？……自宜用旧，未利谋新」（阴课谋旧）

### 新增/修改规则（求财块）
1. 干上神=财爻 且 支上神=日墓（财库）→ 财归财库，得财大利（吉）§137
2. 三传皆鬼 且 干上神=财爻 → 传鬼化财，先难后易终吉 §141
3. 返吟课 → 返吟薄财（凶），**提前于末禄遂意之前**（§142 返吟+末禄仍判凶）§139/142
4. 三传皆阴（丑卯巳未酉亥）→ 宜静谋旧，谋新不利（凶）§148
5. 财爻空亡判据**扩展至支上神**（原仅查三传）——§134「午财旬空故未得」
6. 末禄遂意（§135）置于「三传皆阴」之前（§135 三传皆阴而末禄，邵公仍断「尽在末也」）

### 专项回测
**1/14 → 9/14**。新增命中：§134（求财落空）、§137（财入库吉）、§141（传鬼化财）、
§142（返吟薄财）、§148（宜静谋旧）。

## 三、出行（13案：§11·149~156 + §12·157~161，含行人音信）

### 深读要点
- §149「当主半路归家……中即传宅阴，所以半路归也」（返吟中传归支）
- §150「中传断桥，访之反不得耳」（三合局中传空=断桥）
- §151「甲日火局，十二分盗气，支又来耗我，大有所费……仅与盘缠而归」（盗气局破费）
- §154「日上驿马交驰……主动必远」（返吟驿马交驰）
- §156「中传断桥，又是财库，缘文书次第未备而受阻……在三月子日至也」（断桥而末传旺相=先凶后吉）
- §158「申是岁马带鬼克日……被蒿恼不意而动……充替河州」（初传官鬼临绝=先吉后凶）
- §161「盖昴星课……朱雀临门，主文字立至」（昴星文字即至）

### 新增/修改规则（出行块）
1. 三合局中传空亡（断桥）→ 末传旺相（临官/帝旺）：先凶后吉，终必达（吉）§156；
   否则：访之不得（凶）§150
2. 三合局为日干子孙（盗气局）→ 破费无益，所得微薄（凶）§151
3. 返吟 + 驿马入传 且 中传非日支 → 主动必远，行必成（吉）§154
   （守卫：返吟中传归支=半路归家不作远行之吉 §149）
4. 初传=日干官鬼 且 临绝地 → 音信文字必来，然鬼害来速，先吉后凶（凶）§158
5. 昴星课 → 文字立至，消息速达（吉）§161

### 专项回测
**7/13 → 10/13**。新增命中：§150（访之不得）、§154（主动必远）、§156（先凶后吉）、
§158（先吉后凶）。

## 四、胎产（7案：§07·125~131）

### 深读要点
- §125「干支见酉，皆阳刃破碎自刑……必不利于子母」（羊刃破碎临干支）
- §127「独足……毕竟男胎不成也」（独足课子息难成）
- §129「三传贵人太多，所以贵多不贵……吾兄年三十二上，自有子」（课传贵多=过房子难留）
- §131「支是母兮干是儿……虎乘墓入内门，故母死……日干得旺相之气，故儿存」（末传日墓=母死子存）

### 新增/修改规则（胎产块）
1. 干支上神皆=日干羊刃 → 刃破伤子，产育大凶（凶）§125
2. 末传=日墓 → 母死子存（凶）§131 —— 置于「支上神生日上神=顺产」之前（§131 支上生干上
   但末传墓，邵公断母死，须防误判顺产）
3. 三传独足（同支）→ 独足无子，男胎不成（凶）§127
4. 课传贵人≥3 处 → 贵多不贵，过房子不合留，本命行年自有子（吉）§129

### 专项回测
**3/7 → 6/7**。新增命中：§127（独足无子）、§129（贵多不贵）、§131（母死子存）。
§125 判凶与邵公「必不利于子母」一致，label=平属标注口径（详见冲突表）。
