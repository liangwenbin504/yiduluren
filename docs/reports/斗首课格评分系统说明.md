### 4. 核心功能

#### 新增方法

**第一斗首课格系统** (`douhou_kege_system.py`):
- `get_ke_ge_score(ke_ge_name)` - 获取课格评分
- `is_ke_ge_usable(ke_ge_name)` - 判断课格是否可用
- `get_score_description(score)` - 获取吉凶描述

**二十四山课格系统** (`douhou_shan_jia_system.py`):
- `get_shan_jia_score(shan_jia_name)` - 获取山家评分
- `is_shan_jia_usable(shan_jia_name)` - 判断山家是否可用
- `get_score_description(score)` - 获取吉凶描述

#### 使用示例

```python
from douhou_kege_system import DiYiDouShouKeGe
from douhou_shan_jia_system import DouShouShanJiaKeGe

# 第一斗首课格
kege = DiYiDouShouKeGe()
score = kege.get_ke_ge_score('武财课')  # 9.0
usable = kege.is_ke_ge_usable('贪狼课')  # False

# 二十四山
shanjia = DouShouShanJiaKeGe()
score = shanjia.get_shan_jia_score('子山')  # 8.5
usable = shanjia.is_shan_jia_usable('酉山')  # True
```
