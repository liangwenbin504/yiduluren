# 天地盘北主朝下布局调整说明

## 调整概述

根据传统风水罗盘的视角（从北向南俯视），将天地盘的方位布局从"北上南下"调整为"北下南上"，符合"北主朝下"的传统方位配置。

### 2️⃣ 坐标系统映射

#### 调整前的坐标

```python
# 北上南下（传统地图视角）
dizhi_positions = {
    '子': (center_x, center_y - radius),      # 正北 (上方，y 减小)
    '午': (center_x, center_y + radius),      # 正南 (下方，y 增加)
    '卯': (center_x + radius, center_y),      # 正东 (右方，x 增加)
    '酉': (center_x - radius, center_y),      # 正西 (左方，x 减少)
}
```

#### 调整后的坐标

```python
# 北下南上（风水罗盘视角）
dizhi_positions = {
    '子': (center_x, center_y + radius),      # 正北 (下方，y 增加)
    '午': (center_x, center_y - radius),      # 正南 (上方，y 减小)
    '卯': (center_x + radius, center_y),      # 正东 (右方，x 增加)
    '酉': (center_x - radius, center_y),      # 正西 (左方，x 减少)
}
```

**关键变化**：
- 子（北）：`y - radius` → `y + radius`（从上移到下）
- 午（南）：`y + radius` → `y - radius`（从下移到上）
- 卯（东）：保持不变（右方）
- 酉（西）：保持不变（左方）

## 🎯 技术实现

### 核心代码修改

**文件**：`天地盘.py` 第 1387-1462 行

**修改内容**：

```python
def _draw_dizhi_layout(self, tiandi_pan):
    """绘制地盘十二地支方位图（北主朝下布局）"""
    canvas = self.dizhi_canvas
    canvas.delete("all")
    
    center_x, center_y = 200, 200
    radius = 150
    
    # 北主朝下布局
    dizhi_positions = {
        '子': (center_x, center_y + radius),      # 正北 (下方)
        '丑': (center_x + radius*0.5, center_y + radius*0.866),  # 东北 (右下)
        '寅': (center_x + radius*0.866, center_y + radius*0.5),  # 东北 (右下)
        '卯': (center_x + radius, center_y),      # 正东 (右方)
        '辰': (center_x + radius*0.866, center_y - radius*0.5),  # 东南 (右上)
        '巳': (center_x + radius*0.5, center_y - radius*0.866),  # 东南 (右上)
        '午': (center_x, center_y - radius),      # 正南 (上方)
        '未': (center_x - radius*0.5, center_y - radius*0.866),  # 西南 (左上)
        '申': (center_x - radius*0.866, center_y - radius*0.5),  # 西南 (左上)
        '酉': (center_x - radius, center_y),      # 正西 (左方)
        '戌': (center_x - radius*0.866, center_y + radius*0.5),  # 西北 (左下)
        '亥': (center_x - radius*0.5, center_y + radius*0.866)   # 西北 (左下)
    }
    
    # 方位标签（北在下）
    canvas.create_text(center_x, center_y + radius + 35, text="北", ...)
    canvas.create_text(center_x, center_y - radius - 35, text="南", ...)
    canvas.create_text(center_x - radius - 35, center_y, text="西", ...)
    canvas.create_text(center_x + radius + 35, center_y, text="东", ...)
    
    # 中心说明
    canvas.create_text(center_x, center_y, 
                      text="地盘\n固定\n(北下南上)", ...)
```

## 📐 坐标计算原理

### 三角函数计算

十二地支的位置使用三角函数计算：

```python
# 角度转换（从北开始，顺时针）
角度 = 地支序号 * 30°

# 坐标计算
x = center_x + radius * sin(角度)
y = center_y + radius * cos(角度)

# 北下南上布局（y 轴翻转）
x = center_x + radius * sin(角度)
y = center_y - radius * cos(角度)
```

### 简化计算

使用固定系数简化计算：

```python
# 关键角度的 sin/cos 值
0°:   sin=0,      cos=1
30°:  sin=0.5,    cos=0.866
60°:  sin=0.866,  cos=0.5
90°:  sin=1,      cos=0
```

## 💡 使用说明

### 为什么使用北下南上布局？

**传统依据**：
1. **风水罗盘视角**：从北向南俯视
2. **古代方位观**：面南而治，北在身后（下方）
3. **大六壬传统**：天地盘多用北下南上

**实际优势**：
1. **符合传统**：与传统罗盘一致
2. **便于对比**：与实地风水对应
3. **易于理解**：符合"上南下北"的古代方位观

### 如何使用

1. **进行择日计算**
2. **双击日期打开排盘**
3. **点击"天地盘"选项卡**
4. **查看地盘方位图**
   - 北方在下方
   - 南方在上方
   - 东方在右方
   - 西方在左方
