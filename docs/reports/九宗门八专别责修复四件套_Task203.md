## 0. TL;DR

权威引擎 `engine/sike_sanchuan_engine.py`（V2，`SiKeSanChuanCalculator2`）存在 **三类已印证 BUG**，均使八专宗门失效或产生非法三传：

1. **八专被别责吞没（分类互斥缺失）**：`_is_bie_ze` 把"任意两课相同"判为别责，而八专日（干支同位）四课恰仅两课，被一并误判。叠加 `_decide_method` 把别责（L1419）放在八专（L1425）之前 → **八专法在全 8640 课中命中 = 0（死代码）**。
2. **八专三传中末写错（规则错误）**：`_ba_zhuan_fa` 三传中末写成 `日支上神`，五处独立权威源一致印证应为 **日干上神**（"中末总向日上眠"）。
3. **八专+反吟退化分支（非法空三传）**：`_fan_yin_fa` 内含一段针对 丁未/己未（八专+反吟）的退化分支，直接返回**空三传**（`{'初传':'','中传':'','末传':''}`）并打标 `起法='反吟法（错误：应为八专课）'`。该分支既产出非法空传，又把 24 个八专+反吟课踢出正常反吟归类。Fix C 删除此分支，使八专+反吟正常流入反吟法。

修复后（Fix A+B+C 已落码）：八专法 **0 → 108**、别责法 **264 → 132**、反吟法 **24 → 48**；总数仍 8640、0 错误、0 未分类、数学约束不被破坏。

> ⚠️ 相邻问题（**均已由 Task #3/#4（2026-08-01）修复并验证**）：① 遥克/八专顺序（实际 0 影响）；② 反吟/别责顺序（原 `SiKeSanChuanCalculator2._decide_method` 把别责置于反吟前，24 个反吟+不备错归别责——曾误判为"非 BUG"，实为真 BUG，已重排反吟先于别责）；③ **别责三传规则与古籍不符**（课位置法 vs 干合/支三合，且 §1.5「己寄宫丑」为笔误，正确为「己寄宫未」）—— 已重写 `_bie_ze_fa`。改动后诚实基线 84.8%→87.2%。详见 `docs/reports/九宗门反吟别责顺序与别责三传修复_Task3_4.md`。

### 1.2 八专日范围（干支同位，仅五日）
- 本地 PDF p130 白话提要："干支同位，只有二课，例如**甲寅**日干支同寅，**庚申**日干支同申，**癸丑**日干支同丑，**丁未**、**己未**日干支同未。" → 五日确认。

### 1.3 八专三传细则（Fix B 的印证——中末=日干上神）

### 1.4 八专与遥克/贼克的优先级（顺序印证）
