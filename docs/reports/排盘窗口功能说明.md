# 大六壬排盘窗口功能说明

## 功能概述

现在您可以点击择日结果列表中的任意日期，系统会自动打开大六壬排盘窗口，显示该日期的详细排盘信息，包括四课、三传、天地盘等。

---

## 使用方法

### 步骤 1：进行择日计算

1. 选择山向（如壬山丙向）
2. 设置日期范围
3. 设置筛选条件
4. 点击"开始择日"

### 步骤 2：选择日期并查看排盘

**方式一：双击日期**
- 在结果列表中双击任意日期
- 自动打开排盘窗口

**方式二：选中后点击菜单**
- 单击选中一个日期
- 点击菜单"工具" → "大六壬排盘"
- 或直接点击工具栏的排盘按钮

### 选项卡说明

#### 1️⃣ 基本信息

显示该日期的完整信息：
- **日期时间**：公历日期、星期、时辰
- **四柱**：年柱、月柱、日柱、时柱
- **大六壬参数**：
  - 月将：根据月份计算
  - 占时：时辰地支
  - 日干支：日柱干支
  - 旬首：根据日柱计算
- **课格信息**：
  - 课体：匹配的六壬课体
  - 评分：六壬评分、斗首评分、综合评分
- **特殊课格**：如龙德课等

#### 2️⃣ 四课

显示四课信息：
```
【四课】
━━━━━━━━━━━━━━━━━━━━━━━━

第 1 课：子 / 戊
第 2 课：卯 / 子
第 3 课：午 / 卯
第 4 课：酉 / 午
```

四课含义：
- **第一课**：日干上神（干阳）
- **第二课**：日支上神（支阳）
- **第三课**：干阴神
- **第四课**：支阴神

#### 3️⃣ 三传

显示三传信息：
```
【三传】
━━━━━━━━━━━━━━━━━━━━━━━━

━━━━━━━━━━━━━━━━━━━━━━━━
```

三传含义：
- **初传**：事情的开始
- **中传**：事情的发展
- **末传**：事情的结果

#### 4️⃣ 天地盘

显示天地盘对应关系：
```
【天地盘】
━━━━━━━━━━━━━━━━━━━━━━━━

地盘    天盘
子   →  亥
丑   →  子
寅   →  丑
卯   →  寅
...
```

天地盘含义：
- **地盘**：固定的十二地支方位
- **天盘**：月将加时后形成的动态盘

## 使用场景

### 场景 1：择日后查看详细排盘

1. 进行择日计算
2. 在结果列表中双击最佳日期
3. 查看该日期的完整排盘
4. 分析四课三传吉凶

### 场景 2：对比多个日期

1. 依次双击不同日期
2. 每个日期打开独立的排盘窗口
3. 并排对比分析
4. 选择最优日期

### 场景 3：保存排盘结果

1. 打开排盘窗口
2. 复制文本内容
3. 粘贴到文档中保存
4. 或截图保存

---

## 注意事项

### 1. 计算准确性

- 四课三传计算基于传统方法
- 月将按照节气计算
- 占时使用真太阳时

### 2. 窗口管理

- 每个日期打开独立窗口
- 可以同时打开多个窗口进行对比
- 点击"关闭"按钮关闭窗口

### 3. 数据完整性

- 排盘数据来自择日结果
- 确保先进行择日计算
- 选中有效日期后再查看

## 快捷操作

### 键盘快捷键

- **双击**：打开排盘窗口

- **工具** → **大六壬排盘**：打开选中日期的排盘

## 常见问题

### Q1: 为什么四课显示为空？

A: 可能是计算过程中出现错误，请检查：
- 日期是否有效
- 控制台是否有错误信息
- 重新进行择日计算

### Q2: 三传为什么只有初传？

A: 当前版本简化计算，后续会完善中传和末传的计算。

### Q3: 可以同时打开多个排盘窗口吗？

A: 可以，每个日期打开独立窗口，方便对比分析。

### Q4: 排盘窗口可以调整大小吗？

A: 可以，拖动窗口边缘即可调整大小。
