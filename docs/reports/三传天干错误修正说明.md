# 三传天干计算错误修正

## ❌ 问题描述

在 `daliuren_full_chart.py` 文件中，三传天干计算错误地使用了**五鼠遁元法**（日上起时法），导致甲申日的三传天干显示为**戊己庚**，这是完全错误的。

### 错误表现

**甲申日，三传辰巳午：**
- ❌ 错误显示：戊辰、己巳、庚午
- ✅ 正确应该：壬辰、癸巳、甲午

## 🔍 错误原因

### 错误代码位置

文件：`src/utils/daliuren_full_chart.py` 第 626-696 行

```python
# ❌ 错误的五鼠遁元法
tian_gan_xun_yuan = {
    '甲': ['甲', '乙', '丙', '丁', '戊', '己', '庚', '辛', '壬', '癸'],
    '己': ['甲', '乙', '丙', '丁', '戊', '己', '庚', '辛', '壬', '癸'],
    ...
}

# 计算天干（根据五鼠遁元，天干循环使用）
zhi_index = dizhi_order.get(zhi, 0)
tian_gan = ri_gan_sequence[zhi_index % 10]  # 10 天干循环
```

### 错误原理

**五鼠遁元法（日上起时法）**是用于计算**时柱天干**的方法，口诀：
```
甲己还加甲（甲己日起甲子时）
乙庚丙作初（乙庚日起丙子时）
丙辛从戊起（丙辛日起戊子时）
丁壬庚子居（丁壬日起庚子时）
戊癸何方发，壬子是真途（戊癸日起壬子时）
```

这种方法从子位开始排天干，会导致：
- 子 (甲)、丑 (乙)、寅 (丙)、卯 (丁)、**辰 (戊)**、**巳 (己)**、**午 (庚)**

这是**完全错误**的！

## ✅ 正确方法：旬遁法

### 旬遁法规则

三传天干应该使用**旬遁法**计算，规则：

1. **确定旬首**：根据日干支确定所属的旬
2. **旬首遁甲**：旬首地支遁"甲"
3. **顺排天干**：从旬首开始，按天干顺序顺排到各地支

### 甲申旬遁干排布

```
甲申旬，旬首甲申：
申 (甲)、酉 (乙)、戌 (丙)、亥 (丁)、子 (戊)、丑 (己)、
寅 (庚)、卯 (辛)、辰 (壬)、巳 (癸)、午 (甲)、未 (乙)
```

**正确的三传天干：**
- 初传：**壬辰** ✓
- 中传：**癸巳** ✓
- 末传：**甲午** ✓

### 1. 添加旬遁法函数

在 `daliuren_full_chart.py` 文件开头添加：

```python
def get_xun_shou(ri_gan: str, ri_zhi: str) -> tuple:
    """
    计算日干支的旬首和空亡（旬遁法）
    
    :param ri_gan: 日干
    :param ri_zhi: 日支
    :return: (旬首天干，旬首地支，空亡地支列表)
    """
    stems = ['甲', '乙', '丙', '丁', '戊', '己', '庚', '辛', '壬', '癸']
    branches = ['子', '丑', '寅', '卯', '辰', '巳', '午', '未', '申', '酉', '戌', '亥']
    
    gan_index = stems.index(ri_gan)
    zhi_index = branches.index(ri_zhi)
    
    # 60 甲子序号计算
    ganzhi_index = (gan_index * 6 - zhi_index * 5) % 60
    if ganzhi_index < 0:
        ganzhi_index += 60
    
    # 旬首序号 = 60 甲子序号 // 10 × 10
    xun_shou_index = (ganzhi_index // 10) * 10
    
    # 旬首天干总是甲
    xun_shou_gan = '甲'
    
    # 旬首地支 = 旬首序号 % 12
    xun_shou_zhi = branches[xun_shou_index % 12]
    
    # 计算空亡
    kong_wang_index1 = (xun_shou_index % 12 + 10) % 12
    kong_wang_index2 = (xun_shou_index % 12 + 11) % 12
    kong_wang = [branches[kong_wang_index1], branches[kong_wang_index2]]
    
    return xun_shou_gan, xun_shou_zhi, kong_wang


def get_stem_for_branch(branch: str, ri_gan: str, ri_zhi: str) -> str:
    """
    根据日干支计算地支的遁干（旬遁法）
    
    :param branch: 地支
    :param ri_gan: 日干
    :param ri_zhi: 日支
    :return: 遁干
    """
    stems = ['甲', '乙', '丙', '丁', '戊', '己', '庚', '辛', '壬', '癸']
    branches = ['子', '丑', '寅', '卯', '辰', '巳', '午', '未', '申', '酉', '戌', '亥']
    
    # 获取旬首
    xun_shou_gan, xun_shou_zhi, _ = get_xun_shou(ri_gan, ri_zhi)
    
    # 旬首地支的索引
    xun_index = branches.index(xun_shou_zhi)
    
    # 目标地支的索引
    branch_index = branches.index(branch)
    
    # 计算从旬首到目标地支的距离
    distance = (branch_index - xun_index) % 12
    
    # 遁干按天干顺序循环
    stem_index = distance % 10
    
    return stems[stem_index]
```

## 📝 技术说明

### 60 甲子序号公式

```
序号 = (天干索引 × 6 - 地支索引 × 5) % 60
```

**原理：**
- 天干 10 个，地支 12 个
- 最小公倍数 60，形成 60 甲子循环
- 天干索引×6 和地支索引×5 的组合唯一确定位置

### 旬遁 vs 五子遁

| 方法 | 用途 | 起例 | 应用 |
|------|------|------|------|
| **旬遁法** | 三传天干 | 旬首遁甲，顺排 | 六壬排盘 ✓ |
| **五子遁** | 时柱天干 | 甲己还加甲 | 四柱八字 |

**重要：** 两种方法不能混用！
