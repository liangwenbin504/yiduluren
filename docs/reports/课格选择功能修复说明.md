# 课格选择功能修复说明

## 问题描述

用户反馈：勾选"龙德课"复选框后，点击"开始择日"按钮，系统提示"请至少选择一种课格类型"，但界面显示"已选：0/13"。

## 问题分析

经过分析，可能存在以下问题：

1. **复选框状态未正确同步**：复选框的勾选状态没有正确传递到 `selected_kege_types` 集合
2. **闭包问题**：lambda 函数可能导致所有复选框引用同一个变量
3. **视觉反馈不明显**：复选框太小或颜色问题导致看不清是否勾选

## 修复措施

### 1. 修复 lambda 闭包问题
```python
# 修复前
command=lambda k=kege: self._toggle_kege(k, var)

# 修复后
command=lambda k=kege, v=var: self._toggle_kege(k, v)
```

### 2. 改进复选框样式
```python
# 增加间距，使复选框更清晰
chk.grid(row=row_idx, column=col_idx, padx=15, pady=8, sticky=tk.W)

# 添加焦点支持
takefocus=True
```

### 3. 增强调试信息
```python
def _toggle_kege(self, kege, var):
    """切换课格选择状态"""
    # 获取当前复选框状态
    is_checked = var.get()
    
    if is_checked:
        self.selected_kege_types.add(kege)
    else:
        self.selected_kege_types.discard(kege)
    
    # 更新标签显示
    count = len(self.selected_kege_types)
    self.selected_kege_label.config(text=f"已选：{count}/{len(self.KE_GE_TYPES)}")
```

## 常见错误排查

### 问题 1：勾选后"已选"标签不更新
**原因**：`_toggle_kege` 方法未被调用
**解决**：检查复选框的 `command` 参数是否正确

### 问题 2：点击"开始择日"仍提示未选择
**原因**：`selected_kege_types` 集合为空
**解决**：检查复选框状态是否同步到集合

### 问题 3：复选框看起来没有勾选
**原因**：样式问题或视觉反馈不明显
**解决**：增加复选框间距，使用更清晰的样式
