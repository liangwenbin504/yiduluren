# 仪度六壬综合系统 - 更新说明

## 更新日期：2026-03-15

### 🎯 本次更新内容

#### 1. 四柱显示功能（年月日时天干地支）

**新增功能**：
- 在 GUI 界面中增加"四柱信息"显示区域
- 实时显示选定日期的年柱、月柱、日柱、时柱
- 天干地支完整显示

**显示位置**：
```
【四柱信息（年月日时）】
年柱    月柱    日柱    时柱
甲乙    丙丁    戊己    庚辛
子丑    寅卯    辰巳    午未
```

**计算方法**：
- 年柱：以立春为界（简化处理）
- 月柱：五虎遁年起月法
- 日柱：查表法（简化算法）
- 时柱：五鼠遁日起时法

#### 2. 六壬排盘功能

**新增功能**：
- 完整的天盘显示
- 四课信息显示
- 月将、占时显示

**排盘内容**：
```
============================================================
日期：2026-03-18 23:00
四柱：丙午 辛卯 壬申 庚子
============================================================

【天盘】
月将：亥  占时：子

      巳    午    未    申
      戌    亥    子    丑
辰 酉                  酉 寅
卯 申                  戌 丑
寅 未    丑    子    亥    酉 子
      午    巳    辰    卯

【四课】
  第 1 课：壬（上） / 丁（下）
  第 2 课：子（上） / 壬（下）
  第 3 课：酉（上） / 壬（下）
  第 4 课：午（上） / 酉（下）

============================================================
```

**排盘步骤**：
1. 根据日期计算四柱
2. 根据月份确定月将
3. 月将加时排天盘
4. 根据日干支起四课

#### 3. 自动显示功能

**触发时机**：
- 当用户点击"【第四步】开始择日"后
- 系统找到最佳匹配日期时
- 自动显示该日期的四柱和六壬排盘

**显示内容**：
- 四柱：年月日时的天干地支
- 六壬排盘：天盘、四课
- 时辰：默认为子时（23-1 点）

### 🔧 技术实现

#### 四柱计算模块
- **文件**：`src/ui/comprehensive_gui.py`
- **方法**：`calculate_sizhu()`
- **功能**：根据日期计算四柱天干地支

#### 六壬排盘模块
- **文件**：`src/utils/yiduluren_paipan.py`
- **类**：`YiDuLiuRenPaiPan`
- **功能**：排天盘、贵人盘

- **文件**：`src/engine/daliuren_engine.py`
- **类**：`DaLiuRenEngine`
- **功能**：排四课、三传

#### 显示控制
- **方法**：
  - `display_sizhu()` - 显示四柱
  - `display_daliuren_paipan()` - 显示六壬排盘

### ⚠️ 注意事项

#### 四柱计算说明
1. **年柱**：简化处理，未精确到立春时刻
2. **月柱**：按农历月份计算，未考虑节气深浅
3. **日柱**：使用简化算法，精确计算需查万年历
4. **时柱**：五鼠遁起时，子时为 23-1 点

#### 六壬排盘说明
1. **月将**：按农历月份简化确定
2. **天盘**：月将加时，顺布十二宫
3. **四课**：从日干支起课
4. **三传**：暂未显示（可在后续版本添加）

#### 核对建议
1. **四柱核对**：
   - 使用万年历验证年月日时
   - 特别注意节气交接日
   - 时辰按 2 小时一个单位

2. **六壬排盘核对**：
   - 验证月将是否正确
   - 检查天盘排布
   - 核对四课起法
   - 建议使用专业软件对比
