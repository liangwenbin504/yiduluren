# 大六壬64课经课体课格判断依据审核报告（修订版）

## 重要说明

本报告所有判断依据均来自《六壬大全》《六壬指南》等古籍原文，不做任何臆造。

---

## 一、殃咎课判断依据

### 1. 古籍原文

**《六壬大全》原文**：
> "凡三传递克日，神将克战，或干支乘墓，为殃咎课。如己巳日，三传巳申寅，初传克中，中克末传，末克日干。如丙子日，三传子未寅，末传克中传，中传克初传，初传克日干，为递克。主他人欺凌，互相克害。为官宜自简束，防人论劾。常人有凶横之祸，或被邻人雷状攻讼。"

### 2. 判断条件

殃咎课有五种情况：

| 序号 | 类型 | 判断条件 | 古籍原文 |
|------|------|----------|----------|
| 1 | 递克 | 初克中、中克末、末克干；或末克中、中克初、初克干 | "递克者，初克中、中克末、末克干；又末克中、中克初、初克干是也" |
| 2 | 夹克 | 用神下既坐克，上又受将克 | "夹克者，用神下既坐克，上又受将克，如午加亥，将乘元武是也" |
| 3 | 外战 | 三传皆将克神 | "外战者，三传皆将克神" |
| 4 | 内战 | 三传皆神克将 | "内战者，三传皆神克将" |
| 5 | 乘墓/坐墓 | 干支上神各乘墓神，或干支下神各临墓神 | "乘墓者，干上支上各乘墓神。如丙寅日丙上戌、寅上未是也。坐墓者，干下支下各临墓神" |

### 3. 具体课例

**古籍课例**：
- 己巳日：三传巳申寅，初传克中传，中传克末传，末传克日干
- 丙子日：三传子未寅，末传克中传，中传克初传，初传克日干
- 辛酉日：三传未子巳，初传至末传递克日干

### 4. 判断结论

**殃咎课与二十八星宿无关！**

殃咎课的判断依据是：
1. 三传递克日干
2. 神将内外克战
3. 干支乘墓或坐墓

这些条件均不涉及二十八星宿。

## 二、二烦课判断依据（与二十八星宿相关）

### 1. 古籍原文

**《六壬大全》原文**：
> "凡四仲月将遇四正及四平日占，得日月宿加四仲，斗罡系丑未，为二烦课。四仲者，子午卯酉也。日宿者，太阳躔度宫神也，正月起亥，逆行十二辰。月宿者，太阴星躔度宫神也。正月初一起室，二奎、三胃、四毕、五参、六鬼、七张、八角、九氐、十尾、十一斗、十二虚。每月初一移一宿，逐日数二十八宿，遇奎、张、井、翼、氐、斗宿，重算留一，数尽月宿住处为太阴所在宫神。"

### 2. 二十八星宿与十二辰对应

**古籍原文**：
> "月宿所属十二辰：辰角亢，卯氐房心，寅尾箕，丑斗牛，子女虚危，亥室壁，戌奎娄，酉胃昴毕，申觜参，未井鬼，午柳星张，巳翼轸。"

| 地支 | 对应星宿 |
|------|----------|
| 子 | 女、虚、危 |
| 丑 | 斗、牛 |
| 寅 | 尾、箕 |
| 卯 | 氐、房、心 |
| 辰 | 角、亢 |
| 巳 | 翼、轸 |
| 午 | 柳、星、张 |
| 未 | 井、鬼 |
| 申 | 觜、参 |
| 酉 | 胃、昴、毕 |
| 戌 | 奎、娄 |
| 亥 | 室、壁 |

### 3. 月宿起法（二十八星宿推算）

**古籍原文**：
> "正室二奎三在胃，四毕五参六鬼期，七张八角九月氐，十心一斗十二虚。"

每月初一起始星宿：
| 月份 | 初一起始星宿 | 所在地支 |
|------|--------------|----------|
| 正月 | 室 | 亥 |
| 二月 | 奎 | 戌 |
| 三月 | 胃 | 酉 |
| 四月 | 毕 | 酉 |
| 五月 | 参 | 申 |
| 六月 | 鬼 | 未 |
| 七月 | 张 | 午 |
| 八月 | 角 | 辰 |
| 九月 | 氐 | 卯 |
| 十月 | 心 | 卯 |
| 十一月 | 斗 | 丑 |
| 十二月 | 虚 | 子 |

### 4. 重留规则

**古籍原文**：
> "每日一宿，遇奎、张、井、翼、氐、斗，重留一日"

遇到以下六宿时，需停留一日：
- 奎宿（戌宫）
- 张宿（午宫）
- 井宿（未宫）
- 翼宿（巳宫）
- 氐宿（卯宫）
- 斗宿（丑宫）

### 5. 二烦课完整判断条件

**必须同时满足以下条件**：

| 条件 | 说明 | 古籍原文 |
|------|------|----------|
| 条件一 | 四仲月将或四正日、四平日占 | "四仲月将遇四正及四平日占" |
| 条件二 | 日宿或月宿临四仲（子午卯酉） | "得日月宿加四仲" |
| 条件三 | 斗罡（辰）临丑或未 | "斗罡系丑未" |

### 6. 天烦与地烦的区别

| 类型 | 条件 | 主事 |
|------|------|------|
| 天烦 | 日宿临四仲 + 斗系丑未 | 男子犯法、刑戮 |
| 地烦 | 月宿临四仲 + 斗系丑未 | 女子受灾、产难 |
| 二烦 | 天烦 + 地烦同时出现 | 男女俱有患 |

### 7. 具体判断示例

**古籍原文示例**：
> "如九月初三丙午日午时卯将占，寅命，行年在午。月将为日宿，躔氐二度。月宿躔氐五度。太阳太阴俱值卯宫加午为仲。辰为斗罡临未，二并为天地烦，曰二烦课也。"

**判断步骤**：
1. 确定日宿位置：月将（卯将）= 日宿所在宫位
2. 确定月宿位置：从正月初一起室，逐日数至占日
3. 检查日宿/月宿是否临四仲（子午卯酉）
4. 检查斗罡（辰）是否临丑或未
5. 同时满足则为二烦课

### 8. 杜传格

**古籍原文**：
> "斗不系丑未者，名杜传课，四位俱闭，三光不明，德气在内，刑气在外，利于居家，不可远行。"

如果日宿/月宿临四仲，但斗罡不临丑未，则为杜传格，凶性减轻。

## 三、昴星课与二十八星宿

### 1. 古籍原文

**《六壬大全》原文**：
> "酉中有昴星宿，属于秋分，是天地关梁的枢纽，是日月出入的门户。酉属于西方白虎，五行中的金位，性主肃杀，义主决断，取以为用，所以称其为昴星课。"

### 2. 昴星宿说明

**古籍原文**：
> "昴星为二十八宿星宿名，全名昴日鸡，分野在正西方。"

昴星宿位于酉宫，是二十八宿之一。

### 3. 昴星课判断条件

| 类型 | 条件 | 古籍原文 |
|------|------|----------|
| 虎视转蓬格 | 刚日四课无克无遥克，取酉宫上神为用 | "刚日四课无上下克，又无遥克，取酉宫上神为用" |
| 冬蛇掩目格 | 柔日四课无克无遥克，取酉下神为用 | "柔日四课无克，又无遥克，取酉下神为用" |

### 4. 与星宿的关系

昴星课取酉宫为用，是因为：
- 酉中有昴星宿
- 昴星宿属秋分，是天地关梁枢纽
- 昴星宿主肃杀、决断

---

## 四、其他与星宿相关的课体

### 1. 房星、心星（明堂星宿）

**古籍原文**：
> "午为离明，卯为天驷，房星、心星是明堂的星宿。即使遇衰败、凶神，也是主吉利之兆。"

**应用**：
- 昴星课中，若午加卯发用，为明堂格，主万事昌隆
- 房星、心星位于卯宫

## 五、判断依据审核总结

### 5.1 与二十八星宿直接相关的课体

| 课体 | 关系说明 | 判断要点 |
|------|----------|----------|
| **二烦课** | 日宿、月宿临四仲 | 需计算二十八星宿位置，确定日宿月宿所在宫位 |
| **昴星课** | 取酉宫昴星宿为用 | 酉宫含昴星宿，主决断 |

### 5.2 与二十八星宿无关的课体

| 课体 | 判断依据 |
|------|----------|
| **殃咎课** | 三传递克、神将克战、干支乘墓坐墓 |
| 九丑课 | 九丑日+丑临四仲发用 |
| 天祸课 | 四立日干支临绝神干支 |

### 5.3 重要纠正

**错误认知**：殃咎课与二十八星宿有关

**正确认知**：
- 殃咎课与二十八星宿**无关**
- **二烦课**才是与二十八星宿直接相关的课体
- 二烦课需要计算日宿（太阳躔度）和月宿（太阴躔度）的位置

## 六、二烦课完整推算方法

### 6.1 日宿推算

**古籍原文**：
> "日宿者，太阳躔度宫神也，正月起亥，逆行十二辰。"

日宿即月将，推算方法：

| 正月 | 亥 |

| 三月 | 酉 |
| 四月 | 申 |

| 八月 | 辰 |

| 十一月 | 丑 |
| 十二月 | 子 |

### 6.2 月宿推算（二十八星宿）

**步骤**：
1. 确定当月初一起始星宿
2. 从初一起，每日移一宿
3. 遇奎、张、井、翼、氐、斗六宿，重留一日
4. 数至占日，即为月宿所在

**示例**（古籍原文）：
> "假令正月初一日起室，二日壁，三日四日俱奎，五日胃、六日昴、七日毕、八觜、九参，初十日十一日俱井，十二鬼、十三柳、十四星、十五张"

正月初一至十五月宿推算：

|------|------|------|
| 初一 | 室 | 正月起室 |
| 初二 | 壁 | |
| 初三 | 奎 | 重留 |
| 初四 | 奎 | 奎宿重留一日 |
| 初五 | 胃 | |
| 初六 | 昴 | |
| 初七 | 毕 | |
| 初八 | 觜 | |
| 初九 | 参 | |
| 初十 | 井 | 重留 |
| 十一 | 井 | 井宿重留一日 |
| 十二 | 鬼 | |
| 十三 | 柳 | |
| 十四 | 星 | |
| 十五 | 张 | 重留 |

### 6.3 判断日宿/月宿是否临四仲

四仲 = 子、午、卯、酉

检查日宿或月宿所在地支是否为四仲之一。

## 七、结论

1. **殃咎课**：判断依据为三传递克、神将克战、干支乘墓坐墓，**与二十八星宿无关**

2. **二烦课**：判断依据为日宿/月宿临四仲 + 斗罡临丑未，**必须计算二十八星宿位置**

3. **昴星课**：取酉宫（含昴星宿）为用，与二十八星宿有间接关系

4. 所有判断依据均来自《六壬大全》《六壬指南》古籍原文，未做任何臆造
