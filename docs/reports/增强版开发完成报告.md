## 使用说明

### 启动方法

**方法一：批处理文件**
```
双击 start_enhanced_gui.bat
```

**方法二：命令行**
```bash
cd d:\新建文件夹\仪度六壬择日\yiduluren
python enhanced_date_selector_gui.py
```

### 操作流程

1. **选择山向**
   - 点击二十四山按钮选择坐山
   - 朝向自动匹配，也可手动调整
   - 查看山向信息面板

2. **选择日期范围**
   - 输入开始和结束日期
   - 或使用快捷按钮
   - 查看日期范围验证

3. **选择课格类型**
   - 勾选需要的课格（可多选）
   - 使用快捷按钮快速选择
   - 查看已选数量

4. **设置筛选条件**
   - 选择斗首课格
   - 设置最低评分
   - 勾选仅龙德课（可选）

5. **开始择日**
   - 点击"开始择日"
   - 查看进度条
   - 等待计算完成

6. **查看结果**
   - 浏览结果表格
   - 双击查看详细信息
   - 切换选项卡查看详情

7. **导出保存**
   - 导出结果为 TXT
   - 保存配置为 JSON
   - 加载已有配置
