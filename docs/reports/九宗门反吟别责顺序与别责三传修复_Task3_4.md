### #3 古籍依据（反吟须先于别责）
- 反吟 = 天地盘相冲（月将+6=占时），是**比四课不备更强的结构态**；伏吟/反吟 由天地盘直接判定，**不依赖四课是否全备**。
- 标准九宗门应用：先判天地盘（伏吟→反吟），再判四课克贼/遥克，最后才轮到「不备→别责」「干支同位→八专」「四课全→昴星」。
- 故「反吟+不备」课（天地盘冲 + 四课有两课相同）应归入**反吟法**（无克无遥时走井栏射格/驿马），**不应**先于反吟被别责吞。
- 交叉印证（程序化诊断 `docs/reports/_diag_fanyin_bieze.py`）：以 丁丑 反吟 为例，旧代码给出 初传未/中传丑/末传未（别责课位置法），而 `_fan_yin_fa` 直接调用给出 初传亥/中传未/末传丑（反吟法·井栏格·驿马在亥）——后者为古籍正例。

### #4 古籍依据（别责三传规则）
- **阳日（刚日）**：初传 = 天干五合之神的上神。日干合化之干 → 取该干**寄宫**地支的天盘上神。
  - 甲合己→未、乙合庚→申、丙合辛→戌、丁合壬→亥、戊合癸→丑、己合甲→寅、庚合乙→辰、辛合丙→巳、壬合丁→未、癸合戊→巳。
  - 中末 = 日干上神（日干寄宫的天盘）。
- **阴日（柔日）**：初传 = 日支三合局**生支**的上神（申子辰→申 / 寅午戌→寅 / 巳酉丑→巳 / 亥卯未→亥，与日支在局中第几支无关）。
  - 中末 = 日干上神。
- 歌诀印证（五源一致）：「刚日干合上头神，柔日支前三合取；皆以天上作初传，阴阳中末干中寄。」
- **寄宫纠错**：干合 partner 寄宫须用本引擎标准 `TIAN_GAN_JI_GONG`（己→未，非丑）。Task #203 文档 §1.5 末句「甲己→己寄宫丑上神」为笔误，已更正为「己寄宫未上神」。

        # 4. 无克贼无遥克 → 反吟优先于别责

### Fix #4 — `_bie_ze_fa` 重写（干合/支三合）
位置：`engine/sike_sanchuan_engine.py` `SiKeSanChuanCalculator2._bie_ze_fa`（原 L868-929 课位置法整体替换）。

```python
    def _bie_ze_fa(self, ri_gan, ri_zhi, tiandi_pan, sike=None):
        """别责法 —【Task #4 修订】据《六壬大全》别责门(p~128-129)正例。
        阳日：初传=天干五合之神的上神(干合partner寄宫的天盘)；
        阴日：初传=日支三合局生支的上神；中末：皆日干上神。"""
        GAN_HE_JI_GONG = {  # ri_gan -> 干合partner之寄宫(己→未,非丑)
            '甲': self.TIAN_GAN_JI_GONG['己'], '乙': self.TIAN_GAN_JI_GONG['庚'],
            '丙': self.TIAN_GAN_JI_GONG['辛'], '丁': self.TIAN_GAN_JI_GONG['壬'],
            '戊': self.TIAN_GAN_JI_GONG['癸'], '己': self.TIAN_GAN_JI_GONG['甲'],
            '庚': self.TIAN_GAN_JI_GONG['乙'], '辛': self.TIAN_GAN_JI_GONG['丙'],
            '壬': self.TIAN_GAN_JI_GONG['丁'], '癸': self.TIAN_GAN_JI_GONG['戊'],
        }
        SAN_HE_SHENG = {  # 日支 -> 三合生支
            '申':'申','子':'申','辰':'申','寅':'寅','午':'寅','戌':'寅',
            '巳':'巳','酉':'巳','丑':'巳','亥':'亥','卯':'亥','未':'亥',
        }
        gan_ji = self.TIAN_GAN_JI_GONG[ri_gan]
        gan_shang = tiandi_pan[gan_ji]          # 日干上神（中末传）
        yang_ri = self.is_yang_ri(ri_gan)
        chu_chuan = tiandi_pan[GAN_HE_JI_GONG[ri_gan]] if yang_ri else tiandi_pan[SAN_HE_SHENG[ri_zhi]]
        return {'初传': chu_chuan, '中传': gan_shang, '末传': gan_shang,
                '课体': '别责课', '起法': '别责法',
                '阴阳日': '阳日（刚日·干合上神）' if yang_ri else '阴日（柔日·支三合生支）',
                '起课规则': '干合/支三合（古籍正例）'}
```
