### 第二节 大六壬八煞九宝（L884–L1354）

> 核心框架：八煞 = 刑、冲、破、害、墓、鬼、败、空；九宝 = 德、合、奇、仪、禄、马、生、旺、贵。

**八煞之刑（L892–L907）**：
- 歌诀："寅刑巳兮巳刑申，申复刑寅曰顺刑。丑刑戌兮戌刑未，未复刑丑曰逆刑。互刑子卯卯刑子，自刑辰午酉亥是。"
- 三刑生于三合（巳酉丑金→刑在西方巳申酉；寅午戌火→刑在南方；亥卯未木→刑在北方；申子辰水→刑在东方）。
- 吉则威权、凶则残伤。旺刑衰则福生，衰刑旺则祸起。刑不宜占病干谒，惟利捕捉。
- 四刑细分：自刑（辰午酉亥，自逞自作败，严重死于非命）、无礼之刑（子卯，门户不利淫乱尊卑不睦）、无恩之刑（寅巳申，彼刑我斗官事灾殃）、恃势之刑（丑戌未，贵刑贱大刑小）。
- 子午卯/辰戌丑组合成**三战杀**（刑冲并作，主伤残恶死）。

**八煞之冲（L909–L913）**：六冲。凡事初得有后必倾覆；吉不宜冲、凶冲则散。冲主动移反复。冲岁岁中不足、冲月月中不足。子午相加道路驱逐；卯酉相加门户分异；寅申相加邪鬼作祟；巳亥相加事多反复；丑未相加弟兄异心；辰戌相加悲喜杂异。

**八煞之破（L915–L928）**：
- 地支相破：阳日后三辰（子日见酉、寅日见亥），阴日前三辰（丑日见辰、卯日见午）→ 子酉、丑辰、寅亥、卯午、巳申、未戌。
- 破主散、移、破损，占事多中辍更改，吉见破不成吉、凶见破不成凶。贵人见破功名废、螣蛇见破牵连、朱雀见破文书口舌…（十二将见破全表）。
- 岁破 = 六冲（子年午为岁破）；月破又名白虎杀（子月午为月破）。"月破主破坏离散，却可解冤。"
- **四废**：春酉、夏子、秋卯、冬午。"或破或废传上居，事皆破废不须疑。"
- **破碎煞**（金神大杀/暗金的杀）：子午卯酉在巳、寅申巳亥在酉、辰戌丑未在丑。分三类：巳吟呻、酉破碎、丑白衣。
- 民间六破（丑破卯等）六壬不取。

**八煞之害（L930–L944）**：六害 = 子未、丑午、寅巳、卯辰、申亥、酉戌。害主阻、关、妨，行事多阻折。逐条论断（子加未事无终始官灾口舌；未加子营谋阻滞暗里生灾…全 12 条）。凡害必无和气，只宜守旧，动即有失。

**八煞之墓（L946–L1007）**：
- 五行墓：未木墓、戌火墓、丑金墓、辰水土墓。十干墓：未为甲癸墓、戌为丙戊乙墓、丑为庚丁己墓、辰为壬辛墓。一般以五行墓为主。
- 墓分昼夜：辰未日墓（刚速）、戌丑夜墓（柔延）。夜墓临日自暗投明尚可救；日墓临夜自明投暗愈见模糊。
- 自生入墓（寅加戌、巳加丑、申加辰、亥加未）：如人堕井，占病必死、占贼难获、占行人不来。
- 日之长生处乘墓（甲乙日未临亥等）主旧事再发；长生处自乘墓（甲乙日辰加亥等）主新事废；天上长生坐墓（甲乙日亥临辰等）主不能生。
- 身入墓/魂入墓（墓神覆日）/禄神入墓（庚日申禄加丑）/日入墓（坐墓）/支戴墓坐墓/行年化气入墓/年命乘墓坐墓/鬼入墓。
- **鬼（L976–L1007，六壬判断核心）**：
  - 阳克阴、阴克阳为鬼（七杀）；阳克阳、阴克阴为官星？——原文："古人认为干支之中，阳克阴、阴克阴为鬼。阳克阴，阴克阳，则为官星"（注：原文此处表述，按常规为 阳克阴/阴克阴=鬼即七杀体系）。鬼旺得气可化官，官囚无气可化鬼。
  - 传中多鬼，事事不美。昼鬼主公讼是非、夜鬼主神祇妖崇。
  - 鬼入传而日干旺相/见子孙不为凶。干上鬼发用事多不美，见德合犹可望事求官。
  - 鬼发用又临克日之乡 = **攒眉格**（占事两重不美，遇救神惟解其一，如庚辰日午加巳发用）。
  - 辰上神发用为日鬼 = 自家暗害。鬼多有制返不为凶，惟白虎发用大有畏忌（要年命制虎）。
  - 支上神发用为鬼引中末入鬼乡 = **家鬼弄家神**（有救无祸，无救有祸，如己丑日支上寅发用）。
  - 鬼发用生末传作干长生 = **鬼脱生格**（先凶后吉）。
  - 三传入局为鬼反生起干上神生干 = 返凶为吉（庚午日干上辰三传戊午寅火局为鬼生辰土；庚寅庚午庚戌乙巳乙酉乙丑己巳七日）。
  - 贵德临身制鬼反吉（乙丑乙巳二日酉加巳发用）。
  - 传鬼为贵人盗气亦能免祸（辛巳日午加辛发用）。
  - 传虽脱干能制暗鬼 = **借益格**（暗鬼 = 天将克干，凶甚明鬼；遁干之鬼亦暗鬼）。
  - 同类受克绝（十二神/十二将两表）。

**八煞之败（L1009–L1011）**：败 = 五行十二长生沐浴。甲乙败于子、丙丁败于卯、戊己败于酉（有论卯）、庚辛败于午、壬癸败于酉。败加干支主败坏衰败（占身血气衰败、占宅屋宅崩颓）。

**九宝之合（L1223–L1314）**：三合、干合、支合。
- 三合（亥卯未木合繁冗驳杂、寅午戌火合不正、巳酉丑金合娇革离异、申子辰水合流动无滞）：
  1. 三合入传主事关牵连，必过月了结。
  2. 取成合之期以三合决之（寅午戌日见天空则发…）。
  3. 三合缺一神 = 折腰格/虚一待用格（待缺神值日成）。
  4. 三合缺一神日辰偶足 = 凑合格（意外和合）。
- 干合（五合）：甲己中正合、乙庚仁义合、丙辛威权合、丁壬淫泆合、戊癸无情合（各乘吉凶神论断 5 条）。
- 支合（六合）：
  1. 合与德同入传百事皆吉。
  2. 合入传视进退。
  3. 寅合亥为破合、巳合申为刑合（合而不合成而不成）。
  4. 暗中三合六合主失脱藏匿难获。
  5. 刑破二合发用主内吉外凶。
  6. 合逢空落空又见刑害主和中藏祸（有德可解）。
  7. 合克日或乘蛇虎雀主合中有害。
