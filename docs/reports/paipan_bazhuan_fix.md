# 排盘算法修复：八专日不取遥克（疏正 0.700 → 0.705）

> 2026-08-18 晚 · 疏正吉案补强过程中发现排盘差异根因。

## 根因

§财产08·133（己未日亥将酉时，权威独足酉酉酉）被 paipan_v2 排成遥克亥丑卯——诊断发现：
`_decide_method` 中**八专日无克时仍被"干克上"（蒿矢）遥克分支拦截**，未走八专法。
据《六壬大全》八专门："有上下克取克发用，**无上下克不取遥克径用八专法**"——八专不参与遥克。

## 修复

`_decide_method` 增补分支（ke_results 之后、遥克之前）：八专日无克 → 径用八专法。

原文件 `sike_sanchuan_engine.py` 受系统写保护（edit/python 均拒），修复落地为
`sike_sanchuan_engine_patched.py` 副本，`zhanshi_duanyu` import 指向副本。
