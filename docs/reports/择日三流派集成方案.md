## 二、目标

在「择日分析」面板加**流派多选择框：六壬 / 斗首 / 演禽**：
- 勾选六壬 → 显示拱禄、拱贵、拱马、朝天、归垣、罗纹等**六壬课格**；
- 勾选斗首 → 显示三元辰、三武、武财生元、贪官克元等**斗首课格** + 斗首评分；
- 勾选演禽 → 显示四禽、二十八宿、生克、**演禽格局** + 演禽评分；
- 可多选 → 各流派分区并列展示，各自独立评分，**不做跨流派加权融合**（方法论红线：三套独立体系）。

## 三、方案设计

### 3.1 后端（`stock_dashboard.py`，扩展 `/api/zeri/analyze`）

```
GET /api/zeri/analyze?date=2026-08-15&mountain=壬&shichen=午&liupai=liuren,doushou,yanqin
```

- 新增 `liupai` 参数（逗号分隔，默认 `liuren`）。
- 保持现有六壬逻辑不动（`analyze_yidu_full`）。
- **斗首**：惰性导入 `DouhouKegeAnalyzer`，调 `analyze_kege(mountain, sizhu)`，返回四柱星曜、课格格局、评分、断语。
- **演禽**：惰性导入 `YanQinAnalyzer`，调 `analyze_yanqin_with_calendar(sizhu, y, m, d)`（**历法版优先**，四柱起例版作对照展示），返回四禽、宿吉凶、生克、格局、评分、断语。
- **安全模式**：沿用 `/api/qike` 已验证的「sys.path 复刻 + 惰性导入 + try/except 隔离」——斗首/演禽引擎异常不影响六壬主结果。

### 3.2 前端（`stock_dashboard.html` 择日面板）

1. 表单区新增「流派」多选（三个 checkbox 或分段按钮），默认勾选六壬。
2. 六壬勾选 → 显示现有 6 个筛选框（拱贵/拱禄/拱马/朝天/归垣/罗纹）+ 六壬结果区（现状）。
3. 斗首勾选 → 显示斗首结果区（山家五行、四柱星曜表、课格格局、斗首评分、断语）。
4. 演禽勾选 → 显示演禽结果区（四禽、二十八宿、宿吉凶、生克链、格局、演禽评分、断语）。
5. 各流派结果区用不同色块卡片分区（沿用 zeri-panel 暗色主题），互不干扰。

### 3.3 评分与展示原则

- **各自独立评分**：六壬 `total_score`（现有）、斗首 `综合评分`（analyzer 内 0-100）、演禽 `综合评分`（analyzer 内 0-100）。
- 页面顶部「三流派总览」并列显示三个分数 + 各自吉凶等级；**不设综合加权分**（防止方法论混淆，与项目「古例/股票两域隔离」同一原则）。
- 演禽接入**真实评分**，弃用 :8000 的 `yanqin_score=50` 占位模式。

## 四、验证与风险

| 项目 | 做法 | 风险等级 |
|---|---|---|
| 斗首两张表一致性 | `douhou_analyzer.DOUSHOU_WUXING` vs `data/constants.SHANJIA_WUXING` vs 六壬要诀 `_SHAN_GAN_CATEGORY`，抽 24 山逐山核对，结果应一致 | 中（不一致会吉凶误判） |
| 演禽历法精度 | 儒积日算法目前仅 2026-03-28 单点校准、按每天 1° 近似；用用户本地《通解》/黄历抽 5~10 个日期对照日宿，误差 >1 宿则改用权威农历库（如 sxtwl） | 中（天文精度） |
| 演禽「四柱起例」vs「历法版」 | 两版并列展示让用户对照，历法版为主 | 低 |
| 引擎异常隔离 | 惰性导入 + try/except，单家挂不影响其余 | 低 |
| 回归 | 六壬结果保持逐字节一致（不动现有逻辑，只加分支）；改后 A/B 跑已有择日样例 | 低 |

**备注**：`data/斗首择日规则.py` 文件名与内容不符（实为六壬基础数据），建议顺带改名 `data/_六壬基础数据.py` 或加头部注释，避免后续误用。
