# 219 案农历月份提取 + 月解神守卫接线 报告（2026-08-02）

> 目标：让月解神守卫（D2y：白虎乘当月解神→凶可解）真正生效
> 流程：OCR 标题解析 → 姓名/课式匹配 → 写入 month → 接线 → A/B

## 一、为什么需要新方案
原计划"从 duanyu 正则提取农历月"**不可行**：duanyu 中出现的月份几乎全是**应验时间**（"辛酉年四月脏毒死矣"），非起课月份。起课月份只在案例标题（"戊申年九月庚寅日辰将五时"）中。

## 二、标题解析 + 匹配（docs/reports/_assign_month_v4.py）

### 解析
全文扫描 769 个"例X："标题（含内嵌标题——例十等嵌在前案断语末尾），提取：
- 起课月份（干支年+月 / 年号+月 / 仅月）
- 姓名 + 生年干支
- 日干支 + 月将 + 时辰

### 匹配策略（三级）
1. **姓名+生年精确匹配**（最可靠）：13 案
2. **课式三元组匹配**（日+月将+时辰）+ 占类关键词约束（防同名异类误配）：12 案
3. 未匹配保留 None（原文无月份，宁缺勿错）：4 案

### 踩坑记录
| 问题 | 解法 |
|---|---|
| 例十嵌在断语末尾（非行首） | 全文扫描替代行首正则 |
| "陆孔目"同名两人（癸亥生/己巳生） | 姓名+生年联合匹配 |
| 童秀才(丁酉日午将辰时)误配江文老家宅案 | 加占类关键词约束 |
| OCR 干支混写 戊/戌、末/未、已/己、巴/巳 | fix_gz + match_yue_jiang 归一 |
| 叶八郎"行医求占生意"（疾病类无"病"字） | 占类关键词加"医" |
