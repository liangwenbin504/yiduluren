  - 第35法"人宅受脱俱招盗"：原文"干支上皆乘脱气……必被盗窃" = core_rule ✓
  - 第53法"两蛇夹墓"：原文"丙戌日戌加巳……双蛇夹日墓" = core_rule ✓（与 D3 修正同源）

  互旺皆旺坐谋宜(102) / 已灾凶逃返无疑(60) / 前后引从升迁吉(55) / 将逢内战所谋危(55) / 常问不应逢吉象(53) / 彼此猜忌害相随(52)…

### 3️⃣ 估值链（⚠️ 断裂——核心发现）
古例路径 `RICH_KEGE_ENABLED=True` + `RICH_CALIBRATED_VALUATION=True`（生产默认）时：
```python
bifa_names = BiFaDetector 检测出的"全名"（如"互旺皆旺坐谋宜"）
bifa_val = sum(BIFA_VALENCE.get(n, 0) for n in bifa_names)   # 全名查短名词表 → 恒 0
```
- **BIFA_VALENCE 词表 = 35 个短名**（罗网/三奇/斩关/闭口/游子/芜淫…）
- **检测器输出 = 100 法全名**（互旺皆旺坐谋宜/前后引从升迁吉…）
- 全名 vs 短名**无交集** → `bifa_val` 恒 0 → 毕法股市信号 **0/164 案非平**（实锤）

## 二、A/B 对比（毕法贡献的真实影响）

| 模式 | 毕法估值路径 | M3 (164案) | 混淆 |
|---|---|---|---|
| **calibrated（生产）** | 检测全名查表=0（断裂） | **88.4%** | 凶→吉6/吉→凶13 |
| limited | 文本锚定短名（有效） | 87.8% | 凶→吉7/吉→凶13 |

**解读**：毕法信号有效时（limited）M3 反而低 0.6pp——毕法凶法在凶重语料中产生更多"凶→吉"误判（7 vs 6）。**当前断裂实为"无害的隐藏"**：毕法 valence 零贡献，恰是 88.4% 的一部分。

## 三、结论与建议

### 已验证 ✅
1. 知识库 100 法与原文逐字一致
2. 检测器 100 法全实现、真实激活
3. 第72法缺太岁参数——D6 已覆盖其语义，不阻塞

### 不建议动的（保持现状）
- **毕法估值链断裂不修复**：修复（全名→短名映射）会让毕法信号重新参与融合，预期 M3 向 limited 的 87.8% 靠拢（负回归）。与"正向信号在凶重语料有害"铁律同构。
- 若要修复，必须走「四件套先交审 + A/B」且守住 ≥88.4%——预期通不过，故暂缓。
