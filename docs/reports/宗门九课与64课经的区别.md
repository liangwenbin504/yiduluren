# 宗门九课与64课经的区别

## 核心概念

### 宗门九课（起课方法）
- **定义**：确定三传的方法
- **作用**：根据四课情况，选择初传的规则
- **性质**：**无吉凶之分**，只是起课的技术方法
- **数量**：9种（或10种，含反吟课）

### 64课经（断事方法）
- **定义**：判断吉凶的方法
- **作用**：根据三传、神将、旺相等判断事情的吉凶
- **性质**：**有吉凶之分**，用于断事
- **数量**：64种

## 宗门九课详解

### 1. 元首课（起课法）
```
条件：四课中只有一课上克下
方法：取上克下之神为初传
性质：起课方法，无吉凶
```

### 2. 重审课（起课法）
```
条件：四课中只有一课下克上
方法：取下克上之神为初传
性质：起课方法，无吉凶
```

### 3. 知一课（起课法）
```
条件：四课中有二课或三课相克
方法：取与日干比和者为初传
性质：起课方法，无吉凶
```

### 4. 涉害课（起课法）
```
条件：多课相克且比和
方法：涉害归家，取孟仲季为用
性质：起课方法，无吉凶

从属格：
- 见机格：取四孟上神发用
- 察微格：取仲季为用
- 缀瑕格：取四课中先见者用
```

### 5. 遥克课（起课法）
```
条件：四课无克
方法：
- 蒿矢格：四课上神克日干为用
- 弹射格：日干克上神为用
性质：起课方法，无吉凶
```

### 6. 昴星课（起课法）
```
条件：四课无克无遥克
方法：
- 虎视转蓬格：刚日仰视酉上神为用
- 冬蛇掩目格：柔日伏视酉下神为用
性质：起课方法，无吉凶
```

### 7. 别责课（起课法）
```
条件：四课不备无克
方法：别取一神为用
性质：起课方法，无吉凶
```

### 8. 八专课（起课法）
```
条件：干支同位无克
方法：取干上神或支上神为用
性质：起课方法，无吉凶
```

### 9. 伏吟课（起课法）
```
条件：月将=占时
方法：取日支上神为用
性质：起课方法，无吉凶
```

### 10. 反吟课（起课法）
```
条件：月将冲占时
方法：取日支上神为用
性质：起课方法，无吉凶
```

## 实际应用

### 起课流程

```
第一步：根据占时、月将起四课
第二步：根据宗门九课规则确定三传
        ↓
        这里使用的是【宗门九课】的方法
        ↓
第三步：根据三传、神将、旺相等判断吉凶
        ↓
        这里使用的是【64课经】的方法
        ↓
第四步：得出结论
```

### 示例

假设：月将冲占时

1. **起课阶段（宗门九课）**
   - 判断为"反吟课"起法
   - 按反吟课规则确定三传
   - 此阶段**无吉凶判断**

2. **断事阶段（64课经）**
   - 判断为"反吟课"课体
   - 主反复无常，事难成
   - 此阶段**有吉凶判断**：凶

## 总结

| 维度 | 宗门九课 | 64课经 |
|------|----------|--------|
| **性质** | 起课方法 | 断事方法 |
| **作用** | 确定三传 | 判断吉凶 |
| **吉凶** | 无 | 有 |
| **数量** | 9-10种 | 64种 |
| **关系** | 前置步骤 | 后续步骤 |

**关键理解**：
- 宗门九课是"如何起课"
- 64课经是"如何断事"
- 同一个课例，先用宗门九课起课，再用64课经断事
- 课名相同（如反吟课），但含义不同
