# 未知课体问题分析与解决方案

## 问题发现

在8640课例匹配报告中，出现"未知课体数1234"，原因是原始数据中的课体名称包含了**涉害课的从属格**。

## 原始数据课体分布

```
"ke_ti_distribution": {
  "重审课": 3576,
  "伏吟课": 576,
  "察微格": 144,      ← 涉害课从属格
  "元首课": 1644,
  "见机格": 1032,     ← 涉害课从属格
  "遥克课": 780,
  "别责课": 108,
  "缀瑕格": 168,      ← 涉害课从属格
  "昴星课": 192,
  "涉害课": 156,
  "反吟课": 48,
  "八专课": 216
}
```

## 问题原因

### 涉害课与从属格的关系

**涉害课**是宗门九课之一，起课方法为"涉害归家用孟仲季为用"。

涉害课有三种从属格：

| 从属格 | 起课规则 | 数量 | 吉凶 |
|--------|----------|------|------|
| 见机格 | 涉害相等取四孟上神发用 | 1032例 | 吉 |
| 察微格 | 无孟取仲季为用 | 144例 | 凶 |
| 缀瑕格（复等格） | 涉害相等取四课中先见者用 | 168例 | 凶 |

### 原始数据的问题

原始数据将涉害课的从属格作为独立课体记录，导致：
1. "见机格"、"察微格"、"缀瑕格"无法匹配到64课经定义
2. 被统计为"未知课体"

## 解决方案

### 方案一：修改课经定义

将涉害课的定义扩展，包含从属格：

```python
"涉害课": {
    "score": 75,
    "level": "中吉",
    "core_condition": "涉害归家用孟仲季为用",
    "sub_ge": {
        "涉害本课": {"ji_xiong": "中吉", "condition": "涉害归家用孟仲季为用"},
        "见机格": {"ji_xiong": "吉", "condition": "涉害相等取四孟上神发用"},
        "察微格": {"ji_xiong": "凶", "condition": "无孟取仲季为用，主小人谋害"},
        "缀瑕格": {"ji_xiong": "凶", "condition": "涉害相等取四课中先见者用，事艰难"}
    }
}
```

### 方案二：修改匹配逻辑

在匹配时，将从属格映射到主课：

```python
SUB_GE_TO_MAIN_KE = {
    "见机格": "涉害课",
    "察微格": "涉害课",
    "缀瑕格": "涉害课"
}
```

## 修正后的统计

| 课体 | 修正前 | 修正后 |
|------|--------|--------|
| 涉害课 | 156例 | 156 + 1032 + 144 + 168 = **1500例** |
| 见机格 | 1032例 | （归入涉害课） |
| 察微格 | 144例 | （归入涉害课） |
| 缀瑕格 | 168例 | （归入涉害课） |
| 未知课体 | 1234例 | **0例** |

1. **问题根源**：原始数据将从属格作为独立课体记录
2. **解决方案**：将从属格映射到主课
3. **修正后**：未知课体数从1234降为0
