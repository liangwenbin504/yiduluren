## 二、命题来源：S2 取证 → 意外挖出真 bug

本轮命题原为 **S2 剩余：旺衰作为 `tone` 的条件**。铁律要求「**不可先动结构、必须先原文取证**」
（上一轮正是在这一步发现「旺衰应事其实是独立层、不是 tone 的附加条件」）。

于是先把 `tone` 警戒档 11 条摊开、逐条回原文找**旺衰限定**。取证中回读到
**《注解大六壬指南》十二将章** 的青龙段落，发现原文写的是「蟠泥在丑，**所谋未称**」——
而引擎冻结表`TIANJIANG_GONGWEI_SIDE['青龙']['丑']` 却是 **`'吉'`**。

⇒ **取证副产品＝一个逆原文的判读**，优先级高于原命题，故先修此 bug。

## 三、原文取证（四重，方向一致无歧义）

| # | 出处 | 原文 | 要点 |
|---|---|---|---|
| ① | **《六壬大全》卷2 L605**（断语直接出处） | 「伏陆在酉，允宜退守；**蟠泥在丑，所谋未称**」 | 断语本字 |

> 冻结表中同类「失地」宫（未／申／酉）**早已定 `'凶'`**，唯丑格漏网 ⇒ 与同类宫**口径不一致**，进一步佐证是 bug。

## 四、根因链

```
断语「蟠泥，所谋未称」
   ↓  side_of_duanyu() 机械读解
否定守卫 _NEG = ('非','不','无','免','脱')   ← 🔴 缺「未」
   ↓  _neg_at(_DY, '称') → False（判为"未被否定"）
吉词表 _JI 含 '称'
   ↓  命中吉词
判 '吉'   ← ❌ 与原文相反
```

### 🔴 关键前提：只改 `_OVERRIDE` 不生效

取用链 `side_with_fallback` 的优先级为：

```
冻结表（有值即返回）→ 断语实时判 → 天将本标签
```

**冻结表有值时不走 `_OVERRIDE`** ⇒ 修 `_OVERRIDE` 的同时**必须同步改冻结表那一格**。

## 五、处置形态：为什么**不**扩大 `_NEG`

| 方案 | 评估 | 采纳 |
|---|---|---|
| (a) 把「未」加入通用 `_NEG` | 「未」**兼作地支字**（如《颐旨经》「龙无鳞**未**上」），扩大通用守卫对未来语料**有误伤风险** ⇒ 触碰「**不可推广**」红线 | ⛔ |
| (b) 按 `_OVERRIDE` **人工核校**修正该格 | 精确、可控、与既有 20 条核校条目同范式（**机械读解 ＋ 人工 `_OVERRIDE` 核校**） | ✅ |

## 九、⛔ 本轮踩坑（探针侧，**非生产问题**）

**切片过短把 HTML 从中间切断 ⇒ 浏览器自动补闭合标签 ⇒ 一度误判「前端漏渲染 `xiong[4..8]`」**

- 我的探针用 `full.slice(iA, iY + 3200)`，恰在第 4 条之后切断；
- 浏览器解析被截断的 HTML 时**自动补齐** `</div></div></div></div></div></body></html>`
  ⇒ 截图与 DOM 都「看起来完整」，但**条目少了一半**；
- 改 `iY + 14000` 后 DOM 立刻出现「蟠泥／支上青龙／人君土」⇒ **确系探针切片不足**，前端无 bug。

🔴 **判据（写进 skill）**：DOM 段尾若出现**多余闭合标签**（如 `</div></div></div></div></div></body></html>`）
即为**截断征兆**；**`--dump-dom` ＋ 关键字 count 比肉眼数条目可靠**。
