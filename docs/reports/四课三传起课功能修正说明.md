## ✅ 修正内容

### 1️⃣ 修正方法调用名称

**问题**：原代码使用了错误的方法名调用四课三传引擎

**修正前**：
```python
tiandi_pan = sike_engine.calculate_tiandi_pan(yue_jiang, shi_zhi)
sike = sike_engine.calculate_sike(tiandi_pan, ri_ganzhi)
sanchuan = sike_engine.calculate_sanchuan(sike, ri_gan, ri_zhi, yue_zhi, shi_zhi)
```

**修正后**：
```python
tiandi_pan = sike_engine.get_tiandi_pan(yue_jiang, shi_zhi)
sike = sike_engine.qi_sike(ri_gan, ri_zhi, tiandi_pan)
sanchuan = sike_engine.fa_sanchuan(sike, ri_gan, ri_zhi, tiandi_pan)
```

**依据**：`SiKeSanChuanCalculator` 类的正确方法名
- `get_tiandi_pan()` - 获取天地盘
- `qi_sike()` - 起四课
- `fa_sanchuan()` - 发三传

### 2️⃣ 修正月将计算方法

**问题**：原代码使用简化方法计算月将，不够精确

**修正前**：
```python
# 简化计算（错误）
yue_index = self.calendar.DIZHI.index(yue_zhi)
yue_jiang_index = (12 - (yue_index + 1)) % 12
yue_jiang = self.calendar.DIZHI[yue_jiang_index]
```

**修正后**：
```python
# 使用精确的节气计算（正确）
from engine.yuejiang_engine import YueJiangCalculator
yuejiang_calc = YueJiangCalculator()
yue_jiang, yue_jiang_name = yuejiang_calc.get_yuejiang_by_date(
    sizhu['年']['year'], 
    sizhu['月']['month'], 
    sizhu['日']['day'],
    shi_hour
)
```

**依据**：《大六壬起课规则详解》第一章
> **中气换将原则**：月将的确定遵循中气换将原则
> - 雨水后→亥将
> - 春分后→戌将
> - 未到中气前，仍用上个月的月将

**优势**：
- ✅ 严格按照节气计算
- ✅ 精确到时辰级别
- ✅ 符合《六壬大全》规范

## 📊 起课流程总览

根据《大六壬起课规则详解》第八章，完整的起课步骤如下：

```
第一步：确定月将
├─ 根据占测日期，查节气
├─ 中气后换将，确定月将地支
└─ 使用 YueJiangCalculator 精确计算

第二步：选取占时
└─ 以占测时辰为准（真太阳时）

第三步：排天地盘
├─ 月将加在占时上
├─ 顺布十二宫
└─ 使用 get_tiandi_pan() 计算

第四步：起四课
├─ 日干寄宫，看得天盘（第一课）
├─ 干上神的上神（第二课）
├─ 日支上神（第三课）
└─ 支上神的上神（第四课）
  └─ 使用 qi_sike() 计算

第五步：发三传
├─ 按九法优先级依次判断
├─ 确定初传、中传、末传
└─ 使用 fa_sanchuan() 计算

第六步：排贵人盘（待实现）
├─ 根据日干起贵人
├─ 根据占时定昼夜
├─ 根据贵人位定顺逆
└─ 布十二天将

第七步：定六亲（待实现）
├─ 根据日干与三传五行关系
└─ 父母、官鬼、子孙、兄弟、妻财
```

def _show_paipan_window(self, result):
