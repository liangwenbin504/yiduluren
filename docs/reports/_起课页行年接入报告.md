### HTTP 真实链路（Python 3.12 起服务 :5000）

**GET**：甲子日 午将 卯时 + 午命45男 →
```
课体: 重审课 | 起法: 贼克法 | 三传: ['申','亥','寅']
行年信息: {"行年":"戌","行年上神":"丑","本命上神":"酉"}
```
天地盘 12 键完整，行年上神正常算出。

**POST 通解 L3937 实例对拍**：
- 丙子日 丑将 寅时 + 寅命19男 → `行年=申` ✓（通解「男命丙寅十九岁行年在申」）
- 丙子日 丑将 寅时 + 寅命16女 → `行年=巳` ✓（通解「女命丙寅十六岁行年在巳」）

**无参数回归**（默认 甲子日子将子时 + 无行年三参数）：行年信息全空 → 安全。
