## 📋 操作指南

### 推荐设置（快速测试）

#### 1. 选择山向
- 点击"壬"字按钮 → 坐壬向丙

#### 2. 选择日期范围（关键！）
```
开始日期：2026-03-15
结束日期：2026-06-15 （3 个月，90 天）
```

**重要**：不要选择太大的日期范围（如 4 年），会导致计算时间过长。

#### 3. 选择课格
- 点击"仅选龙德课"按钮 → 确保显示"已选：1/13（龙德课）"

#### 4. 开始择日
- 点击"开始择日"按钮
- 等待 1-2 分钟
- 观察控制台输出

#### 5. 查看结果
- 结果表格应该显示 20-30 个日期
- 双击任意日期查看详细信息

## ⚠️ 注意事项

### 1. 日期范围建议
```
推荐：3 个月（90 天） → 计算时间 1-2 分钟
可行：半年（180 天） → 计算时间 3-5 分钟  
警告：1 年（365 天） → 计算时间 10+ 分钟
危险：2 年+（730+ 天） → 计算时间 30+ 分钟
```

### 2. 课格选择建议
```
快速测试：仅选龙德课
传统择日：传统五课
全面筛选：全选
```

### 3. 评分设置建议
```
宽松：7.0 → 结果较多
适中：7.5 → 结果适中
严格：8.0 → 结果较少
```

## 🔍 如果仍然没有结果

如果按照上述步骤操作后仍然没有结果，请检查：

### 1. 控制台输出
- 查看命令行窗口的输出信息
- 看是否有错误信息

### 2. 日期范围
- 确保日期范围不太大（建议 3-6 个月）
- 确保开始日期 ≤ 结束日期

### 3. 课格选择
- 确保至少选择了一种课格
- 确保"已选：X/13"标签显示正确

### 4. 筛选条件
- 评分设置不要太严格（如 9.0+）
- 如果勾选了"仅龙德课"选项，确保龙德课检查通过
