## 🚀 使用方法

### 方法一：图形界面（推荐）

```bash
# 双击批处理文件
启动龙德课择日系统.bat

# 或命令行启动
python src/ui/long_de_ke_gui.py
```

**操作步骤**:
1. 选择坐山朝向
2. 设置日期范围
3. 配置筛选条件
4. 点击"开始择日"
5. 查看结果
6. 导出报告

### 方法二：编程调用

```python
from datetime import datetime
from src.engine.long_de_ke_selector import LongDeKeSelector

# 创建选择器
selector = LongDeKeSelector()

# 执行择日
results = selector.select_long_de_dates(
    mountain='壬',
    direction='丙',
    start_date=datetime(2026, 3, 15),
    end_date=datetime(2026, 12, 31),
    min_arrival_count=3
)

# 生成课格结构
kege = selector.generate_kege_structure(results[0])
print(kege)

# 保存结果
selector.save_results(results, '结果.json')
```

### 方法三：演示脚本

```bash
# 运行演示
python 龙德课择日演示.py
```

## 📖 理论依据

### 龙德课定义

> **龙德课者，太岁或月将乘贵人发用也。**

**判断条件**:
1. 太岁或月将发用（满足其一）
   - 太岁发用：初传 = 年支
   - 月将发用：初传 = 月将
2. 乘贵人：初传是日干贵人

**课体类型**:
- 太岁龙德课：权贵之象（力量最强）
- 月将龙德课：光明之象（力量次强）

### 到山到向定义

**到山到向**：贵人、禄神、驿马出现在坐山或朝向的对应位置。

**判断标准**:
- 6 个以上：上上大吉 ⭐⭐⭐
- 5 个：上吉 ⭐⭐
- 4 个：中吉 ⭐
- 3 个：小吉
- 少于 3 个：平
