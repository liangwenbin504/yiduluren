# 六壬引擎分类架构（2026-08-18）

占测输出 = **吉凶结论**（判级+权重合成） + **事体叙事**（过程/方位/环境/应期）。
吉凶引擎决定"level"，叙事引擎决定"叙事"；两者分层，互不干扰评分基线。

## 一、引擎分类总表

### A. 吉凶引擎（评分层，输出终局 → 决定 level）
| 引擎 | 模块 | 权重 | 说明 |
|---|---|---|---|
| 事体走向引擎 | engine/liuchen_engine.py | **0.5** | 占类化规则（功名/疾病/官讼/求财/家宅/胎产/出行/婚姻/贼盗/行人/其他），三传时序（初=始/中=过程/末=结局），632 实测主导信号 |
| 占类专属信号 | liuren_keti_bifa 9 抽取器 | 0.2 | 占类 valence（古籍出处确定性规则） |
| 三传时序 | _sanchuan_time_sequence | 0.2 | 天将吉凶±旺衰±空亡，权重(0.2,0.3,1.5)末传定结局 |
| 支上神信号 | _zhi_shang_signal | 0.1 | 支=事体/内/静；支上泄克冲刑墓日干+凶将→凶，有解神可解 |
| 合成器 | zhanshi_duanyu.generate | — | total = 0.5·liu + 0.2·zl + 0.2·seq + 0.1·zs，阈值 ±1.2/±0.4 定 吉/小吉/凶/小凶/平 |

## 二、数据流

```
排盘(四课三传天将) ─┬─> 吉凶引擎: liuchen(0.5) + zl(0.2) + seq(0.2) + zs(0.1) ─> level
                     └─> 叙事引擎: 课体话术 + 毕法条文
                          ├─ 类神引擎(失物类): W1-W4 吉凶 → 并入 liuchen 贼盗块
                          │    └─ 方位引擎: 类神所加方/初传定向 → "当往X方寻之"
                          │        └─ 环境类象: 类神×下神×天将 → "炉灶前/神庙/园内…"
                          ├─ 道里数法: 支数/五行数 → "共X数"
                          └─ 应期引擎: → "初X日/月内见"
```

## 三、输出结构（既有事体又有吉凶）

generate 返回：
- `level`（吉凶结论：吉/小吉/凶/小凶/平）
- `liuchen`（事体走向：走向/终局/阶段{初传,中传,末传}/叙事/出处）——叙事已含方位/环境
- `yingqi`（应期）、`seq_desc`（三传时序）、`zhi_shang_desc`（支上事体）
- `summary`（合成总叙）

**已生效示例**（§200 失船）：
> level=吉；叙事="类神卯不入传，然初传寅与类神同气乘六合发用，物寻之必见，**当往东南方寻之**"
> （§199：吉，"类神酉现于初传……当往**正南**方寻之（**南方炉灶前水湿处**）"）

## 四、可信度增强方向（按建议顺序）

1. **全链路输出**（已接线 ✓）：类神(在不在) → 方位(何处) → 道里(多远) → 应期(何时) 四段合成。
2. **方位验证集**（本轮）：从案例断语提取方位结论标注 → 方位引擎单独回测命中率（与吉凶分开评）。
3. **占类方位扩展**：行人（L994-1046"望东南以酉为限、功曹加东南已动加北将至"、将军煞/太岁分级定远近）、
   贼盗（玄武所临方 §641、游都所临方 ZN-应候-二"自东北来"）、求医（天医地医 §167）、
   阴宅山向（§041"卯龙入首作乙山辛向"）。
4. **环境类象扩充**：案例库亡盗/失物案全量提取"类神×下神×天将→场所"（§194 厕坑、§183 瓮器厕中、§416 水边…）。
5. **数法口径标注**：每案标注"哪套数法+数为何意（年/月/日/里）"，攒实例再提炼选择规则（防臆造）。
