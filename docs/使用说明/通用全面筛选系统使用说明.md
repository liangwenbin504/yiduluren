# 通用全面筛选系统使用说明

## 系统概述

本系统采用**严格逐一筛选法**，适用于**任何时间范围**的日课筛选需求（三年、五年、十年等）。系统保证：

1. **不遗漏任何一课**：对时间范围内的每一天、每一时辰都进行分析
2. **完整细致的检查**：对每一课都进行斗首课格和六相六替的全面分析
3. **统一评分标准**：采用一致的评分体系，确保结果的可比性
4. **可扩展性强**：可轻松调整时间范围、坐山、筛选条件等参数

---

## 核心原则

### 1. 全面遍历原则
- 遍历时间范围内的**每一年**
- 遍历每一年的**每一月**
- 遍历每一月的**每一日**
- 遍历每一日的**每一时辰**（12 个）

### 2. 逐一筛选原则
- 对**每一课**都进行独立分析
- 不预设、不跳过、不遗漏
- 严格按照评分标准打分
- 按总分排序选出最优

### 3. 评分权重原则
- **斗首课格：70%**（核心）
  - 元辰得位是关键
  - 三元辰格最优
  - 元辰旺相加分
- **六相六替：30%**（辅助）
  - 吉星坐六相
  - 凶星坐六替
  - 水土同宫

## 使用方法

### 基础用法

```python
from comprehensive_selector_universal import ComprehensiveSelector
from datetime import datetime

# 1. 创建筛选器
selector = ComprehensiveSelector(shan='壬')

# 2. 设置时间范围
start_date = datetime(2026, 3, 24)
end_date = datetime(2029, 3, 24)

# 3. 执行筛选（选出前 5 课）
top_5 = selector.select_top_ke(start_date, end_date, top_n=5)

# 4. 显示结果
selector.display_results(top_5)

# 5. 保存结果
selector.save_results(top_5, 'result.txt')
```

### 进阶用法

```python
# 筛选五年范围（2026-2031）
start_date = datetime(2026, 3, 24)
end_date = datetime(2031, 3, 24)
top_10 = selector.select_top_ke(start_date, end_date, top_n=10)

# 筛选十年范围（2026-2036）
start_date = datetime(2026, 3, 24)
end_date = datetime(2036, 3, 24)
top_20 = selector.select_top_ke(start_date, end_date, top_n=20, min_score=80)
```

## 筛选流程

### 步骤 1：初始化
```
创建筛选器 → 设置坐山 → 初始化统计信息
```

### 步骤 2：遍历日期
```
for 每一天 in 时间范围:
    获取日柱干支
    for 每一个时辰 (12 个):
        获取四柱
        分析课格
        计算评分
        保存结果
```

### 步骤 3：排序筛选
```
按总分降序排序 → 选出前 N 课 → 显示结果
```

### 步骤 4：保存输出
```
保存到文件 → 包含详细信息 → 便于查阅
```

## 评分标准

### 斗首课格评分（70% 权重）

| 格局 | 基础分 | 加分条件 |
|------|--------|----------|
| 三元辰格 | +25 | 三柱以上元辰 |
| 三武格 | +25 | 三柱以上武财 |
| 元辰旺相 | +15 | 元辰两现以上 |
| 武财生元格 | +20 | 武财两现，元辰一见 |
| 武财关鬼格 | +15 | 破军一见，武曲两见 |
| 贪狼克元格 | -30 | 贪狼两现，元辰一见 |
| 破军泄气格 | -25 | 破军两现 |
| 廉子伤克格 | -20 | 廉贞两现，元辰一见 |

**元辰不得位惩罚**：-30 分

### 六相六替评分（30% 权重）

| 吉凶 | 分数 | 条件 |
|------|------|------|
| 吉 | 90 | 吉星坐六相 / 凶星坐六替 |
| 平 | 70 | 廉贞星 / 其他 |
| 凶 | 30 | 吉星坐六替 / 凶星坐六相 |

### 综合评分计算
```
总分 = 调整后斗首评分 × 70% + 六相六替评分 × 30%
```

## 统计信息

系统会实时统计以下信息：

- **总天数**：时间范围内的总天数
- **总课数**：分析的总课数（天数 × 12）
- **已分析课数**：已完成分析的课数
- **元辰得位课数**：元辰得位的课数
- **上上大吉课数**：综合评价为上上大吉的课数
- **吉课数**：综合评价为吉的课数
- **平课数**：综合评价为平的课数
- **凶课数**：综合评价为凶的课数

## 性能说明

### 处理速度
- 每天（12 时辰）：约 0.1 秒
- 100 天：约 10 秒
- 1000 天（约 3 年）：约 100 秒
- 3650 天（约 10 年）：约 365 秒（6 分钟）

### 内存占用
- 每课数据：约 1KB
- 10000 课：约 10MB
- 100000 课：约 100MB

### 优化建议
1. **长时间范围**：可分段处理，每段保存一次结果
2. **大内存占用**：可边分析边排序，不保存所有结果
3. **多次使用**：可缓存四柱计算结果

## 质量保证

### 1. 准确性保证
- 使用精确的四柱计算引擎
- 严格按节气计算年月柱
- 使用高氏日柱公式计算日柱
- 五鼠遁计算时柱

### 2. 完整性保证
- 遍历所有日期，不跳过任何一天
- 分析所有时辰，不遗漏任何一课
- 完整评分，不简化任何步骤
- 详细记录，不省略任何信息

### 3. 一致性保证
- 统一评分标准
- 统一筛选条件
- 统一输出格式
- 统一统计口径

## 注意事项

### 1. 时间范围
- 开始日期必须早于结束日期
- 时间范围不宜过大（建议不超过 30 年）
- 超大范围可分段处理

### 2. 坐山选择
- 根据实际需求选择坐山
- 不同坐山的评分标准不同
- 需要修改 douhou_analyzer 中的配置

### 3. 筛选条件
- 可根据实际需求调整 min_score
- 可根据实际需求调整 top_n
- 可增加其他筛选条件

### 4. 结果使用
- 结果仅供参考
- 实际应用需结合其他因素
- 建议咨询专业人士
