# 大六壬 64 课经提取与关联系统 - 使用指南

## 功能概述

本系统从《白话大六壬全书》中提取 64 课经，并与起课结果自动关联，提供完整的课经查询和匹配功能。

## 核心功能

### 1. 课经数据管理
- **数据结构**：JSON 格式存储（`data/64_ke_jing.json`）
- **字段包含**：
  - 课名
  - 课体（贼克、涉害、遥克等）
  - 特征（三传特征、特殊格局）
  - 课经原文
  - 断语
  - 示例课例

### 2. 课经查看器
**启动方式**：双击 `启动课经查看器.bat`

**功能**：
- 浏览 64 课经列表
- 查看课经详情（原文、断语）
- 编辑课经内容
- 保存修改
- 导入 PDF（开发中）

### 3. 自动匹配系统
在起课验证 GUI 中，系统会：
1. 根据起课结果（课体、三传、格局）
2. 自动匹配对应的课经
3. 显示匹配的课经及断语
4. 提供详细的课经解释

## 匹配规则

### 1. 课体匹配（50 分）
- 起课结果的课体与课经名称匹配
- 起课法与课经类别匹配

### 2. 三传特征匹配（20 分）
- 初传、中传、末传的特征
- 三合、六合、刑冲等

### 3. 特殊格局匹配（30 分）
- 见机格、察微格、缀瑕格
- 井栏格、无亲格等

### 4. 匹配阈值
- ≥50 分：认为匹配成功
- 按分数排序，显示最匹配的课经

## 使用流程

### 方法一：课经查看器
1. 双击 `启动课经查看器.bat`
2. 浏览 64 课经列表
3. 点击课名查看详情
4. 可编辑和保存修改

### 方法二：起课验证 GUI（集成版）
1. 双击 `start.bat`
2. 输入起课参数
3. 点击【验证起课】
4. 查看匹配的课经及断语

## 数据管理

### 数据存储位置
- `data/64_ke_jing.json` - 课经数据文件

### 数据格式
```json
{
  "涉害课": {
    "ke_name": "涉害课",
    "ke_type": "涉害法",
    "features": {
      "te_shu": "孟仲季"
    },
    "description": "涉害课者，用神相克，涉害深浅也。",
    "judgment": "取涉害最深者为用，浅者次之。",
    "examples": []
  }
}
```

### 添加课经
```python
from engine.ke_jing_engine import LiuShiSiKeEngine

engine = LiuShiSiKeEngine()
engine.add_ke_jing(
    ke_name="课名",
    ke_type="课体",
    features={"特征": "值"},
    description="课经原文",
    judgment="断语",
    examples=[]
)
```
