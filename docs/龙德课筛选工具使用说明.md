# 龙德课筛选工具使用说明

## 📋 功能概述

本系统提供从 2026-2036 年 10 年中筛选**龙德课**的专业工具，针对**壬山丙向**风水择日需求。

### 龙德课定义

**龙德课**：太岁月将乘贵人发用

判断条件：
1. **太岁发用**：初传 = 年支（太岁）
2. **月将发用**：初传 = 月将
3. **乘贵人**：初传是日干贵人

满足：(太岁发用 OR 月将发用) AND 乘贵人 = 龙德课

## ⚠️ 注意事项

1. **龙德课条件严格**：
   - 需要同时满足"太岁或月将发用"和"乘贵人"
   - 平均 2-3 天出现一个

2. **月将计算**：
   - 当前使用简化算法（正月亥，二月戌，...）
   - 实际应用中应使用精确的节气计算

3. **日干支计算**：
   - 使用六十甲子循环推算
   - 基准日期：1984 年 1 月 1 日（甲子日）

4. **贵人判断**：
   - 使用标准贵人歌诀：
     - 甲戊庚牛羊，乙己鼠猴乡
     - 丙丁猪鸡位，壬癸兔蛇藏
     - 六辛逢马虎，此是贵人方

## 🎓 技术实现

### 核心算法

```python
def is_long_de_ke(ri_gan_zhi, yue_jiang, tai_sui, sanchuan):
    """判断龙德课"""
    chu_chuan = sanchuan.get('初传', '')
    
    # 条件 1：太岁或月将发用
    is_tai_sui_yong = (chu_chuan == tai_sui)
    is_yue_jiang_yong = (chu_chuan == yue_jiang)
    
    # 条件 2：乘贵人
    ri_gan = ri_gan_zhi[0]
    gui_ren_list = get_gui_ren(ri_gan)
    is_gui_ren_yong = (chu_chuan in gui_ren_list)
    
    # 龙德课判定
    return (is_tai_sui_yong or is_yue_jiang_yong) and is_gui_ren_yong
```

## 💡 常见问题

### Q1: 为什么龙德课这么少？

A: 龙德课条件非常严格，需要同时满足：
1. 初传是太岁或月将
2. 初传是日干贵人

三个条件同时满足的概率较低。

### Q2: 可以放宽条件吗？

A: 可以。修改判断逻辑：

```python
# 只要求太岁或月将发用（不要求乘贵人）
if is_tai_sui_yong or is_yue_jiang_yong:
    # 这是"太岁课"或"月将课"，不是严格龙德课
```

### Q3: 壬山丙向如何应用？

A: 壬山丙向是风水坐向：
- 壬山：坐北朝南（壬方）
- 丙向：朝向南方（丙方）

在择日时，选择龙德课可以增强吉气，主：
- 仕宦高升
- 贵人扶持
- 万事亨通
