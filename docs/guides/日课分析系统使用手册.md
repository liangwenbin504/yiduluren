# 日课分析系统使用手册

## 系统概述

本系统是基于传统择日学理论开发的日课分析工具，整合了斗首择日、演禽真法、大六壬等多种传统术数方法，通过科学的加权评分算法，为用户提供全面、客观的日课吉凶评价。

## 核心功能模块

### 1. 日期范围生成模块
- 生成当前日期至 2100 年 12 月 31 日的完整日期序列
- 每日生成 12 个时辰的日课基础数据
- 处理节气转换、闰月等特殊历法情况

### 2. 炉传斗首课格分析模块
- 基于坐山信息生成斗首课格
- 严格参照《斗首择日秘本》规则
- 计算吉凶分值 (0-100 分)

### 3. 演禽真法分析模块
- 基于四柱信息实现演禽星宿排布
- 计算禽星生克关系
- 判定吉凶格局

### 4. 综合评分模块
- 实现加权评分算法
- 默认权重：斗首 40%、演禽 30%、大六壬 30%
- 支持自定义权重配置

## 快速开始

### 基础使用

```python
from datetime import datetime
from src.engine.riku_analysis_system import RikeAnalysisSystem

# 创建分析系统实例
system = RikeAnalysisSystem()

# 分析单个日课
test_date = datetime(2026, 3, 24)
result = system.analyze_single_ke(
    date=test_date,
    shichen_index=7,  # 午时 (第 7 个时辰)
    shan='壬'  # 坐山
)

# 查看综合评分
print(f"综合评分：{result['综合评分']['综合评分']}分")
print(f"综合吉凶：{result['综合评分']['综合吉凶']['level_name']}")

# 查看完整报告
print(result['GLM 评价报告'])
```

### 分析单日所有时辰

```python
# 分析单日 12 个时辰，筛选 70 分以上的日课
daily_results = system.analyze_daily_ke(
    date=datetime(2026, 3, 24),
    shan='壬',
    min_score=70
)

print(f"找到 {len(daily_results)} 个符合条件的日课")

# 显示最佳 3 个时辰
for i, res in enumerate(daily_results[:3], 1):
    print(f"{i}. {res['基础信息']['时辰']['时辰地支']}时 - "
          f"{res['综合评分']['综合评分']}分")
```

### 分析日期范围

```python
# 分析指定日期范围内的所有日课
best_results = system.get_best_ke(
    start_date=datetime(2026, 3, 1),
    end_date=datetime(2026, 3, 31),
    shan='壬',
    top_n=10  # 返回前 10 个最佳日课
)

print("2026 年 3 月最佳 10 个日课:")
for i, res in enumerate(best_results, 1):
    date_str = res['基础信息']['公历日期']['日期字符串']
    shichen = res['基础信息']['时辰']['时辰地支']
    score = res['综合评分']['综合评分']
    print(f"{i}. {date_str} {shichen}时 - {score}分")
```

## API 参考

### RikeAnalysisSystem

#### `__init__(weight_config=None)`
初始化日课分析系统

**参数**:
- `weight_config`: 权重配置对象，默认使用标准配置 (斗首 40%、演禽 30%、大六壬 30%)

#### `analyze_single_ke(date, shichen_index, shan)`
分析单个日课

**参数**:
- `date`: datetime 对象，公历日期
- `shichen_index`: int, 时辰索引 (1-12)
  - 1=子时，2=丑时，...，7=午时，...，12=亥时
- `shan`: str, 坐山 (24 山之一)
  - 壬、子、癸、丑、艮、寅、甲、卯、乙、辰、巽、巳、
  - 丙、午、丁、未、坤、申、庚、酉、辛、戌、乾、亥

**返回**:
- dict, 包含完整分析结果:
  - `基础信息`: 日期、四柱、坐山、时辰
  - `斗首课格分析`: 斗首分析结果
  - `演禽真法分析`: 演禽分析结果
  - `大六壬课体分析`: 大六壬分析结果
  - `综合评分`: 综合评分详情
  - `GLM 评价报告`: 完整报告文本

#### `analyze_daily_ke(date, shan, min_score=0)`
分析单日 12 个时辰的所有日课

**参数**:
- `date`: datetime 对象，公历日期
- `shan`: str, 坐山
- `min_score`: int, 最低分数筛选 (默认返回全部)

**返回**:
- list, 分析结果列表，已按综合评分降序排序

#### `analyze_date_range(start_date, end_date, shan, min_score=60, progress_callback=None)`
分析指定日期范围内的所有日课

**参数**:
- `start_date`: datetime 对象，开始日期
- `end_date`: datetime 对象，结束日期
- `shan`: str, 坐山
- `min_score`: int, 最低分数筛选 (默认 60 分)
- `progress_callback`: 进度回调函数 `callback(date, total_days, current_day)`

**返回**:
- list, 符合条件的分析结果列表，已按综合评分降序排序

#### `get_best_ke(start_date, end_date, shan, top_n=10)`
获取指定日期范围内最佳的 N 个日课

**参数**:
- `start_date`: datetime 对象，开始日期
- `end_date`: datetime 对象，结束日期
- `shan`: str, 坐山
- `top_n`: int, 返回前 N 个最佳日课

**返回**:
- list, 最佳日课列表

### ComprehensiveScorer

#### `set_weights(douhou, yanqin, daliuren)`
设置权重

**参数**:
- `douhou`: float, 斗首权重 (0-1)
- `yanqin`: float, 演禽权重 (0-1)
- `daliuren`: float, 大六壬权重 (0-1)

**要求**: 三个权重之和必须等于 1

#### `calculate_comprehensive_score(douhou_score, yanqin_score, daliuren_score)`
计算综合评分

**参数**:
- `douhou_score`: float, 斗首评分 (0-100)
- `yanqin_score`: float, 演禽评分 (0-100)
- `daliuren_score`: float, 大六壬评分 (0-100)

**返回**:
- dict, 综合评分详情:
  - `综合评分`: 最终综合分数
  - `综合吉凶`: 吉凶等级信息
  - `各单项评分`: 各模块详细评分
  - `评分详情`: 评分构成列表

## 评分标准说明

### 综合评分等级

| 分数范围 | 吉凶等级 | 说明 |
|---------|---------|------|
| 90-100 | 上上大吉 | 百事亨通，万事如意 |
| 80-89 | 上吉 | 诸事顺利，谋事可成 |
| 70-79 | 中吉 | 总体吉利，小有波折 |
| 60-69 | 小吉 | 小利，宜守不宜攻 |
| 50-59 | 吉凶参半 | 吉凶混杂，需谨慎行事 |
| 40-49 | 小凶 | 小有不利，易生波折 |
| 30-39 | 中凶 | 多有不利，诸事难成 |
| 20-29 | 大凶 | 大凶之象，灾祸难免 |
| 0-19 | 上凶 | 极凶，大灾大难 |

### 斗首课格格局

**吉格**:
- 三元辰格：三柱以上元辰，家业兴隆
- 三武格：三柱以上武财，财源广进
- 元辰旺相：元辰得令旺相
- 武财生元格：武财生山家及元辰
- 武财关鬼格：年日为武财夹克鬼破

**凶格**:
- 贪狼克元格：贪狼克山头元辰
- 破军泄气格：破军重见泄元气
- 廉子伤克格：廉子重见伤克子孙

### 演禽格局

**吉格**:
- 四吉俱全格：年月日时四禽皆吉 (95 分)
- 连续相生格：四禽连续相生 (90 分)
- 三吉格：四禽中有三禽为吉 (80 分)
- 比和格：多禽比和 (70 分)

**凶格**:
- 连续相克格：四禽连续相克 (20 分)

## 常见问题

### 1. 如何选择合适的坐山？
坐山选择需根据具体用事类型和方位确定：
- 阳宅：根据房屋坐向
- 阴宅：根据墓地坐向
- 其他用事：根据当事人生肖或方位

### 2. 权重如何设置？
默认权重 (斗首 40%、演禽 30%、大六壬 30%) 是基于传统择日学的经验配置。如需调整：
- 重视斗首：可提高斗首权重至 50-60%
- 重视演禽：可提高演禽权重
- 平衡考虑：使用默认配置

### 3. 分数多少可以使用？
建议标准:
- 80 分以上：大吉，百事可为
- 70-79 分：中吉，可用
- 60-69 分：小吉，斟酌用之
- 60 分以下：不建议使用

### 4. 如何处理结果中的"待实现"模块？
当前大六壬课体分析模块和辅助信息模块尚未完全集成，使用占位分数。后续将完善这些模块。
