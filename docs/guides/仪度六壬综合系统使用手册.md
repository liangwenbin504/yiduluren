# 仪度六壬综合系统使用手册

## 系统概述

本系统基于《仪度六壬选日要诀》注解，建立了六壬课格标准化评分体系和斗首六壬权衡算法，提供完整的择日决策支持。

## 核心功能

### 1. 六壬课格评分系统（10 分制）

#### 评分指标及权重

| 指标 | 权重 | 说明 |
|------|------|------|
| 课格吉凶本质 | 30% | 课格本身的吉凶属性（龙德、天赦等） |
| 三吉神将 | 25% | 贵人、禄、马的出现情况 |
| 五行生克 | 20% | 三传四课的五行生克关系 |
| 神煞组合 | 15% | 吉神凶煞的组合 |
| 旺相休囚 | 10% | 月令和时辰的旺衰 |

#### 吉凶等级划分

| 分数范围 | 吉凶等级 | 使用建议 |
|---------|---------|---------|
| 9.0-10.0 | 上上大吉 | 最吉利，百事皆宜 ⭐⭐⭐ |
| 8.0-8.9 | 上吉 | 非常吉利，适合重要事项 ⭐⭐ |
| 7.0-7.9 | 中吉 | 吉利，适合一般事项 ⭐ |
| 6.0-6.9 | 小吉 | 略有吉利，可使用 |
| 5.0-5.9 | 吉凶参半 | 需谨慎使用 |
| 4.0-4.9 | 小凶 | 不太吉利，不建议使用 |
| 3.0-3.9 | 中凶 | 凶险，避免使用 |
| 2.0-2.9 | 大凶 | 很凶险，严禁使用 |
| 0.0-1.9 | 上凶 | 极凶，绝对不可使用 |

### 2. 斗首法评分系统

| 课格 | 评分 | 吉凶 | 可用性 |
|------|------|------|--------|
| 武财课 | 9.0 | 上上大吉 | ✓ 推荐使用 |
| 元辰课 | 8.5 | 上吉 | ✓ 推荐使用 |
| 廉贞课 | 6.0 | 小吉 | ✓ 推荐使用 |
| 贪狼课 | 3.0 | 中凶 | ✗ 不建议使用 |
| 破军课 | 2.5 | 大凶 | ✗ 不建议使用 |

### 3. 权衡算法

#### 优先级规则

1. **斗首法优先级 > 六壬课格优先级**
2. 先筛选斗首最吉日期，再匹配六壬最吉课格
3. 逐级匹配，直至找到合适的组合

#### 匹配策略

```
步骤 1：应用斗首法对日期范围内的所有日期进行吉凶评估并排序
步骤 2：筛选出最吉日期（斗首评分≥要求）
步骤 3：将斗首最吉日期与六壬最吉课格进行匹配验证
步骤 4：若最吉斗首日期无法匹配最吉六壬课格，则：
  - 选择次吉斗首日期继续尝试匹配最吉六壬课格
  - 或保持最吉斗首日期不变，尝试匹配次吉六壬课格
步骤 5：以此类推，逐级匹配
```

#### 匹配优先级

**斗首优先级**：上上大吉 > 上吉 > 中吉 > 小吉

**六壬优先级**：上上大吉 > 上吉 > 中吉 > 小吉 > 吉凶参半

## 系统使用

### 方法一：GUI 界面

#### 启动综合系统
```bash
python src\ui\comprehensive_gui.py
```

#### 功能一：六壬课格评分查看

1. **搜索课格**：在搜索框输入课格名称（如"龙德"）
2. **分类浏览**：选择吉凶等级查看对应课格
3. **查看详情**：点击课格查看详细信息和评分

#### 功能二：综合择日（正确流程）

**重要：斗首择日的正确顺序**

1. **第一步：选择坐山**
   - 从下拉列表选择二十四山（如"壬山"）
   - 系统自动显示该山的元辰和五行
   - 例如：壬山 → 元辰甲己，五行土

2. **第二步：设置日期范围**
   - 输入开始日期和结束日期
   - 建议至少 30 天范围

3. **第三步：设置评分要求**
   - 斗首最低评分：一般 7.0 分（中吉），重要事项 8.0 分（上吉）
   - 六壬最低评分：一般 7.0 分（中吉）

4. **第四步：开始择日**
   - 点击"【第四步】开始择日"按钮
   - 系统按以下流程执行：
     a. 根据坐山元辰筛选斗首吉课
     b. 对日期进行斗首评分排序
     c. 匹配六壬吉课
     d. 输出最佳组合

5. **查看结果**
   - 最佳日期
   - 斗首课格及评分
   - 六壬课格及评分
   - 完整决策依据

## 系统架构

### 核心模块

1. **`src/engine/kejing_scoring.py`**
   - 六壬课格评分系统
   - 10 分制评分算法
   - 吉凶等级判断

2. **`src/engine/comprehensive_selector.py`**
   - 综合择日权衡算法
   - 斗首六壬匹配策略
   - 日期 ranking 系统

3. **`src/engine/douhou_kege_system.py`**
   - 斗首课格系统
   - 第一斗首课格断语
   - 评分和可用性判断

4. **`src/engine/douhou_shan_jia_system.py`**
   - 二十四山课格系统
   - 各山评分和断语

### GUI 模块

**`src/ui/comprehensive_gui.py`**
- 课格评分查看器
- 综合择日界面
- 结果展示和决策依据

## 使用示例

### 示例 1：查询课格评分

```python
from kejing_scoring import KeJingScoring

scoring = KeJingScoring()

# 获取基础分
score = scoring.calculate_score('龙德', [], [], [])
print(f"龙德课基础分：{score}")  # 9.5 分

# 计算综合分（有贵人、天德）
comprehensive_score = scoring.calculate_score(
    '龙德', 
    ['贵人', '禄神'],  # 三吉
    ['天德', '月德'],  # 吉神
    []  # 凶煞
)
print(f"龙德课综合分：{comprehensive_score}")

# 判断吉凶等级
level = scoring.get_score_level(comprehensive_score)
print(f"吉凶等级：{level}")
```

### 示例 2：综合择日

```python
from comprehensive_selector import ComprehensiveSelector
from datetime import datetime, timedelta

selector = ComprehensiveSelector()

# 择日
start = datetime.now()
end = start + timedelta(days=30)

best_match, history = selector.select_auspicious_date(
    start, 
    end,
    min_doushou_score=7.0,  # 斗首中吉以上
    min_kejing_score=7.0    # 六壬中吉以上
)

if best_match:
    print(f"最佳日期：{best_match['date'].strftime('%Y-%m-%d')}")
    print(f"斗首课格：{best_match['doushou_kege']} ({best_match['doushou_score']:.1f}分)")
    print(f"六壬课格：{best_match['kejing']} ({best_match['kejing_score']:.1f}分)")
```

### 示例 3：判断课格可用性


## 决策依据说明

系统择日时遵循以下原则：

1. **斗首优先原则**：斗首法吉凶判断优先级高于六壬课格
2. **逐级匹配原则**：从最吉等级开始逐级向下匹配
3. **最优组合原则**：在满足最低要求的前提下，寻找最优组合
4. **灵活调整原则**：可根据实际情况调整最低评分要求

## 注意事项

1. **评分标准**：5 分以下为凶课，不建议使用
2. **日期范围**：建议至少提供 30 天的日期范围
3. **评分要求**：一般事项建议 7.0 分以上，重要事项建议 8.0 分以上
4. **特殊情况**：若未找到合适日期，可扩大范围或降低要求

## 系统优势

1. **标准化评分**：10 分制评分体系，直观易懂
