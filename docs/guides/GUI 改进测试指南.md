## 常见问题排查

### 问题 1：下拉框无法选择

**现象**：点击下拉框无反应

**排查**：
1. 检查 `state="readonly"` 是否正确设置
2. 检查是否有其他窗口遮挡
3. 重启程序

**解决**：
- 确保程序正常运行
- 检查 tkinter 版本

---

### 问题 2：山向不自动匹配

**现象**：选择坐山后，朝向不变

**排查**：
1. 检查 `_on_shan_xiang_change` 方法是否绑定
2. 查看控制台是否有错误信息
3. 检查 `SHAN_XIANG_PAIRS` 字典是否正确

**解决**：
- 重新绑定事件：`self.shan_combo.bind('<<ComboboxSelected>>', self._on_shan_xiang_change)`
- 检查配对关系字典

---

### 问题 3：结果显示窗口不更新

**现象**：择日完成后，右侧窗口仍显示提示信息

**排查**：
1. 检查 `_selection_finished` 方法是否调用 `_update_date_result_display()`
2. 检查 `self.results` 是否有数据
3. 查看控制台错误信息

**解决**：
- 确保在 `_selection_finished` 中调用 `_update_date_result_display()`
- 检查结果数据格式是否正确

---

### 问题 4：结果显示格式混乱

**现象**：日期结果格式不正确或乱码

**排查**：
1. 检查字体设置是否正确
2. 检查文本编码
3. 查看是否有特殊字符

**解决**：
- 确保使用 `font=('Microsoft YaHei UI', 9)`
- 使用 UTF-8 编码保存文件
- 检查字符串格式化语法

## 快速验证脚本

如果需要自动化验证，可以使用以下脚本：

```python
import tkinter as tk
from tkinter import ttk

# 创建测试窗口
root = tk.Tk()
root.title("山向选择测试")

# 测试下拉框
shan_combo = ttk.Combobox(root, values=['壬', '子', '癸', '丑'], state="readonly")
shan_combo.pack(pady=10)
shan_combo.set('壬')

def on_change(event):
    print(f"选择：{shan_combo.get()}")

shan_combo.bind('<<ComboboxSelected>>', on_change)

root.mainloop()
```
