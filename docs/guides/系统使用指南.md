# 仪度六壬择日系统 - 壬山丙向安葬择日集成指南

## 一、系统概述

**仪度六壬择日系统**是一个基于传统六壬择日法、斗首择日法、高精度历法计算的综合性风水择日系统。本系统专为壬山丙向阴宅安葬事宜设计，综合考虑以下要素：

- ✅ 龙德课（太岁/月将乘贵人发用）
- ✅ 斗首择日（元辰、武财、廉贞、破军等课格）
- ✅ 六壬课格（三光、天福、玉堂等吉课）
- ✅ 吉神凶煞（天德、月德、三煞、五黄等）
- ✅ 山向宜忌（壬山丙向的特殊要求）
- ✅ 五行生克（天干地支的生克制化）
- ✅ 九星方位（紫白九星的吉凶）
- ✅ 禄马贵到山到向（贵人、禄神、驿马出现在坐山或朝向）

### 2.2 核心类说明

#### `PreciseCalendar` - 高精度历法类
**位置**：`src/engine/precise_calendar.py`

**主要方法**：
- `get_sizhu_precise(year, month, day, hour, city_name)` - 精确计算四柱
- `get_year_ganzhi(year, month, day)` - 获取年柱
- `get_month_ganzhi(year, month, day)` - 获取月柱
- `_calculate_true_solar_time(hour, minute, longitude, date)` - 计算真太阳时
- `_calculate_equation_of_time_precise(date)` - 精确计算均时差

**示例**：
```python
from precise_calendar import PreciseCalendar

calendar = PreciseCalendar()
sizhu = calendar.get_sizhu_precise(2026, 9, 9, 10, city_name='北京')
print(f"四柱：{sizhu['年柱']}年 {sizhu['月柱']}月 {sizhu['日柱']}日 {sizhu['时柱']}时")
# 输出：四柱：丙午年 己酉月 丙戌日 癸巳时
```

#### `LongDeKeSelector` - 龙德课择日引擎
**位置**：`src/engine/long_de_ke_selector.py`

**主要方法**：
- `is_long_de_ke(ri_ganzhi, yue_jiang, tai_sui, sanchuan)` - 判断是否为龙德课
- `check_lu_ma_gui_dao_shan(ri_ganzhi, shi_ganzhi, shan_xiang)` - 检查禄马贵到山到向
- `select_dates(start_date, end_date, shan_xiang)` - 选择龙德课吉日

**示例**：
```python
from long_de_ke_selector import LongDeKeSelector

selector = LongDeKeSelector()
ri_ganzhi = '丙戌'
yue_jiang = '酉'
tai_sui = '午'
sanchuan = {'初传': '酉', '中传': '', '末传': ''}

is_long_de, long_de_type = selector.is_long_de_ke(ri_ganzhi, yue_jiang, tai_sui, sanchuan)
print(f"龙德课：{is_long_de}, 类型：{long_de_type}")
# 输出：龙德课：True, 类型：月将龙德课（光明之象）
```

#### `RenShanFengShuiSelector` - 壬山丙向择日系统
**位置**：`ren_shan_feng_shui_selector.py`

**主要方法**：
- `check_douhou_kege(year, month, day)` - 检查斗首课格
- `check_ji_shen_xiong_sha(year, month, day)` - 检查吉神凶煞
- `check_lu_ma_gui_dao_shan(year, month, day, hour)` - 检查禄马贵到山到向
- `select_an_zang_dates(start_date, end_date, min_score)` - 选择安葬吉日
- `generate_report(results, output_file)` - 生成择日报告

**示例**：
```python
from ren_shan_feng_shui_selector import RenShanFengShuiSelector
from datetime import datetime

selector = RenShanFengShuiSelector()
start_date = datetime(2026, 3, 15)
end_date = datetime(2027, 12, 31)

results = selector.select_an_zang_dates(start_date, end_date, min_score=6.0)
print(f"找到 {len(results)} 个吉日")

# 生成报告
selector.generate_report(results, 'ren_shan_an_zang_report.txt')
```

## 四、技术细节

### 4.1 综合评分算法

**评分公式**：
```
总评分 = 斗首课格评分 × 40% + 吉神凶煞评分 × 30% + 禄马贵数量 × 30%
```

**权重分配**：
- **斗首课格（40%）**：决定基本吉凶格局
- **吉神凶煞（30%）**：决定神煞吉凶
- **禄马贵（30%）**：决定到山到向的吉利程度

**评分示例**（2026 年 9 月 9 日）：
- 斗首课格：9.0 分（武财课）× 40% = 3.6 分
- 吉神凶煞：2 分（月德）× 30% = 0.6 分
- 禄马贵：7 个 × 30% = 2.1 分
- **总评分**：3.6 + 0.6 + 2.1 = 6.3 分

### 4.2 龙德课判断逻辑

**龙德课条件**：
1. **发用**：太岁或月将出现在初传
2. **乘贵人**：初传为日干的天乙贵人

**判断流程**：
```python
def is_long_de_ke(ri_ganzhi, yue_jiang, tai_sui, sanchuan):

        return False, None
    
    # 2. 检查初传是否为日干贵人
    ri_gan = ri_ganzhi[0]
    gui_map = {...}  # 贵人映射表
    if sanchuan['初传'] in gui_map[ri_gan]:
        if sanchuan['初传'] == tai_sui:
            return True, "太岁龙德课（岁君赐福）"
        else:
            return True, "月将龙德课（光明之象）"

```

### 4.3 斗首课格判断

**斗首五行化气**：

## 六、常见问题

### Q1: 为什么找不到日期？

**原因**：评分标准过高或择日范围过小

**解决方法**：
1. 降低 `min_score` 参数（如从 7.0 降至 6.0）
2. 扩大择日范围（如从 3 个月扩大至 1 年）
3. 检查是否有大凶煞（岁破、月破等）排除所有日期

### Q2: 如何为其他山向择日？

**方法**：修改 `RenShanFengShuiSelector` 类中的山向信息

```python
self.shan_xiang_info = {
    '坐山': 'X',  # 修改为所需山向
    '朝向': 'Y',
    '山家五行': 'X',
    '元辰': 'XX',
    '禄位': 'X',
    '马位': 'X',
    '贵人': ['X', 'Y'],
    '武财': 'XX',
    ...
}
```

### Q3: 真太阳时如何影响择日？

**影响**：时柱的地支由真太阳时决定

**示例**：
- 北京时间 10:00（平太阳时）= 巳时
- 北京真太阳时 9:44 = 巳时（不变）
- 成都真太阳时 8:55 = 辰时（改变）

**建议**：使用 `get_sizhu_precise()` 并指定城市名称，自动计算真太阳时

### Q4: 如何验证历法准确性？

**验证方法**：
1. 对比万年历（如寿星万年历、八字万年历）
2. 使用天文算法验证节气时刻
3. 检查四柱是否符合传统规则（立春换年柱、节气换月柱等）

**测试案例**：
```python
from precise_calendar import get_sizhu_accurate

# 2026 年 9 月 4 日
sizhu = get_sizhu_accurate(2026, 9, 4, 12, city_name='北京')
print(sizhu)
# 应为：丙午年 己酉月 辛巳日 甲午时

# 验证：2026 年白露=9 月 8 日，9 月 4 日仍在己酉月
# 日柱：辛巳日（查万年历验证）
```
