### 排序规则

- **默认**：按综合评分从高到低排序
- 综合评分 = 六壬评分×60% + 斗首评分×40% + 额外加分
- 额外加分项：
  - 龙德课：+2.0 分
  - 多课格（≥3）：+0.5 分
  - 有大吉课（≥9.0）：+1.0 分

## 常见问题解答

### Q1: 为什么无结果？

**可能原因**：
1. 最低评分设置过高（>8.0）
2. 斗首课格限制过严（特定课格）
3. 日期范围过小（<30 天）
4. 课格选择过多（同时选多个课体）

**解决方法**：
```
1. 降低最低评分至 5.0 或 6.0
2. 将斗首课格改为"全部"
3. 扩大日期范围至 3-6 个月
4. 不选课格让系统自动筛选
```

### Q2: 结果太多怎么办？

**解决方法**：
1. 提高最低评分至 7.0 或 8.0
2. 选择特定的吉课课体（如龙德课）
3. 只看综合评分前 10% 的日期
4. 缩小日期范围至 1-2 个月

### Q3: 如何选择最佳日期？

**推荐步骤**：
1. 使用默认配置（5.0 分）获得所有结果
2. 按综合评分排序
3. 查看前 20 个结果的四柱和课体
4. 选择综合评分高且课体吉利的日期
5. 结合实际需求（如周末、节假日）

### Q4: 六壬分值优先如何体现？

**计算示例**：
```
日期：2026-03-15 子时
课体：龙德课 (10.0 分)，富贵课 (9.5 分)，荣华课 (8.5 分)

六壬评分计算：
- 最高分：10.0
- 平均分：(10.0 + 9.5 + 8.5) / 3 = 9.33
- 六壬最终分：10.0×0.6 + 9.33×0.4 = 9.73

斗首评分：8.5（元辰课）

综合评分：
= 六壬 9.73×60% + 斗首 8.5×40% + 龙德课加分 2.0
= 5.84 + 3.40 + 2.0
= 11.24（四舍五入：11.2）
```

## 最佳实践建议

### 初次使用

1. **使用默认配置**：
   - 最低评分：5.0
   - 斗首课格：全部
   - 不选课格
   
2. **查看结果分布**：
   - 观察最高分和最低分
   - 了解评分范围
   
3. **逐步提高要求**：
   - 第一次：5.0 分，看整体
   - 第二次：6.0 分，看优质
   - 第三次：7.0 分，看精品

### 高级使用

1. **针对性筛选**：
   - 明确需求（如必须龙德课）
   - 设置特定课体
   - 提高评分至 7.0+
   
2. **多方案对比**：
   - 方案 A：3 个月，6.0 分
   - 方案 B：6 个月，7.0 分
   - 对比结果质量和数量

3. **结合实际情况**：
   - 排除节假日
   - 考虑天气因素
   - 协调人员时间
