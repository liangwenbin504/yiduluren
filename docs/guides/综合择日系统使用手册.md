# 仪度六壬综合择日系统使用手册

## 一、系统概述

**仪度六壬综合择日系统**是一个集成了斗首择日法和大六壬六壬课体判断的专业择日系统。该系统能够在图形用户界面（GUI）中准确匹配并展示斗首法和大六壬相关内容，帮助用户快速找到符合特定条件的最佳日期。

### 1.1 核心功能

1. **山向选择**：支持 24 山向的任意组合
2. **日期范围**：灵活设置择日日期范围
3. **条件筛选**：
   - 斗首课格（元辰、武财、贪狼、廉贞、破军）
   - 最低评分（0-10 分）
   - 六壬吉课（龙德课、富贵课、三光课等）
4. **结果展示**：表格化显示，支持排序和导出
5. **详细分析**：双击查看完整的课格解析

### 1.2 技术特点

- **斗首择日法**：完整的 5 种课格断语和评分系统
- **大六壬课体**：64 课经完整判断逻辑
- **龙德课筛选**：太岁/月将龙德课自动识别
- **高精度历法**：精确节气计算，真太阳时支持
- **多线程处理**：后台计算，不阻塞界面

## 三、详细使用步骤

### 3.1 第一步：选择山向

#### 3.1.1 选择坐山和朝向

1. **坐山选择**：
   - 点击"坐山"下拉框
   - 从 24 山中选择所需山向
   - 24 山：壬子癸丑艮寅甲卯乙辰巽巳丙午丁未坤申庚酉辛戌乾亥

2. **朝向选择**：
   - 点击"朝向"下拉框
   - 选择与坐山相对的朝向
   - 常用山向组合：
     - 壬山丙向（坐北朝南）
     - 子山午向（正北正南）
     - 艮山坤向（坐东北朝西南）
     - 甲山庚向（坐东朝西）

3. **互换山向**：
   - 点击"互换山向"按钮
   - 快速交换坐山和朝向
   - 用于快速测试不同组合

#### 3.1.2 查看山向信息

选择山向后，系统会显示该山向的基本信息：
- 山家五行
- 禄马贵方位
- 喜忌地支
- 元辰、武财等

**示例**：
```
坐壬山朝丙向
山家五行：火
元辰：甲己
武财：丙辛
禄位：亥
马位：巳
贵人：巳、卯
喜用：寅卯辰巳申酉戌亥
忌用：子丑午未
```

### 3.2 第二步：选择日期范围

#### 3.2.1 手动输入日期

- **开始日期**：输入起始日期（格式：YYYY-MM-DD）
- **结束日期**：输入结束日期（格式：YYYY-MM-DD）

**示例**：
```
开始日期：2026-03-15
结束日期：2027-12-31
```

#### 3.2.2 快捷日期范围

点击"选择范围"按钮，快速设置：

- **当年**：当年 1 月 1 日至 12 月 31 日
- **半年**：今天起 180 天
- **两年**：今天起 730 天

**示例**：
```
今天是 2026-03-15
选择"半年" → 2026-03-15 至 2026-09-11
选择"当年" → 2026-01-01 至 2026-12-31
```

### 3.3 第三步：设置筛选条件

#### 3.3.1 斗首课格筛选

**斗首课格**是斗首择日法的核心，分为 5 种：

1. **元辰课**（8.5 分）
   - 日干为甲或己
   - 断语：甲己化戊土元辰，催丁生子富贵上吉
   - 适用：催丁、求子、建房

2. **武财课**（9.0 分）⭐ 最吉
   - 日干为丙或辛
   - 断语：丙辛武才多富贵，乙庚单干正财丁
   - 适用：求财、安葬、开业

3. **贪狼课**（7.0 分）
   - 日干为乙或庚
   - 断语：乙庚单干正财丁
   - 适用：求财、婚姻

4. **廉贞课**（6.0 分）
   - 日干为丁或壬
   - 断语：丁壬廉贞子孙旺
   - 适用：求子、考试

5. **破军课**（2.5 分）❌ 大凶
   - 日干为戊或癸
   - 断语：戊癸破军泄元气，凶
   - 忌用：所有事宜

**筛选选项**：
- **全部**：不过滤课格类型
- **元辰课**：只选元辰课
- **武财课**：只选武财课（推荐）
- **贪狼课**：只选贪狼课
- **廉贞课**：只选廉贞课
- **破军课**：一般不选

#### 3.3.2 最低评分设置

**评分范围**：0-10 分，步进 0.5 分

**推荐设置**：
- **≥ 9.0 分**：上上大吉（极难找到）
- **≥ 8.0 分**：上吉（很难找到）
- **≥ 7.0 分**：中吉（推荐）
- **≥ 6.0 分**：小吉（默认）
- **≥ 5.0 分**：平（能找到较多）

**示例**：
```
设置 6.0 分：能找到约 16 个日期（一年范围）
设置 7.0 分：能找到约 8 个日期（一年范围）
设置 8.0 分：可能找不到日期
```

## 五、常见问题

### Q1: 为什么找不到符合条件的日期？

**可能原因**：
1. 筛选条件过严（如评分≥9.0）
2. 日期范围过小（如只有 1 个月）
3. 山向特殊，符合条件的日期少

**解决方法**：
1. 降低最低评分（如从 9.0 降至 7.0）
2. 扩大日期范围（如从 3 个月扩大至 1 年）
3. 放宽课格要求（如从"武财课"改为"全部"）
4. 取消"仅龙德课"选项

### Q2: 如何为不同用途选择课格？

**安葬**：
- 首选：武财课（催财）
- 次选：元辰课（催丁）
- 忌用：破军课

**入宅**：
- 首选：元辰课（人丁兴旺）
- 次选：武财课（财源广进）

**开业**：
- 首选：武财课（财运亨通）
- 次选：贪狼课（生意兴隆）

**结婚**：
- 首选：贪狼课（夫妻和睦）
- 次选：廉贞课（子孙兴旺）

**考试**：
- 首选：廉贞课（文运亨通）
- 次选：玉堂课（金榜题名）

### Q3: 评分标准是什么？

**斗首课格评分**：
- 武财课：9.0 分（最吉）
- 元辰课：8.5 分（上吉）
- 贪狼课：7.0 分（中吉）
- 廉贞课：6.0 分（小吉）
- 破军课：2.5 分（大凶）

**推荐指数**：
- ★★★★★ 上上大吉（≥9.0 分）
- ★★★★☆ 上吉（≥8.0 分）
- ★★★☆☆ 中吉（≥7.0 分）
- ★★☆☆☆ 小吉（≥6.0 分）
- ★☆☆☆☆ 平（≥5.0 分）

### Q4: 如何查看完整的课体断语？

**方法 1**：双击结果查看详情
- 显示课格断语
- 显示龙德课类型
- 显示吉神凶煞

**方法 2**：导出结果后查看
- 文本文件包含完整信息
- 可以打印或分享

**方法 3**：使用课经查看器
- 运行：启动课经查看器.bat
- 查询 64 课经完整断语

### Q5: 真太阳时如何使用？

系统已自动计算真太阳时：
- 根据城市经纬度自动计算
- 时柱地支基于真太阳时
- 无需手动设置

如需指定城市：
- 修改代码中的 `city_name` 参数
- 支持 60+ 中国城市
