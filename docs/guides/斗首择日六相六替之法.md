# 斗首择日 - 六相六替之法

## 理论来源

依据《仪度六壬选日要诀》及《斗首择日秘本》整理

## 一、核心理论

### 1. 三元理论

斗首论三元，以：
- **天元**：四天干在上（天干化气）
- **地元**：四地支在下（地支）
- **人元**：遁五子遁遁元到山者（山家五行）

**应用原则**：
- 天元为明用
- 地元为暗用
- 人元为山家根本

### 2. 六相（五星）

六相是指斗首五行与四柱化气的六种相生相克关系：

| 六亲 | 五行关系 | 别名 | 吉凶 |
|------|----------|------|------|
| 元辰 | 同我者（比和） | 吉神 | 吉 |
| 武财 | 我克者（克出） | 妻财 | 吉 |
| 贪狼 | 生我者（生入） | 官星 | 凶 |
| 廉贞 | 我生者（生出） | 子孙 | 吉凶参半 |
| 破军 | 克我者（克入） | 鬼贼 | 凶 |

### 3. 六替（番化五行）

六替是指番化五行的六种转化规律，核心秘诀：

**番化诀**：
```
元元武化贪，官鬼子孙财

详解：
- 元辰番化是元辰（不变）
- 武财化贪官（武财→贪狼）
- 贪官化破鬼（贪狼→破军）
- 破鬼化廉子（破军→廉贞）
- 廉子化武财（廉贞→武财）
```

**循环关系**：
```
元辰 → 元辰
武财 → 贪狼 → 破军 → 廉贞 → 武财（循环）
```

## 二、二十四山斗首五行

```
壬子巽巳辛戌土，艮寅丁未木元辰。
癸丑丙午乾亥火，坤申甲卯属水神。
若问金星何处是，乙庚辰酉四山真。
```

### 详细分类

| 五行 | 二十四山 |
|------|----------|
| 土山 | 壬、子、巽、巳、辛、戌 |
| 火山 | 癸、丑、丙、午、乾、亥 |
| 木山 | 艮、寅、丁、未 |
| 水山 | 坤、申、甲、卯 |
| 金山 | 乙、辰、庚、酉 |

## 三、十天干化气五行

```
甲己化土，乙庚化金，丙辛化水，丁壬化木，戊癸化火。
```

## 四、六相六替计算方法

### 步骤 1：确定山家五行

根据坐山查表获取斗首五行。

### 步骤 2：确定天干化气

根据四柱天干查化气五行。

### 步骤 3：确定六相（五星）

以山家五行为"我"，比较化气五行：
- 同我者为**元辰**
- 我克者为**武财**
- 生我者为**贪狼**
- 我生者为**廉贞**
- 克我者为**破军**

### 步骤 4：计算番化五行

根据六替诀计算每柱的番化五行。

## 五、课格格局

### 吉格

1. **三元辰格**
   - 条件：三柱以上元辰
   - 特征：元辰会一家，人丁大旺
   - 评分：95 分以上

2. **三武格**
   - 条件：三柱以上武财
   - 特征：武财会一家，财源广进
   - 评分：95 分以上

3. **武财生元格**
   - 条件：武财生山家及元辰
   - 特征：吉格，只宜阴宅
   - 评分：90 分以上

4. **元辰旺相格**
   - 条件：元辰临月令长生、临官、帝旺
   - 特征：家业兴隆，子孙昌盛
   - 评分：85-95 分

5. **武财关鬼格**
   - 条件：年日为武财夹克月柱破军
   - 特征：制伏凶星，可用之吉课
   - 评分：70-80 分

### 凶格

1. **三重贪狼格**
   - 条件：三柱以上贪狼
   - 特征：贪狼克元辰，大凶
   - 评分：20 分以下

2. **廉子重见格**
   - 条件：两柱以上廉贞
   - 特征：伤克子孙，损父母
   - 评分：30-40 分

3. **破鬼重见格**
   - 条件：两柱以上破军
   - 特征：鬼煞坐长生，大凶
   - 评分：20 分以下

## 六、吉凶判断规则

### 元辰
- 宜：生旺，临长生、临官、帝旺
- 忌：衰弱、受克、入墓
- 特殊情况：元辰旺宜见一位廉子，大旺人丁

### 武财
- 宜：生旺，不受克
- 忌：受克、衰弱
- 特殊情况：年月双武生山家，大吉

### 贪狼
- 宜：有武财通关
- 忌：重见、克元辰
- 特殊情况：一位贪狼需制伏

### 廉贞
- 宜：元辰旺时见一位
- 忌：元辰衰时见、重见
- 特殊情况：元辰旺见一位廉子，大旺人丁

### 破军
- 宜：衰弱、被制伏
- 忌：重见、坐长生
- 特殊情况：武财夹克可用（武财关鬼格）

## 八、应用实例

### 案例 1：上上大吉课

**日课**：2026 年 3 月 31 日未时 壬山

**四柱**：
```
年柱：丙午 - 丙化水 - 武财 - 番化木
月柱：辛卯 - 辛化水 - 武财 - 番化木
日柱：甲辰 - 甲化土 - 元辰 - 番化土
时柱：辛未 - 辛化水 - 武财 - 番化木
```

**六相统计**：
- 武财：3 重（三武格）
- 元辰：1 重

**格局判断**：
- 三武格（上吉）
- 武财会一家，财源广进

**评分**：95 分（上上大吉）

### 案例 2：大凶课

**日课**：丙山 辛丑年 辛丑月 丙申日 丙申时

**四柱**：
```
年柱：辛丑 - 辛化水 - 破军 - 番化土
月柱：辛丑 - 辛化水 - 破军 - 番化土
日柱：丙申 - 丙化水 - 破军 - 番化土
时柱：丙申 - 丙化水 - 破军 - 番化土
```

**六相统计**：
- 破军：4 重（破鬼重见）

**格局判断**：
- 破鬼重见本已凶
- 鬼煞又坐长生申位
- 山头元辰无位，反病于申位

**评分**：15 分（上凶）

**应验**：用后不到两个月，为被盗命而败家

## 九、注意事项

1. **元辰入墓**
   - 阳宅：日久必绝嗣
   - 阴宅：可用

2. **廉子重见**
   - 伤克子孙
   - 损父母

3. **贪狼夹克**
   - 元辰受克，虽有如无

4. **破鬼坐长生**
   - 大凶，主败家

5. **三元合法**
   - 柱中要重见三重元辰或三重武财
   - 山方得时令旺相
   - 化气逢长生、冠带、临官、帝旺、墓库、胎养之支

## 十一、结语

斗首择日法是以山家斗首五行为体，四柱天干化气为用，通过六相六替的转化关系，判断日课的吉凶。其核心在于：

1. **明辨三元**：天元、地元、人元的配合
2. **精通六相**：元辰、武财、贪狼、廉贞、破军的生克关系
3. **掌握六替**：番化五行的循环转化规律
4. **权衡吉凶**：综合判断，趋吉避凶

学者需熟记歌诀，灵活运用，方能准确判断日课吉凶。
