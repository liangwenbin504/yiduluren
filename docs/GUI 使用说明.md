## 🔧 使用步骤

### 快速测试

1. **点击快捷测试按钮**
   - 点击"伏吟课"、"反吟课"或"普通课"
   - 系统自动填入测试参数

2. **点击"起课"按钮**
   - 系统开始计算四课三传
   - 排布天将、计算神煞
   - 判断课体类型
   - 匹配 64 课经

3. **查看结果**
   - 右上：查看完整课式排盘
   - 右下：查看匹配的课经信息

### 手动起课

1. **选择日干支**
   - 从下拉列表中选择 60 甲子之一

2. **选择月将**
   - 根据农历月份选择对应的月将

3. **选择占时**
   - 选择占卜的时辰

4. **设置神煞参数**
   - 农历月份（1-12 月）
   - 年支（子 - 亥）

5. **点击"起课"**
   - 查看完整结果

## 💡 使用技巧

1. **先看课体判断**
   - 快速了解课式特征
   - 伏吟、反吟等特殊课体优先识别

2. **重点看三传**
   - 三传是课式的核心
   - 起法决定了推导逻辑

3. **参考神煞**
   - 神煞提供额外信息
   - 禄马贵等吉神重要

4. **细读课经断语**
   - 传统断语精炼准确
   - 结合多个课经综合判断

## 🛠️ 故障排除

### 如果 GUI 无法启动
1. 检查 Python 是否安装 Tkinter
2. 检查依赖模块是否完整
3. 查看错误信息并修复

### 如果起课失败
1. 检查输入参数是否正确
2. 检查日干支是否在 60 甲子范围内
3. 查看错误提示

### 如果匹配结果为空
1. 某些课式可能确实无特殊课经
2. 检查课体判断是否准确
3. 系统会自动使用基本九宗门方法 fallback
