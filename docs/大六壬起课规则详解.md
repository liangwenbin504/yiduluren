# 大六壬起课规则详解

## 概述

大六壬起课法是中国传统预测学的核心技法，包含月将确定、占时选取、天地盘排布、四课推导、三传发用等完整流程。本文档基于《仪度六壬选日要诀》注解，系统阐述起课法的完整规则与实现。

---

## 第一章：月将确定法

### 1.1 月将概念

**月将**者，日所舍之辰也。即太阳在黄道上所处的位置，用十二地支表示。

### 1.2 中气换将法

月将的确定遵循**中气换将**原则：

| 中气 | 月份 | 月将 | 月将名 |
|------|------|------|--------|
| 雨水 | 正月 | 亥 | 登明 |
| 春分 | 二月 | 戌 | 河魁 |
| 谷雨 | 三月 | 酉 | 从魁 |
| 小满 | 四月 | 申 | 传送 |
| 夏至 | 五月 | 未 | 小吉 |
| 大暑 | 六月 | 午 | 胜光 |
| 处暑 | 七月 | 巳 | 太乙 |
| 秋分 | 八月 | 辰 | 天罡 |
| 霜降 | 九月 | 卯 | 太冲 |
| 小雪 | 十月 | 寅 | 功曹 |
| 冬至 | 十一月 | 丑 | 大吉 |
| 大寒 | 十二月 | 子 | 神后 |

### 1.3 月将计算规则

```python
# 核心规则：中气后换将
- 雨水（2 月 19 日左右）后 → 亥将
- 春分（3 月 21 日左右）后 → 戌将
- 未到中气前，仍用上个月的月将

# 示例
2024 年 2 月 15 日（雨水前）→ 仍用子将（大寒后）
2024 年 2 月 25 日（雨水后）→ 改用亥将
```

### 1.4 注意事项

1. **精确计算**：月将应以节气为准，而非农历月份
2. **交节时刻**：中气交节时刻后即刻换将
3. **节气查询**：实际应用中应使用精确的天文算法计算节气

## 第二章：占时选取法

### 2.1 占时概念

**占时**即占测的时辰，用于月将加临。传统以十二地支表示一日十二时辰。

### 2.2 时辰对应

| 时辰 | 地支 | 现代时间 |
|------|------|----------|
| 子时 | 子 | 23:00-01:00 |
| 丑时 | 丑 | 01:00-03:00 |
| 寅时 | 寅 | 03:00-05:00 |
| 卯时 | 卯 | 05:00-07:00 |
| 辰时 | 辰 | 07:00-09:00 |
| 巳时 | 巳 | 09:00-11:00 |
| 午时 | 午 | 11:00-13:00 |
| 未时 | 未 | 13:00-15:00 |
| 申时 | 申 | 15:00-17:00 |
| 酉时 | 酉 | 17:00-19:00 |
| 戌时 | 戌 | 19:00-21:00 |
| 亥时 | 亥 | 21:00-23:00 |

### 2.3 取时方法

1. **正时法**：以占测时的实际时辰为准（最常用）
2. **活时法**：以抽签、报数等方式取时
3. **值时法**：以日支三合局取时

## 第三章：天地盘排布法

### 3.1 天地盘概念

- **地盘**：固定不动的十二地支方位
- **天盘**：随月将加时转动的十二地支

### 3.2 月将加时法

**核心规则**：月将加在占时之上，顺布十二宫

```
公式：天盘子位 = (地盘时支位置 - 月将位置) % 12

示例：亥将午时
- 月将亥，占时午
- 月将亥加在地盘午上
- 天盘：午=亥、未=子、申=丑...顺布
```

### 3.3 地盘固定位置

```
        巳  午  未  申
        辰          酉
        卯          戌
        寅  丑  子  亥
```

### 3.4 天地盘对应关系

天地盘确定后，形成固定对应：
- 地盘子 → 天盘 X
- 地盘丑 → 天盘 Y
- ...

## 第四章：四课起法

### 4.1 四课概念

**四课**是从日干支推导出的四层课式，反映事物的不同层面。

### 4.2 天干寄宫

起四课前需知天干寄宫：

| 天干 | 寄宫 | 原理 |
|------|------|------|
| 甲 | 寅 | 禄位 |
| 乙 | 辰 | 寄位 |
| 丙/戊 | 巳 | 禄位/同宫 |
| 丁/己 | 未 | 寄位/同宫 |
| 庚 | 申 | 禄位 |
| 辛 | 戌 | 寄位 |
| 壬 | 亥 | 禄位 |
| 癸 | 丑 | 寄位 |

### 4.3 起四课步骤

```
第一步：起第一课（日干上神）
- 看日干寄宫的天盘是什么
- 例：甲日，甲寄寅，看地盘寅上的天盘

第二步：起第二课（干上神的上神）
- 看第一课上神的地盘位置，其天盘是什么

第三步：起第三课（日支上神）
- 看日支的地盘位置，其天盘是什么

第四步：起第四课（支上神的上神）
- 看第三课上神的地盘位置，其天盘是什么
```

### 4.4 四课格式

```
第四课：上神之上（支上神的上神）
第三课：日支上神
第二课：干上神的上神
第一课：日干上神
```

## 第五章：三传发用法

### 5.1 三传概念

**三传**即初传、中传、末传，代表事物发展的三个阶段。

### 5.2 九种发用法则

发用遵循严格的优先级顺序：

```
1. 贼克法（优先级最高）
2. 比用法
3. 涉害法
4. 遥克法
5. 昂星法
6. 别责法
7. 八专法
8. 伏吟法
9. 反吟法（优先级最低）
```

### 5.3 贼克法

**条件**：四课中只有一课相克

```
- 上克下：元首课（尊制卑）
- 下贼上：重审课（卑犯尊）

取用：取克贼之神为初传
中传：取初传的天盘
末传：取中传的天盘
```

### 5.4 比用法

**条件**：四课中有两课或以上相克

```
规则：取与日干阴阳相同者为用
- 阳日（甲丙戊庚壬）：取阳支（子寅辰午申戌）
- 阴日（乙丁己辛癸）：取阴支（丑卯巳未酉亥）

若仍有多课，进入涉害法
```

### 5.5 涉害法

**条件**：比用后仍有多课

```
涉害深浅计算：
- 从本位归原位，数经过的克位数量
- 克位多者涉害深，取为初传

特殊格局：
- 见机格：害深者（深度>3）
- 缀瑕格：害深相同，取先见者
```

### 5.6 遥克法

**条件**：四课无克贼

```
规则：
1. 取上神克日干者（上克干）
2. 无上克干，取日干克上神者（干克上）

取先见者为初传
```

### 5.7 昂星法

**条件**：四课无克，非特殊格局

```
规则：
- 阳日：取酉上神为初传
- 阴日：取酉下神（酉本身）为初传

中末传：依次取天盘
```

### 5.8 别责法

**条件**：四课不全，只有三课

```
规则：
- 取干上神之合神为初传
- 中传、末传皆用日支上神

六合：子丑合、寅亥合、卯戌合、辰酉合、巳申合、午未合
```

### 5.9 八专法

**条件**：干支同位（八专日）

```
八专日：甲寅、丁未、己未、庚申、癸丑

规则：
- 阳日：从干上神顺数第三位为初传
- 阴日：从第四课逆数第三位为初传
- 中末传皆用日支上神
```

### 5.10 伏吟法

**条件**：天地盘相同（子加子、丑加丑...）

```
规则：
- 有克取克贼
- 无克用自刑（取日支为初传）

中末传：取刑位
- 子卯刑、寅巳申刑、丑未戌刑、辰午酉亥自刑
```

### 5.11 反吟法

**条件**：天地盘对冲（子加午、丑加未...）

```
规则：
- 有克取克贼
- 无克取冲神

中末传：
- 中传取冲神
- 末传复归本位
```

## 第六章：贵人盘排布法

### 6.1 贵人起例

```
甲戊庚牛羊（丑未）
乙己鼠猴乡（子申）
丙丁猪鸡位（亥酉）
壬癸兔蛇藏（卯巳）
辛用马虎走（午寅）
六辛逢马虎（午寅）
```

### 6.2 昼夜判断

```
昼贵：卯、辰、巳、午、未、申时
夜贵：酉、戌、亥、子、丑、寅时

卯至申为昼，酉至寅为夜
```

### 6.3 贵人顺逆

```
规则：
- 贵人在阳位（亥子丑寅卯辰）→ 顺行
- 贵人在阴位（巳午未申酉戌）→ 逆行

十二天将顺序：
贵人→螣蛇→朱雀→六合→勾陈→青龙→
天空→白虎→太常→玄武→太阴→天后
```

## 第七章：特殊格局判断

### 7.1 课体分类

```
元首课：上克下（尊制卑，事顺）
重审课：下贼上（卑犯尊，事逆）
比用课：比和取用（事涉众人）
涉害课：涉害深者（事多艰难）
见机格：害深明显（当机立断）
缀瑕格：害深相同（事有牵连）
遥克课：遥相克贼（事在远方）
昂星课：仰视酉星（事主惊恐）
别责课：四课不全（事有缺失）
八专课：干支同位（事主专一）
伏吟课：天地伏吟（事主停滞）
反吟课：天地反吟（事主反复）
```

### 7.2 格局判断优先级

```
1. 先查克贼（贼克、比用、涉害）
2. 无克查遥克
3. 无克查特殊格局（伏吟、反吟、八专、别责）
4. 最后用昂星
```

## 第八章：起课流程总览

### 8.1 完整起课步骤

```
第一步：确定月将
- 根据占测日期，查节气
- 中气后换将，确定月将地支

第二步：选取占时
- 以占测时辰为准

第三步：排天地盘
- 月将加在占时上
- 顺布十二宫，得天地盘对应

第四步：起四课
- 日干寄宫，看得天盘（第一课）
- 干上神的上神（第二课）
- 日支上神（第三课）
- 支上神的上神（第四课）

第五步：发三传
- 按九法优先级依次判断
- 确定初传、中传、末传

第六步：排贵人盘
- 根据日干起贵人
- 根据占时定昼夜
- 根据贵人位定顺逆
- 布十二天将

第七步：定六亲
- 根据日干与三传五行关系
- 父母、官鬼、子孙、兄弟、妻财
```

### 8.2 注意事项

1. **月将精确**：必须以节气为准，不可用农历月份代替
2. **克贼优先**：九法必须按顺序判断，不可跳级
3. **涉害计算**：需精确计算涉害深度
4. **特殊格局**：伏吟、反吟、八专等需优先判断
5. **贵人顺逆**：以贵人落地盘位置判断，非天盘位置
