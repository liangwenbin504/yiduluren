# 六壬古例长征 · 总结报告

**日期**: 2026-08-17
**范围**: 长征主线（六壬断案 218 案）+ 全部扩展（指南卷三 / 壬占汇选 / 胎产 / 类神寻物法 / 不平衡训练）
**评估口径**: Python 3.12 + PYTHONHASHSEED=0；M3 为主指标；朴素「永远判凶」为对照基线

---

## 一、长征是什么

以《大六壬断案》（邵彦和）218 例真实疏正案为唯一权威语料，构建并验证六壬古例吉凶判别引擎的完整方法论闭环：

```
218 案精细标注 → 特征向量 → CBR 检索 → 训练打包 → 接入起课 → 主战场六战 → 行年诚实收口
                                                                        ↓
                              扩展：指南卷三 / 壬占汇选 / 胎产回攻 / 类神寻物法 / 不平衡训练
```

**核心信条（方法论红线）**：
1. 评估须由引擎代码从头重算，不引用任何预计算结论
2. 所有修复须有原始资料（古籍/《通解》）印证
3. 已动基线须 A/B 验证零回归
4. label 标注只依据断语真实结局，自动标注会误取假设句/否定句/喜词（三连坑）
5. 古例高准确率 = 特征工程保真度，非预知力；古例结论不可外推股票域（两域架构隔离）

| 项目 | 数值 |

| label 分布 | 凶 174 / 吉 32 / 未知 11 / 平 1 |

**label 自动标注三连坑**（血泪教训）：
- **疾病鬼胎 / 亡盗 / 功名** 三类最容易误标：自动标注会误取「假设句（若…必…）/ 否定句（不是及第课）/ 晚年享福喜词」，把真凶案标吉
- 功名 10 错里 5 个是 label 误标 → 修正后 91.7%
- 攻任何难类前必须先逐案核对断语真实结局

## 三、特征工程 → CBR → 训练打包

1. **特征向量**（`data/longmarch_feature_vectors.json`）：每案 7 数值特征（课格数/毕法数/特殊格数/变格数/吉煞数/凶煞数/神煞命中数）+ 7 类别特征（发用/发用五行/与日干日支关系/传变/初克中/中克末）

## 五、行年接入：诚实收口

- 本命 135/219（61.6%）为原文上限；行年反推不可用
- 断语明确行年支仅 17/218 案；age 字段不可靠（§052 age=41 但断语行年=午，反推对不上）
- **结论：行年只能进「记录层/起课页真实排盘/叙事层」，进评分层须先解决 age 可靠性 + 覆盖率**
- 功名吉案（三奇拱照/出户课/官星学堂/天吏入宅）依赖行年；单一课体特征（青龙值官/朱雀值官）在凶重语料无分离度 → 强行加吉规则 = 过拟合

## 六、三个独立古例验证集 + 语料比例效应（关键发现）

| 验证集 | 规模 | 吉凶比 | M3 | 数据可靠性 |
|---|---|---|---|---|
| 断案（主战场） | 207 案 | 凶5:1吉 | **90.8%** | 原文给月将+三传（94.8% 自洽） |
| 壬占汇选 v2 | 153 案 | 凶2.1:1吉 | 67.3% → **71.2%** | 原文给月将+三传（最可靠） |
| 指南卷三 | 78 案 | 1:1.1 | **55.1%** | 盘面反推月将（无月将死结解法） |

**🔴 语料比例效应**：引擎「逢凶推凶」偏置被语料吉凶比例放大/缩小——凶越重显得越准，吉凶越均衡越暴露短板。吉案识别（12-24%）是所有语料共同的**能力边界**，非数据问题。

## 七、天地盘反推月将（指南卷三解法，可复用方法）

**问题**：陈公献系古例只记「X月」不记月将，排盘不可靠（月将映射课体一致率最高仅 57%）。

**解法**：原文自带天地盘（4 行「天将+天盘地支」，对应地盘固定布局）→ **月将 = 地盘时辰位上的天盘地支**。

- 脚本：`engine/_reverse_yj_from_pan2.py`（行首正则 `^[天将][地支]{2,4}[天将]`）
- 验证三重保险：搜狐注解版已知月将 4/5 对、四课精确匹配、3 特殊案三传遍历锁定
- **78 案全部拿到月将**（75 盘面反推 + 3 手动）；胎产类 40% → **80%**
- 副产品：陈公献案例月将 = 中气换将理论 +1 宫（搜狐版四例全对）

## 八、类神寻物法跨语料验证（走失 38% → 80%）

- **触发条件**：`extract_zeidao_valence` 类神寻物法只在 `zhanlei=='其他'` 时触发（ancient_backtest.py:219 `zhanlei = category`）
- 壬占汇选走失 13 案原分「走失」类 → 不触发 → 38%；归「其他」+ leishen 字段后 → **80%（8/10）**
- **W1「类神在三传→寻得吉」6/6 全对**，累计断案 14 案 + 壬占汇选 6 案 = **20 案零失误，规则普适性成立**
- 已知边界：①类神在传但被三传他支克→不吉（甲辰失狗，n=1 记知识库）②天将类神（玄武/朱雀）不触发（只认地支，与断案口径一致）

## 九、胎产回攻：12 案 75% → 18 案 77.8%

| 语料 | 案数 | 准确率 |
|---|---|---|
| 断案 7 案 | 7 | 71.4% |
| 指南 5 案 | 5 | 80% |
| 壬占汇选 6 案 | 6 | 83% |
| **合并 18 案** | **18** | **77.8%**（凶→凶 10/11=90.9%，吉→吉 4/6=66.7%） |

样本翻倍准确率反升 → 胎产规则（子孙生扶/德神/胞胎神）跨语料稳定。4 错案全是「吉案识别弱」+「label 边界」共性，无新规则可落地（守铁律，n=1 不加规则）。

## 十、label 类别不平衡训练（长征第1期遗留待办）

- 206 可判案（凶174:吉32），9 组合（{LR/RF/HGB}×{默认/class_weight/SMOTE}），5 折分层 CV
- **LR_balanced 最优：吉 recall 0 → 36.2%**（F1吉 0 → 0.247）
- **🔴 全模型 AUC ≈ 0.49-0.59（贴地 0.5）→ 当前特征体系对吉凶无判别力** → ML 分类器不进评分层（90.8% 规则引擎换成 66-82% 弱分类器是倒退）
- 吉案识别提升方向 = 行年/占者处境（与功名结论一致），非 ML 调参

## 十一、能力边界总结（诚实声明）

1. **吉案识别 12-24% 是共性上限**：功名/胎产/§214·218/三个验证集全部指向同一结论——引擎被凶重语料训练成「逢凶推凶」，吉凶均衡语料会放大短板
2. **§214（沈公）/§218（蔡京）**：杂占吉案，通用信号无分离度，记录在案不修
3. **「无禄课久困者发」例外**（邵彦和 §218 + 陈公献选举/四注释双重印证）→ 只进叙事层/CBR，不进评分层
4. **古例结论不可外推股票域**：两域架构隔离，引擎默认股票域不输出涨跌方向
