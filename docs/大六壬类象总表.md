三、赵林声《北大课例》实战断法要点（现代活法，承古法而用）
════════════════════════════════════════════════════════════

1. 【类神优先】测什么找什么类神（钱包=财未、狗=戌、车=卯、卡=朱雀），
   类神不上卦→找第二类神→看发用。
2. 【神将一体论】天将与地支一体看：白虎=申、玄武=亥、朱雀=午、
   螣蛇=巳、勾陈=辰、太常=未、天后=亥、太阴=酉、青龙=寅、天空=戌、
   贵人=丑未、六合=卯。将+支组合推象（如 巳乘青龙遁癸=热水管道）。
3. 【先锋门】问事前正时上神为先锋门，先看它（应事发端）。
4. 【七处】行、命、行命上神、日上神、支上神、三传、先锋门——解灾必在七处找。
5. 【空亡妙用】测久远事不忌空（空为远/空为天/空为虚），测近事空=不成；
   太岁不能填实，月令月将本命行年可以填实。
6. 【冲的时效】冲日应当天、冲月应当月、冲年应当年（寅申冲=申日/申月/申年）。
7. 【组合推象】现代事物由传统象组合推：手机=卯(朱雀)+戌(网络)+巳(信息)；
   取款机=朱雀(卡)+午虎(老虎机)+亥水；避孕套=寅(淫)+天空(空)+丙(圆)。
8. 【行为风水】病在那药在那，用七处之神冲墓/合财化解（如辰冲戌墓、
   放鱼缸/搬陶罐），解神必在七处。

四、赵林声课例·现代类象断例汇编（38 课全文提取，2026-08-25）
════════════════════════════════════════════════════════════
（每例=传统象+现代事物，直接可查可仿）

【手机】发用卯乘朱雀（卯=手机/车在叫），卯坐申（传送/道路），
        卯阴神戌（火库=网络）乘白虎（过硬），戌阴神巳（信息/文明）乘贵遁辛（小金）
        → 苹果手机；卯为盗神子孙（小孩），中传戌虎官鬼=路上丢。
【银行卡】朱雀=卡；戌=库/网络/电子产品（遁丙），阴神巳有口象乘太常（吃）遁癸（闭口），
        末传子水小片=取款机；朱雀入玄武水墓辰土=卡被吞。
【取款机】朱雀(卡)+午乘白虎(老虎机)+末传子水(小片)。
【汽车】卯=车，乘太阴（藏）；寅卯辰三传空=车没被偷；寅=树（停车处有树）。
【飞机】申乘青龙（申落空=天空，坐飞机去远方）；初传申空发用=天马动。
【网络】戌=火库（火为信息），故戌=网络。
【交警/警察】申=太岁乘青龙（标准的交警）；勾陈=交警/警察；未乘勾陈=警察；
        辰乘勾陈=真勾陈必被抓；辰是勾陈本家。
【银行】戌=日干财库乘青龙=大财库（银行）；丑=金库（发放贷款）；
        子亥乘贵/天后=国家企业。
【避孕套】桃花午阴神辰遁戊（面积/宽）乘勾陈（可挂），辰阴神寅乘天空（中间空）
        遁丙（圆），寅能淫 → 避孕套。
【热水管道】螣蛇(巳)本家，巳乘青龙遁癸（吊客/弯曲/热）=热水管道；
        巳落空遁癸（闭口）=水管堵塞。
【部队】亥乘太常阴神白虎=部队人员；戌=部队。
【贷款】本命亥临马星为财乘天后（恩泽）坐金库丑=发放贷款；天医=医治经济/身体/心理。
【酒驾】申官鬼贵人=交警；罡塞鬼户（辰坐寅）=不会被抓。
【酒具/玉器】太阴或酉金=酒具/玉器类神，谁上传看谁；酉乘勾陈=带把/雕刻。
【佛珠】酉=贵重物件（朱同珠），酉阴神卯乘太常遁乙=手+艺术品+条状长物=佛珠。
【咽喉炎】朱雀临酉坐卯（酉=兑=口/咽喉，卯=本命）。
【纸钱煞】青龙=纸钱煞，申长生坐辰墓=坟上挂亲纸。
【警察抓骗子】玄武=骗子类神，玄武乘寅发传化空（寅阴神未旬空）=跑得无影无踪。
【桃花】申子辰桃花在酉；午=桃花旺月；卯=日干支桃花。
【婚姻】子酉破=破口大骂；六合临申坐巳（申巳合中有破）=吵吵闹闹不离婚；
        干上寅支上亥合破害=吵吵闹闹故事多不离婚。
【病症】午火=心脏、寅木=肝脏、戌=脾胃/块状、辰=胃、螣蛇=眼睛/神经、
        子水=妻财瘦弱、白虎=病、酉=咽喉/腰椎、巳=胃口/吃喝。
【眼睛】螣蛇=眼睛（子水克蛇=眼病；本命午落空=眼睛问题）。
【行为风水解】病在戌墓用辰冲（家北边放鱼缸/辰=水库）；戌=陶瓷搬开（正南窗台）；
        寅乘玄武=西北角放木质老子/鬼谷子雕像；不能养狗（戌=狗）。
【认属相解】寅填实=认属虎的做干爹；寅乘玄武=玄学道家之物。
【神煞应期】丧门/吊客/死神/死气/天医/地医套入断生死。
【选择行业】申金临马星遁戊=运输/道路/旅游/中医（巳=天医，申=针灸）；
        酉=鸡坐午火=饮食（以鸡为主）；子孙辰戌丑未=门路/投资。
【六冲应病】近病一冲就好，久病一冲就死。
【测官】测官最喜白虎（催官使者）；头顶墓神=测官大忌（昏昏噩噩）；
        父母上三传=好事（非测子孙时）；官星落空+行年冲=竞争大被夺。
【钱财】传财太旺反财亏；兄弟=劫财（亥为双数=四情人以上）。
