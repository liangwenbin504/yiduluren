# 龙德课到山到向择日系统使用手册

## 📖 系统概述

**龙德课到山到向择日系统**是仪度六壬择日软件的核心功能模块，专门用于筛选符合传统风水择日标准的吉日良辰。

### 核心功能

1. **龙德课判断**：自动识别太岁龙德课和月将龙德课
2. **贵人禄马到山到向**：精确计算禄马贵是否到山到向
3. **二十四山支持**：支持所有坐山朝向组合
4. **智能筛选**：根据用户指定的日期范围和条件自动筛选
5. **课格结构生成**：提供完整的课格结构和理论依据
6. **推荐指数评估**：根据到山到向数量评估课格等级

## 🎯 龙德课理论基础

### 什么是龙德课？

**龙德课**是风水择日中的上上吉课，源自《仪度六壬选日要诀》，其定义为：

> **龙德课者，太岁或月将乘贵人发用也。**

### 判断条件

龙德课必须同时满足以下两个条件：

1. **太岁或月将发用**（满足其一即可）
   - 太岁发用：初传 = 年支（太岁）
   - 月将发用：初传 = 月将

2. **乘贵人**：初传必须是日干的贵人

### 龙德课类型

- **太岁龙德课**：太岁发用 + 乘贵人
  - 特征：主权贵显达，百事亨通
  - 力量：最强，适合重大事务

- **月将龙德课**：月将发用 + 乘贵人
  - 特征：主光明磊落，逢凶化吉
  - 力量：次强，百事皆宜

### 贵人查法（十干贵人）

```
甲戊庚牛羊（丑未）
乙己鼠猴乡（子申）
丙丁猪鸡位（亥酉）
壬癸兔蛇藏（巳卯）
六辛逢马虎（午寅）
```

禄马贵到山到向的数量越多，课格越吉：

- **6 个以上**：上上大吉 ⭐⭐⭐（强烈推荐）

- **3 个**：小吉（一般）
- **少于 3 个**：平（不建议）

## 💻 使用方法

### 方法一：图形界面（GUI）

#### 启动方式

```bash
# 方式 1：直接运行 GUI 模块
python src/ui/long_de_ke_gui.py

# 方式 2：通过主程序启动（待集成）
python src/main.py
```

#### 操作步骤

1. **选择坐山朝向**
   - 坐山：从下拉列表选择（如"壬"）
   - 朝向：从下拉列表选择（如"丙"）

2. **设置日期范围**
   - 开始日期：YYYY-MM-DD 格式（如 2026-03-15）
   - 结束日期：YYYY-MM-DD 格式（如 2027-03-14）

3. **设置筛选条件**
   - 最少到山到向：1-10 个（建议 3 个以上）
   - 龙德课类型：全部/太岁龙德课/月将龙德课

4. **开始择日**
   - 点击"开始择日"按钮
   - 系统自动扫描并筛选符合条件的日期
   - 进度条显示当前进度

5. **查看结果**
   - 左侧列表显示所有符合条件的日期
   - 点击任意日期查看详细信息
   - 详细信息包含：
     - 四柱信息
     - 六壬课式
     - 龙德课分析
     - 到山到向分析
     - 综合评价

6. **导出结果**
   - 点击"导出结果"按钮
   - 选择保存格式（JSON/TXT）
   - 保存到指定位置

# 筛选特定课体组合
def filter_by_ke_ti(results, required_ke_ti):
    """筛选包含特定课体的结果"""
    filtered = []
    for r in results:
        if all(kt in r['ke_ti'] for kt in required_ke_ti):
            filtered.append(r)
    return filtered

# 筛选同时包含龙德课和三光课的日期

## ⚠️ 注意事项

### 1. 龙德课的局限性

虽然龙德课是上吉之课，但使用时仍需注意：

- 需结合用事人年命（八字）
- 考虑山向利否（避开三煞、五黄等）
- 避开岁破、月破等凶日
- 建议由专业风水师最终确认

### 2. 到山到向的准确性

- 本系统采用传统禄马贵查法
- 不同流派可能略有差异
- 建议结合其他择日法综合判断

### 3. 性能考虑

- 扫描 1 年（365 天）约需 1-2 分钟
- 扫描 10 年约需 10-20 分钟
- 建议先缩小日期范围测试

### 4. 结果解读

- 到山到向数量越多越吉
- 但也要考虑课体组合
- 避开凶课（如天狱、绝嗣等）

## 🎓 常见问题

### Q1：什么是太岁龙德课和月将龙德课？

**A**：两者都是龙德课，区别在于发用的来源：
- 太岁龙德课：初传 = 年支（太岁）+ 贵人，力量最强
- 月将龙德课：初传 = 月将 + 贵人，力量次强

### Q2：到山到向数量多少才算吉？

**A**：
- 6 个以上：上上大吉
- 5 个：上吉
- 4 个：中吉
- 3 个：小吉
- 少于 3 个：平

建议至少选择 3 个以上的日期。

### Q3：如何结合斗首择日法？

**A**：建议先用斗首法筛选出元辰、武财等吉课日期，再用龙德课到山到向法进一步筛选。

### Q4：为什么有些日期龙德课成立但没有禄马贵到山？

**A**：龙德课和禄马贵到山是两个独立的条件。龙德课主要看三传和贵人，禄马贵到山看的是年日时的禄马贵位置。两者都满足才是最佳选择。

### Q5：系统支持哪些坐山？

**A**：支持完整的二十四山：
- 八干：甲乙丙丁庚辛壬癸
- 十二地支：子丑寅卯辰巳午未申酉戌亥
- 四维卦：乾坤艮巽
