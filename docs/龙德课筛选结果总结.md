```python
def is_long_de_ke(ri_gan_zhi, yue_jiang, tai_sui, sanchuan):
    chu_chuan = sanchuan.get('初传', '')
    
    # 条件 1：太岁或月将发用
    is_tai_sui_yong = (chu_chuan == tai_sui)
    is_yue_jiang_yong = (chu_chuan == yue_jiang)
    
    # 条件 2：乘贵人
    ri_gan = ri_gan_zhi[0]
    gui_ren_list = get_gui_ren(ri_gan)
    is_gui_ren_yong = (chu_chuan in gui_ren_list)
    
    # 龙德课判定
    return (is_tai_sui_yong or is_yue_jiang_yong) and is_gui_ren_yong
```

## ⚠️ 重要提示

1. **月将计算**：
   - 当前使用简化算法（正月亥，二月戌，...）
   - 精确应用应使用节气计算

2. **日干支计算**：
   - 使用六十甲子循环推算
   - 基准：1984 年 1 月 1 日（甲子日）

3. **实际应用**：
   - 建议结合完整课体分析
   - 考虑年命、行年等因素
   - 最好由专业人士择日
