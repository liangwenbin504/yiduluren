# 大六壬完整起课引擎系统

## 系统概述

本系统是一套功能完整、算法精准的大六壬起课引擎，集成了四课、三传、天将、神煞、课体判断等核心模块，实现了 64 课经的完整匹配。

## 核心模块

### 1. 四课计算模块 (`sike_sanchuan_engine.py`)

**功能**：
- 实现规范的四课（第一课、第二课、第三课、第四课）排盘算法
- 计算天地盘、四课之间的生克制化关系
- 支持十干寄宫转换

**算法特点**：
- 严格遵循传统起课逻辑
- 天地盘对应关系准确
- 四课上下生克判断精确

**使用示例**：
```python
from sike_sanchuan_engine import SiKeSanChuanCalculator

calculator = SiKeSanChuanCalculator()
sike = calculator.arrange_si_ke(ri_gan, ri_zhi, tiandi_pan)
```

### 2. 三传计算模块 (`sike_sanchuan_engine.py`)

**功能**：
- 完整实现九宗门全部算法：
  1. 贼克法（Ze Ke）
  2. 比用法（Bi Yong）
  3. 涉害法（She Hai）
  4. 遥克法（Yao Ke）
  5. 昴星法（Mao Xing）
  6. 别责法（Bie Ze）
  7. 八专法（Ba Zhuan）
  8. 伏吟法（Fu Yin）
  9. 返吟法（Fan Yin）

**算法特点**：
- 三传推导过程符合传统典籍规范
- 课体判断准确（元首课、重审课等）
- 伏吟、反吟特殊处理

**使用示例**：
```python
sanchuan = calculator.fa_sanchuan(sike, ri_gan, ri_zhi, tiandi_pan)
# 返回：{'初传': '子', '中传': '巳', '末传': '戌', '课体': '重审课', '起法': '贼克法'}
```

### 3. 天将排布模块 (`gui_ren_engine.py`)

**功能**：
- 实现十二天将标准排布规则
- 十二天将：贵人、螣蛇、朱雀、六合、勾陈、青龙、天空、白虎、太常、玄武、太阴、天后
- 顺逆排法判定（根据昼夜、贵人位置）

**算法特点**：
- 贵人查找准确（甲戊庚牛羊，乙鼠猴乡等）
- 昼夜判断精确（卯酉为昼夜分界）
- 顺逆排法符合古法

**使用示例**：
```python
from gui_ren_engine import GuiRenCalculator

calculator = GuiRenCalculator()
is_night = calculator.is_night_time(shi_chen)
gui_ren_pan = calculator.arrange_gui_ren_pan(ri_gan, tiandi_pan, shi_chen, is_night)
```

### 4. 神煞计算模块 (`shen_sha_calculator.py`)

**功能**：
- 日辰神煞：日禄、日德、羊刃等
- 干支神煞：驿马、桃花、劫煞、灾煞等
- 月建神煞：天德、月德、天喜等
- 年支神煞：丧门、吊客等

**神煞列表**：
| 神煞类型 | 神煞名称 |
|---------|---------|
| 日干神煞 | 日禄、日德、羊刃 |
| 日支神煞 | 驿马、桃花、劫煞、灾煞 |
| 月建神煞 | 天德、月德、天喜、月厌、天鬼、死神、死气 |
| 年支神煞 | 孤辰、寡宿、丧门、吊客 |

**使用示例**：
```python
from shen_sha_calculator import ShenShaCalculator

calculator = ShenShaCalculator()
shen_sha = calculator.calculate_all_shen_sha(ri_gan, ri_zhi, lunar_month, nian_zhi)
```

### 5. 课体判断规则库 (`ke_ti_judge.py`)

**功能**：
- 基础课体：伏吟课、反吟课
- 克贼课体：元首课、重审课、比用课
- 特殊课体：玄胎课、三奇课、六仪课等
- 神煞课体：天网课、地网课、孤辰课、寡宿课等

**课体判断体系**：
```
1. 伏吟课：天地盘相同
2. 反吟课：天地盘对冲
3. 元首课：一上克下
4. 重审课：一下贼上
5. 比用课：多课克贼，取比和
6. 涉害课：比用后仍多课，取涉害深者
7. 玄胎课：三传皆孟
8. 度厄课：三课上下克
... 共 64 种课体
```

**使用示例**：
```python
from ke_ti_judge import KeTiJudgeCalculator

calculator = KeTiJudgeCalculator()
ke_ti_list = calculator.judge_all_ke_ti(sike, sanchuan, tiandi_pan, ri_gan, ri_zhi)
```

## 64 课经匹配系统 (`accurate_ke_jing_matcher.py`)

**功能**：
- 加载完整的 64 课经数据
- 根据完整起课结果匹配课经
- 提供课经查询功能

**匹配方法**：
1. `match_by_complete_qi_ke()` - 使用完整四课三传信息匹配
2. `match_by_jiu_zong_men()` - 使用九宗门基本方法匹配

**使用示例**：
```python
from accurate_ke_jing_matcher import AccurateKeJingMatcher

matcher = AccurateKeJingMatcher()
matched = matcher.match_by_complete_qi_ke(qi_ke_result)

for ke in matched:
    print(f"课名：{ke['ke_name']}")
    print(f"断语：{ke['duanyu'][0]}")
```

## 使用指南

### 快速开始

```python
from src.engine.complete_qi_ke_engine import CompleteQiKeEngine

# 创建引擎
engine = CompleteQiKeEngine()

# 起课
result = engine.qi_ke(
    ri_gan_zhi='甲子',  # 日干支
    yue_jiang='亥',     # 月将
    shi_chen='午',      # 占时
    lunar_month=1,      # 农历月（神煞用）
    nian_zhi='子'       # 年支（神煞用）
)

# 获取关键信息
sike = result['四课']
sanchuan = result['三传']
ke_ti = result['课体']
shen_sha = result['神煞']

# 打印结果
engine.print_result(result)
```

### 课经匹配

```python
from src.engine.accurate_ke_jing_matcher import AccurateKeJingMatcher

# 创建匹配器
matcher = AccurateKeJingMatcher()

# 匹配课经
matched = matcher.match_by_complete_qi_ke(result)

# 显示结果
for ke in matched:
    print(f"{ke['ke_name']}: {ke['duanyu'][0]}")
```
