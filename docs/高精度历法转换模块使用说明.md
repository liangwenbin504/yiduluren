# 高精度历法转换模块使用说明

## 📖 模块概述

**高精度历法转换模块**（`precise_calendar.py`）提供精确的公历与中国传统干支历法转换功能，严格遵循传统历法规则，确保与权威历法数据一致。

### 核心特性

✅ **精确节气计算** - 基于太阳黄经计算，精度达 0.0001 度  
✅ **精确四柱计算** - 年柱以立春为界，月柱以节气为界  
✅ **真太阳时计算** - 考虑经度差异，精确计算时柱  
✅ **历法验证机制** - 内置验证功能，确保数据准确性  
✅ **完整文档** - 详细说明算法原理和使用方法

## 🔧 算法原理

### 1. 年柱计算（立春为界）

**原理**：
- 年柱不是以正月初一为界，而是以**立春节气**为界
- 立春前属于上一年，立春后属于当年

**算法**：
```python
def get_year_ganzhi(year, month, day):
    # 1. 计算当年立春日期
    lichun = find_jieqi_time(year, '立春')
    
    # 2. 判断是否在立春后
    if date(year, month, day) >= lichun.date():
        # 立春后，属当年
        ganzhi_index = (year - 1984) % 60
    else:
        # 立春前，属上一年
        ganzhi_index = (year - 1 - 1984) % 60
    
    return LIUSHIJIAZI[ganzhi_index]
```

**示例**：
- 2026 年 2 月 3 日（立春前）：乙巳年
- 2026 年 2 月 4 日（立春）：丙午年
- 2026 年 2 月 5 日（立春后）：丙午年

### 2. 月柱计算（节气为界）

**原理**：
- 月柱不是以农历初一为界，而是以**12 节气**为界
- 12 节气：立春、惊蛰、清明、立夏、芒种、小暑、立秋、白露、寒露、立冬、大雪、小寒

**节气与月支对应**：
| 节气 | 月支 | 农历月 |
|------|------|--------|
| 立春 | 寅 | 正月 |
| 惊蛰 | 卯 | 二月 |
| 清明 | 辰 | 三月 |
| 立夏 | 巳 | 四月 |
| 芒种 | 午 | 五月 |
| 小暑 | 未 | 六月 |
| 立秋 | 申 | 七月 |
| 白露 | 酉 | 八月 |
| 寒露 | 戌 | 九月 |
| 立冬 | 亥 | 十月 |
| 大雪 | 子 | 十一月 |
| 小寒 | 丑 | 十二月 |

**算法**：
```python
def get_month_ganzhi(year, month, day):
    # 1. 找到当前日期所在的节气
    current_jieqi = find_current_jieqi(year, month, day)
    
    # 2. 获取对应的月支
    month_zhi = JIEQI_MONTH[current_jieqi]
    
    # 3. 五虎遁年起月法
    year_gan = get_year_ganzhi(year, month, day)[0]
    
    if year_gan in ['甲', '己']:
        month_gan_base = 2  # 丙
    elif year_gan in ['乙', '庚']:
        month_gan_base = 4  # 戊
    elif year_gan in ['丙', '辛']:
        month_gan_base = 6  # 庚
    elif year_gan in ['丁', '壬']:
        month_gan_base = 8  # 壬
    else:  # 戊、癸
        month_gan_base = 0  # 甲
    
    month_gan_index = (month_gan_base + month_zhi_index) % 10
    
    return f'{TIANGAN[month_gan_index]}{month_zhi}'
```

**示例**：
- 2026 年 9 月 7 日（白露前）：丁酉月
- 2026 年 9 月 8 日（白露）：戊戌月
- 2026 年 9 月 9 日（白露后）：戊戌月

### 3. 日柱计算（基准日推算）

**原理**：
- 使用已知准确日柱的基准日
- 通过天数差推算目标日期的日柱
- 60 甲子循环

**算法**：
```python
# 基准日：2026 年 3 月 20 日癸巳日（已验证）
BASE_DATE = date(2026, 3, 20)
BASE_GANZHI_INDEX = 29  # 癸巳

def get_day_ganzhi(year, month, day):
    target_date = date(year, month, day)
    delta = (target_date - BASE_DATE).days
    
    ganzhi_index = (BASE_GANZHI_INDEX + delta) % 60
    
    return LIUSHIJIAZI[ganzhi_index]
```

**验证**：
- 2026 年 3 月 20 日：癸巳（基准日）
- 2026 年 3 月 21 日：甲午（+1 天）
- 2026 年 9 月 4 日：辛巳（已验证）

### 4. 时柱计算（真太阳时）

**原理**：
- 时柱以真太阳时为准，不是标准时间
- 考虑经度差异（每度 4 分钟）
- 考虑均时差（地球轨道椭圆）

**时辰与地支对应**：
| 时辰 | 地支 | 时间范围 |
|------|------|----------|
| 子时 | 子 | 23:00-01:00 |
| 丑时 | 丑 | 01:00-03:00 |
| 寅时 | 寅 | 03:00-05:00 |
| 卯时 | 卯 | 05:00-07:00 |
| 辰时 | 辰 | 07:00-09:00 |
| 巳时 | 巳 | 09:00-11:00 |
| 午时 | 午 | 11:00-13:00 |
| 未时 | 未 | 13:00-15:00 |
| 申时 | 申 | 15:00-17:00 |
| 酉时 | 酉 | 17:00-19:00 |
| 戌时 | 戌 | 19:00-21:00 |
| 亥时 | 亥 | 21:00-23:00 |

**算法**：
```python
def get_hour_ganzhi(day_ganzhi, hour, minute, longitude):
    # 1. 计算真太阳时
    true_solar_hour = calculate_true_solar_time(hour, minute, longitude)
    
    # 2. 确定时辰地支
    hour_zhi_index = int((true_solar_hour + 1) % 24) // 2
    
    # 3. 五鼠遁日干起时法
    day_gan = day_ganzhi[0]
    
    if day_gan in ['甲', '己']:
        hour_gan_base = 0  # 甲
    elif day_gan in ['乙', '庚']:
        hour_gan_base = 2  # 丙
    elif day_gan in ['丙', '辛']:
        hour_gan_base = 4  # 戊
    elif day_gan in ['丁', '壬']:
        hour_gan_base = 6  # 庚
    else:  # 戊、癸
        hour_gan_base = 8  # 壬
    
    hour_gan_index = (hour_gan_base + hour_zhi_index) % 10
    
    return f'{TIANGAN[hour_gan_index]}{DIZHI[hour_zhi_index]}'
```

### 5. 节气计算（太阳黄经）

**原理**：
- 节气是太阳黄经达到特定角度的时刻
- 每个节气间隔 15 度
- 使用天文算法精确计算

**节气与黄经对应**：
| 节气 | 黄经 | 节气 | 黄经 |
|------|------|------|------|
| 小寒 | 285° | 大暑 | 135° |
| 大寒 | 300° | 立秋 | 150° |
| 立春 | 315° | 处暑 | 165° |
| 雨水 | 330° | 白露 | 180° |
| 惊蛰 | 345° | 秋分 | 195° |
| 春分 | 0° | 寒露 | 210° |
| 清明 | 15° | 霜降 | 225° |
| 谷雨 | 30° | 立冬 | 240° |
| 立夏 | 45° | 小雪 | 255° |
| 小满 | 60° | 大雪 | 270° |
| 芒种 | 75° | 冬至 | 285° |
| 夏至 | 90° | | |

**算法**：
```python
def find_jieqi_time(year, jieqi_index):
    # 1. 目标黄经
    target_longitude = jieqi_index * 15.0
    
    # 2. 估算日期
    estimated_date = estimate_jieqi_date(year, jieqi_index)
    
    # 3. 二分法查找精确时刻
    start_dt = estimated_date - 2 days
    end_dt = estimated_date + 2 days
    
    while precision < 0.0001:
        mid_dt = (start_dt + end_dt) / 2
        lon = calculate_sun_longitude(mid_dt)
        
        if lon < target_longitude:
            start_dt = mid_dt
        else:
            end_dt = mid_dt
    
    return mid_dt
```

## ⚠️ 注意事项

### 1. 立春分界

**重要**：年柱以**立春**为界，不是正月初一

- 2026 年立春：2 月 4 日
- 2 月 3 日及之前：乙巳年
- 2 月 4 日及之后：丙午年

### 2. 节气分界

**重要**：月柱以**12 节气**为界，不是农历初一

- 2026 年白露：9 月 8 日
- 9 月 7 日及之前：丁酉月
- 9 月 8 日及之后：戊戌月

### 3. 真太阳时

**重要**：时柱应考虑真太阳时，特别是西部地区

- 北京（116.4°E）：比标准时间晚约 14 分钟
- 成都（104°E）：比标准时间晚约 64 分钟
- 乌鲁木齐（87.6°E）：比标准时间晚约 130 分钟

### 4. 早晚子时

**注意**：23-24 点为夜子时，0-1 点为早子时

### 5. 基准日校准

**重要**：定期用万年历验证基准日的准确性

- 当前基准日：2026 年 3 月 20 日癸巳日
- 建议：每月验证一次
