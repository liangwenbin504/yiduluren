## 五、方法论沉淀

1. **80% 达标必须全量验证**——5 条求财小样本是假象，全量实测 54%
2. **假阴性排查顺序**：输入数据完整性 → API 调用层（签名/参数/凭据）→ 模型行为（思考/格式）
3. **低成本模型瓶颈 = 随机性 > 准确性**——用投票众数稳定化
4. **占事修正必须带课体条件**——无条件修正误伤率高（勾陈=平 误伤不虞格）
5. **升级机制需双通道**——投票分歧（波动）+ 信号矛盾（一致错误）
6. **删除/修正后准确率必须实测**，不可推算；同源重复课先查重再归因
