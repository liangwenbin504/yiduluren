# 日课分析系统 - README

## 项目简介

日课分析系统是一个基于传统择日学理论开发的智能化日课分析工具。系统整合了**斗首择日**、**演禽真法**、**大六壬**等多种传统术数方法，通过科学的加权评分算法，为用户提供全面、客观的日课吉凶评价。

## 核心特性

✅ **传统理论**: 严格遵循《斗首择日秘本》等古籍规则  
✅ **模块化设计**: 5 大核心模块，松耦合、易扩展  
✅ **科学评分**: 0-100 分量化评价，支持自定义权重  
✅ **高精度**: 支持当前至 2100 年的日期范围，精确处理节气  
✅ **完整文档**: 使用手册、API 文档、测试报告齐全  
✅ **测试完备**: 7 项综合测试，100% 通过率  

## 快速开始

### 安装依赖

本项目使用 Python 3.7+，无需额外依赖包。

### 基础使用

```python
from datetime import datetime
from src.engine.riku_analysis_system import RikeAnalysisSystem

# 创建系统
system = RikeAnalysisSystem()

# 分析单个日课
result = system.analyze_single_ke(
    date=datetime(2026, 3, 24),
    shichen_index=7,  # 午时
    shan='壬'  # 坐山
)

# 查看结果
print(f"综合评分：{result['综合评分']['综合评分']}分")
print(f"综合吉凶：{result['综合评分']['综合吉凶']['level_name']}")
print(result['GLM 评价报告'])
```

## 系统架构

```
日课分析系统
├── 日期范围生成模块      # 生成日期和时辰数据
├── 斗首课格分析模块      # 斗首择日分析
├── 演禽真法分析模块      # 演禽星宿分析
├── 综合评分模块         # 加权评分计算
└── 主分析系统          # 整合所有模块
```

## 核心模块

### 1. 日期范围生成模块
- 生成当前至 2100 年 12 月 31 日的日期序列
- 每日 12 个时辰数据
- 处理节气、闰年等特殊历法

### 2. 斗首课格分析模块
- 基于坐山生成斗首课格
- 天干化气五行计算
- 格局判定 (三元辰格、三武格等)
- 0-100 分评分

### 3. 演禽真法分析模块
- 起四禽 (年禽、月禽、日禽、时禽)
- 二十八宿排布
- 禽星生克关系
- 格局判定 (四吉俱全格等)

### 4. 综合评分模块
- 加权评分算法
- 默认权重：斗首 40%、演禽 30%、大六壬 30%
- 支持自定义权重
- 吉凶等级判定 (9 个等级)

### 5. 主分析系统
- 整合所有模块
- 提供统一接口
- 生成评价报告

## 评分标准

| 分数 | 等级 | 说明 |
|------|------|------|
| 90-100 | 上上大吉 | 百事亨通 |
| 80-89 | 上吉 | 诸事顺利 |
| 70-79 | 中吉 | 总体吉利 |
| 60-69 | 小吉 | 斟酌用之 |
| 50-59 | 吉凶参半 | 谨慎行事 |
| 40-49 | 小凶 | 不宜用 |
| 30-39 | 中凶 | 忌用 |
| 20-29 | 大凶 | 不可用 |
| 0-19 | 上凶 | 大忌 |

## 高级用法

### 自定义权重

```python
from src.engine.comprehensive_scorer import WeightConfig

# 自定义权重：斗首 50%、演禽 25%、大六壬 25%
custom_weight = WeightConfig(
    douhou_weight=0.5,
    yanqin_weight=0.25,
    daliuren_weight=0.25
)

system = RikeAnalysisSystem(weight_config=custom_weight)
```

### 筛选最佳日课

```python
# 获取 2026 年 3 月最佳 10 个日课
best_results = system.get_best_ke(
    start_date=datetime(2026, 3, 1),
    end_date=datetime(2026, 3, 31),
    shan='壬',
    top_n=10
)
```

### 分析日期范围

```python
# 分析指定日期范围
results = system.analyze_date_range(
    start_date=datetime(2026, 3, 1),
    end_date=datetime(2026, 3, 31),
    shan='壬',
    min_score=70  # 筛选 70 分以上
)
```
