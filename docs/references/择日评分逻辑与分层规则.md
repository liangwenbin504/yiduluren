## 一、评分流程概览

择日评分采用 **11 步管线式处理**，每个时辰作为一个独立候选进行评估：

```
输入 → ①斗首快筛 → ②大六壬排盘 → ②b权威仪度评分 → ②c古籍合参 → ②d古例变通
     → ③禄马贵人引擎 → ④演禽 → ⑤知识库仪度 → ⑥禄马贵明细
     → ⑦本命/本命年命 → ⑧十三吉课+加权分 → ⑨补救建议 → ⑩空亡审计 → ⑪十二建星
     → ⑬禄马贵人分层评级
     → 输出：候选课（含各维度分数、等级、排序键）
```

### 过滤阈值

| 环节 | 阈值 | 说明 |
|------|------|------|
| 斗首 | ≥ 50 | 低于50分直接淘汰 |
| 大凶排除 | - | 命中文档大凶格直接淘汰 |
| 六壬分 | ≥ min_liuren | 默认70，可配置 |
| 演禽 | ≥ 50 | 低于50分淘汰 |

### 2.7 三传间神贵禄检查（夹贵/夹禄）

**引擎**：`engine/daliuren_luma_guiren.py` → `check_sanchuan_luma_guiren`

**规则**：检查三传两两之间的间神（中间地支）是否为日干贵人或日干禄，形成"夹贵"或"夹禄"的吉格。

**判定逻辑**：
1. 计算三传相邻两传之间的间神（取较短路径上的中间地支）
2. 同时计算末传与初传之间的间神（首尾相连）
3. 若间神为日干贵人，则判定为"夹贵"
4. 若间神为日干禄，则判定为"夹禄"

**示例1 - 夹贵**：
- 铸印课三传：戌 → 巳 → 子，日干：丙/丁
- 丙丁贵人：[亥, 酉]
- 末传(子)与初传(戌)之间的间神为"亥"
- 亥 ∈ 丙丁贵人[亥, 酉] → 夹贵 ✅

**示例2 - 夹禄**：
- 铸印课三传：戌 → 巳 → 子，日干：壬
- 壬禄：亥
- 末传(子)与初传(戌)之间的间神为"亥"
- 亥 = 壬禄 → 夹禄 ✅

**示例3 - 案例1**：
- 三传：卯 → 申 → 丑，日干：辛
- 辛贵人：[寅, 午]
- 末传(丑)与初传(卯)之间的间神为"寅"
- 寅 ∈ 辛贵人[寅, 午] → 夹贵 ✅

**加分**：每个夹贵/夹禄 +8分

### 2.8 贵人禄乘临属相得利

**引擎**：`engine/daliuren_luma_guiren.py` → `get_benefited_zodiacs`

**规则**：吉课应验在特定属相的人身上，通过贵人禄乘临关系计算得利属相。

**判定逻辑**：
1. 发传的贵人禄所在地支 → 对应属相得利
2. 贵人禄乘临的地支 → 对应属相得利

**示例**：
- 三传申子辰水局，乙巳年月日
- 日干乙贵人在子、申
- 贵人申乘临辰（申下为辰）→ 辰属龙得利
- 贵人子乘临申（子下为申）→ 申属猴得利
- 贵人申本身 → 申属猴得利
- 贵人子本身 → 子属鼠得利
- **得利属相：申子辰（猴鼠龙）**

## 三、加权加分规则

### 3.1 加权加分公式

```python
bonus_score = (命中吉课数 × 3) + (禄马贵发传数 × 4) + (到山到向数 × 2) + 拱格数
```

### 3.2 权重说明

| 因素 | 单位加分 | 说明 |
|------|----------|------|
| 禄马贵发传 | × 4 | 天机灵动，权重最高 |
| 十三吉课 | × 3 | 课体质量 |
| 到山到向 | × 2 | 禄马贵方位 |
| 拱格 | × 1 | 仪度拱格命中 |

### 3.3 示例

若一课命中：
- 2个十三吉课
- 禄马贵发传3处
- 到山到向4柱
- 2个拱格

则：`bonus_score = 2×3 + 3×4 + 4×2 + 2 = 6 + 12 + 8 + 2 = 28`

## 四、禄马贵人分层评级（核心规则）

### 4.1 评级条件

分层评级严格按以下四个条件判定：

| 条件 | 变量 | 判定标准 |
|------|------|----------|
| 到山到向 | `has_dx` | 四柱禄马贵人到山到向数 > 0 |
| 发三传 | `has_fc` | 三传中有日柱禄马贵人 |
| 十三吉课 | `has_j13` | 命中十三吉课数 > 0 |
| 互禄互贵 | `has_mutual` | 多柱交叉验证：禄是对方贵人或贵人含对方禄 |

### 4.2 互禄互贵格详解（多柱交叉验证）

#### 互禄格：禄是对方贵人

互禄是指某柱的禄神（地支）恰好是另一柱/山的贵人地支，形成"禄即为贵"的吉象。

**判定规则**（三条规则，命中任一条即算互禄）：

| 规则 | 禄源 | 检查目标 | 判定逻辑 |
|------|------|----------|----------|
| 1 | 年干禄 `LU[nian_gan]` | 月干/日干/本命/坐山 | 年干禄 ∈ 月干贵人 ∪ 日干贵人 ∪ 本命贵人 ∪ 坐山贵人 |
| 2 | 本命禄 `LU[bm_gan]` | 坐山 | 本命禄 ∈ 坐山贵人 |
| 3 | 月干禄 `LU[yue_gan]` | 年干/月干/日干/坐山 | 月干禄 ∈ 年干贵人 ∪ 月干贵人 ∪ 日干贵人 ∪ 坐山贵人 |

**示例**：
- 乙年 + 子山：乙禄卯 ∈ 子贵人[卯,巳] → 互禄 ✅
- 庚年 + 乙月：庚禄申 ∈ 乙贵人[子,申] → 互禄 ✅
- 壬年 + 丙月：壬禄亥 ∈ 丙贵人[亥,酉] → 互禄 ✅
- 戊月 + 丑山：戊禄巳 ∈ 丑贵人[卯,巳] → 互禄 ✅

#### 互贵格：贵人含对方禄

互贵是指某柱的贵人地支列表中包含另一柱/山的禄神地支，形成"贵即含禄"的吉象。

**判定规则**（三条规则，命中任一条即算互贵）：

| 规则 | 贵人源 | 检查目标 | 判定逻辑 |
|------|--------|----------|----------|
| 1 | 年干贵人 `GAN_GUIREN_ZHIS[nian_gan]` | 月干/日干/本命/坐山的禄 | 年干贵人 ∩ {月干禄, 日干禄, 本命禄, 坐山禄} ≠ ∅ |
| 2 | 本命贵人 `GAN_GUIREN_ZHIS[bm_gan]` | 坐山的禄 | 本命贵人 ∩ 坐山禄 ≠ ∅ |
| 3 | 月干贵人 `GAN_GUIREN_ZHIS[yue_gan]` | 年干/月干/日干/坐山的禄 | 月干贵人 ∩ {年干禄, 月干禄, 日干禄, 坐山禄} ≠ ∅ |

**示例**：
- 乙年 + 庚月：乙贵人[子,申] ∋ 庚禄申 → 互贵 ✅
- 壬年 + 丙月：壬贵人[卯,巳] ∋ 丙禄巳 → 互贵 ✅
- 癸年 + 乙山：癸贵人[卯,巳] ∋ 乙禄卯 → 互贵 ✅

#### 数据映射表

**天干禄神** (`LU`)：
```
甲→寅  乙→卯  丙→巳  丁→午  戊→巳
己→午  庚→申  辛→酉  壬→亥  癸→子
```

**天干贵人地支** (`GAN_GUIREN_ZHIS`)：
```
甲戊庚→丑未  乙己→子申  丙丁→亥酉  壬癸→卯巳  辛→寅午
```

**坐山贵人** (`BEN_SHAN_GUIREN`)：二十四山对应贵人地支（双山纳甲口径）

**坐山禄神** (`BEN_SHAN_LU_DSM`)：二十四山对应禄神地支（双山纳甲口径）

### 4.3 五级分层（含互禄互贵加成）

| 等级 | 名称 | 条件 | 基础分 | 说明 |
|------|------|------|--------|------|
| **L3** | 上上吉（互禄互贵） | 到山到向 ✅ + 发三传 ✅ + 十三吉课 ✅ + 互禄互贵 ✅ | 100 | 最佳课，四条件齐备 |
| **L3** | 上上吉 | 到山到向 ✅ + 发三传 ✅ + 十三吉课 ✅ | 95 | 三条件齐备（无互禄互贵） |
| **L2** | 吉课 | 到山到向 ✅ + 发三传 ✅ | 75 | 吉课，有到山到向且发三传 |
| **L1** | 普通课 | 到山到向 ✅（不发三传） | 50 | 有到山到向但不发三传 |
| **L0** | 平课 | 无到山到向 | 25 | 前提条件不满足 |

### 4.4 判定逻辑流程图

```
开始
  │
  ├─ has_dx && has_fc && has_j13 && has_mutual → L3 上上吉（互禄互贵）
  │
  ├─ has_dx && has_fc && has_j13 → L3 上上吉
  │
  ├─ has_dx && has_fc → L2 吉课
  │
  ├─ has_dx → L1 普通课 ⚠️ 关键：不发三传即使有吉课也只能算普通课
  │
  └─ 其他 → L0 平课
```

### 4.5 关键规则说明

> **禄马贵人到山到向，且必须发出在三传上，如果没有发出在三传，只能算是普通课。如果再加上是十三美课，才算吉课。**

此规则的核心：
1. **到山到向是前提**：没有到山到向，无论其他条件如何，都是平课
2. **发三传是吉课必要条件**：不发三传，即使有到山到向+十三吉课，也只能算普通课（L1）
3. **十三吉课是锦上添花**：在到山到向+发三传的基础上，加上十三吉课才能达到上上吉（L3）
4. **互禄互贵是顶级加成**：在三条件齐备的基础上，加上互禄互贵可获得最高基础分（100 vs 95）

|------|----------|--------|----------|----------|------|------|

| 2 | ✅ | ✅ | ✅ | ❌ | **L3** | 三条件齐备，上上吉 |
| 3 | ✅ | ✅ | ❌ | - | **L2** | 到山到向+发三传，吉课 |

| 5 | ✅ | ❌ | ❌ | - | **L1** | 到山到向但不发三传 |
| 6 | ❌ | ✅ | ✅ | - | **L0** | 无到山到向，前提不满足 |
| 7 | ❌ | ❌ | ❌ | - | **L0** | 什么都没有，平课 |

## 五、排序逻辑

### 5.1 两种排序模式

#### 模式1：日期范围择日（range）

适用于常规择日，按以下优先级排序：

```
1. 禄马贵人条件倾向（若启用）
2. 月柱六相优先级（武财>元辰>廉贞>贪官>破鬼）
3. 加权加分（bonus_score）
4. 六壬分（liuren_score）
5. 总分（total_score）
```

#### 模式2：禄马贵人择日（lmg）

适用于禄马贵人条件择日，按以下优先级排序：

```
1. 禄马贵人分层评级（L3>L2>L1>L0）
2. 月柱六相优先级
3. 加权加分
4. 六壬分
5. 总分
```

### 5.2 同层内排序

在同一分层内，按以下公式计算细节排序分：

```python
排序分 = 基础分 + 到山到向数 × 10 + 发传数 × 5 + 十三吉课数 × 3 + 互禄互贵 × 20
```

| 等级 | 基础分 | 说明 |
|------|--------|------|
| L3 | 400 | 最高优先级 |
| L2 | 300 | |
| L1 | 200 | |
| L0 | 100 | 最低优先级 |

**互禄互贵加成**：若课命中互禄或互贵格，额外加20分，用于在同层内优先排序。

### 5.3 示例

若两课都是 L3：
- 课A：到山4柱，发传2处，吉课4个，有互禄互贵 → 排序分 = 400 + 4×10 + 2×5 + 4×3 + 20 = 442
- 课B：到山4柱，发传1处，吉课4个，无互禄互贵 → 排序分 = 400 + 4×10 + 1×5 + 4×3 + 0 = 417

则课A排在课B前面（因为有互禄互贵加成）。

## 六、总分计算

### 6.1 基础分

```python
总分 = min(100, round(权威仪度评分 + 本命年命调整, 1))
```

### 6.2 本命年命调整

| 条件 | 加分 | 说明 |
|------|------|------|
| 本命四柱全到山到向 | +8 | 本命禄马贵齐备 |
| 功名格（本命前一位+后一位） | +5 | 利于功名 |
| 出行+马临本命 | +5 | 利于出行 |

### 6.3 等级判定

总分对应的等级与权威仪度评分一致（见2.3节）。

## 八、补救建议

系统会根据评分结果给出针对性建议：

| 情况 | 建议 |
|------|------|
| 到山到向 < 4柱 | 可换年柱/月柱重选以催动到山到向 |
| 发传 = 0 | 禄马贵未发三传（天机未灵动），宜择发传之日 |

## 实战案例

### 案例1：2027-01-02 酉山 申时 开业课

**四柱**：丙午 己丑 辛巳 丙申
**课体**：重审课
**三传**：卯 → 申 → 丑

#### 评分流程追踪

| 步骤 | 结果 | 说明 |
|------|------|------|
| ① 斗首快筛 | 50分 ✅ | 达标，继续评估 |
| ② 六壬排盘 | 重审课 | 三传：卯→申→丑 |
| ③ 权威仪度评分 | 55分 / 中吉课 | |
| ④ 禄马贵人 | 4柱合格，三传禄马贵人1个 | |
| ⑤ 演禽 | 62分 ✅ | |
| ⑥ 十三吉课 | 2个命中（和美、斫轮） | |
| ⑦ 互禄互贵 | 互禄1项+互贵1项 | 详见下方 |
| ⑧ 加权加分 | 18分 | |
| ⑨ 总分 | 100分 / 上上吉 | |

#### 互禄互贵判定详情

**互禄**（1项命中）：
- 月干己禄午 → 日干辛贵人[寅,午] ✅

**互贵**（1项命中）：
- 年干丙贵人[亥,酉] → 日干辛禄酉 ✅

#### 传间见贵吉格

三传"卯 → 申 → 丑"中：
- 末传(丑)与初传(卯)之间的间神为**寅**
- 寅是日干辛的贵人之一（辛贵人[寅, 午]）
- **传间见贵** ✅（加8分）

#### 分层评级

| 条件 | 状态 | 说明 |
|------|------|------|
| 到山到向 | ✅ | 4柱合格 |
| 发三传 | ✅ | 三传中有禄马贵人 |
| 十三吉课 | ✅ | 2个命中 |
| 互禄互贵 | ✅ | 1项互禄+1项互贵 |

**结果**：L3 上上吉（禄马贵人到山到向+发三传+十三吉课+互禄互贵），基础分100
