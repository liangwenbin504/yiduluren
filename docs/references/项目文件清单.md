## 📋 模块功能清单

### 1. 日期范围生成模块 (date_range_generator.py)

**类**: `DateRangeGenerator`

**主要方法**:
- `__init__()`: 初始化
- `generate_date_range()`: 生成日期范围
- `generate_daily_ke_data()`: 生成单日 12 时辰数据
- `get_single_day_data()`: 获取单日数据
- `get_single_ke_data()`: 获取单个时辰数据
- `generate_full_range_data()`: 生成完整范围数据

**数据结构**:
```python
{
    '公历日期': {...},
    '农历日期': {...},
    '四柱信息': {...},
    '时辰信息': {...},
    '节气信息': {...},
    '特殊历法': {...}
}
```

### 2. 斗首课格分析模块 (douhou_analyzer.py)

**类**: `DouhouKegeAnalyzer`

**主要方法**:
- `analyze_kege()`: 分析斗首课格
- `get_shan_jia_wuxing()`: 获取山家五行
- `get_tiangan_huaqi()`: 获取天干化气
- `get_liuqin()`: 获取六亲星曜
- `_judge_kege_pattern()`: 判断格局
- `_calculate_score()`: 计算评分
- `_generate_duanyu()`: 生成断语

**格局类型**:
- 吉格：三元辰格、三武格、元辰旺相、武财生元格、武财关鬼格
- 凶格：贪狼克元格、破军泄气格、廉子伤克格

**输出**:
```python
{
    '坐山': str,
    '山家五行': str,
    '四柱分析': dict,
    '课格格局': list,
    '综合评分': int (0-100),
    '吉凶断语': list,
    '日志': list
}
```

### 3. 演禽真法分析模块 (yanqin_analyzer.py)

**类**: `YanQinAnalyzer`

**主要方法**:
- `analyze_yanqin()`: 分析演禽课
- `get_nian_qin/yue_qin/ri_qin/shi_qin()`: 起四禽
- `analyze_shengke()`: 分析生克关系
- `_analyze_shengke_relations()`: 分析生克关系
- `_judge_yanqin_patterns()`: 判定格局
- `_calculate_yanqin_score()`: 计算评分
- `_generate_yanqin_duanyu()`: 生成断语

**格局类型**:
- 吉格：四吉俱全格、连续相生格、三吉格、比和格
- 凶格：连续相克格

**输出**:
```python
{
    '四柱': dict,
    '四禽': dict,
    '四禽禽星': dict,
    '二十八宿属性': dict,
    '生克关系': dict,
    '格局判定': list,
    '综合评分': int (0-100),
    '吉凶断语': list
}
```

### 4. 综合评分模块 (comprehensive_scorer.py)

**类**: 
- `WeightConfig` (数据类): 权重配置
- `ComprehensiveScorer`: 综合评分器

**主要方法**:
- `set_weights()`: 设置权重
- `get_weights()`: 获取权重
- `calculate_comprehensive_score()`: 计算综合评分
- `compare_scores()`: 比较多个评分
- `generate_report()`: 生成报告

**权重配置**:
```python
WeightConfig(
    douhou_weight=0.4,    # 斗首 40%
    yanqin_weight=0.3,    # 演禽 30%
    daliuren_weight=0.3   # 大六壬 30%
)
```

**输出**:
```python
{
    '综合评分': float,
    '综合吉凶': dict,
    '各单项评分': dict,
    '评分详情': list,
    '权重配置': dict
}
```

### 5. 主分析系统 (riku_analysis_system.py)

**类**: `RikeAnalysisSystem`

**主要方法**:
- `analyze_single_ke()`: 分析单个日课
- `analyze_daily_ke()`: 分析单日所有时辰
- `analyze_date_range()`: 分析日期范围
- `get_best_ke()`: 获取最佳日课
- `_generate_glm_report()`: 生成 GLM 报告

**输出**:
```python
{
    '基础信息': dict,
    '斗首课格分析': dict,
    '演禽真法分析': dict,
    '大六壬课体分析': dict,
    '综合评分': dict,
    '辅助信息': dict,
    'GLM 评价报告': str,
    '系统日志': list
}
```

```

   ↓

   ↓
```
