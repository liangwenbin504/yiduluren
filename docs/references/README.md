# 仪度六壬择日软件

一款基于《仪度六壬选日要诀》开发的专业大六壬排盘与斗首择日软件。

## 功能特性

### 斗首择日
- ✅ 二十四山山家五行配置
- ✅ 天干化气五行计算
- ✅ 番化五行推演
- ✅ 斗首五星配置（元辰、武财、贪狼、廉贞、破军）
- ✅ 四柱化气分析
- ✅ 吉凶判断

### 大六壬排盘
- ✅ 月将起法（按节气/农历月）
- ✅ 天地盘排布
- ✅ 四课起法
- ✅ 三传起法（九宗门：贼克、比用、涉害、遥克、昴星、别责、八专、伏吟、反吟）
- ✅ 禄马贵推算
- ✅ 十干寄宫

## 使用说明

### 斗首择日
1. 选择山向（二十四山）
2. 输入年、月、日、时的天干
3. 点击"斗首分析"按钮
4. 查看分析结果：
   - 山家五行
   - 五星配置
   - 四柱化气分析
   - 吉凶判断

### 大六壬排盘
1. 选择农历月份
2. 选择占时（时辰）
3. 输入日干支
4. 点击"开始排盘"按钮
5. 查看排盘结果：
   - 天地盘
   - 四课
   - 三传（含课体、起法）
   - 禄马贵

## 理论基础

### 斗首五行
根据《仪度六壬选日要诀》：
- 壬子巽巳辛戌属土
- 癸丑丙午乾亥属火
- 艮寅甲卯乙辰属木
- 庚酉坤申属金
- 丁未属水

### 天干化气
- 甲己化土
- 乙庚化金
- 丙辛化水
- 丁壬化木
- 戊癸化火

### 大六壬起课
遵循九宗门法则：
1. 贼克法（重审课、元首课）
2. 比用法（知一课）
3. 涉害法（见机格、察微格、缀瑕格）
4. 遥克法（篙矢格、弹射格）
5. 昴星法（虎视格、冬蛇掩日格）
6. 别责法
7. 八专法
8. 伏吟法（自任格、自信格、杜传格）
9. 反吟法（无依格、井栏射格）
