## 数据结构设计

```python
class LiuShiSiKe:
    """64 课经数据结构"""
    def __init__(self):
        self.ke_name = ""        # 课名
        self.ke_type = ""        # 课体（贼克、涉害等）
        self.features = {}       # 特征（三传、干支等）
        self.description = ""    # 课经原文
        self_judgment = ""       # 断语
        self_examples = []       # 示例课例
```

## 关联匹配规则

### 1. 课体匹配
- 根据起课法判断课体（贼克、涉害、遥克等）
- 匹配对应的课经范围

### 2. 三传特征匹配
- 初传、中传、末传的特征
- 三合、六合、刑冲等

### 3. 特殊格局匹配
- 三光、三阳、三奇等
- 天乙、贵人、禄神、驿马等

## 实现步骤

1. 从 PDF 提取课经内容
2. 结构化存储到 JSON/数据库
3. 在起课引擎中添加匹配逻辑
4. GUI 中显示匹配的课经
