## 📊 界面布局（左中右三栏）

### 左侧：课体选择与统计区

#### 1. 课体搜索框
- **搜索**：输入课体名称关键词（如"伏吟"、"反吟"）
- **清除**：清空搜索，显示全部课体

#### 2. 课体列表（带数量统计）
以表格形式显示：
- **课体名称**：如"伏吟课"、"反吟课"、"元首课"等
- **课例数量**：该课体包含的课例个数

**功能**：
- 📋 按课例数量降序排序（最多的在前）
- 🖱️ 点击课体即可查看该课体的所有课例
- 📊 显示统计信息（总数、Top 5 等）

#### 3. 统计信息框
显示：
- 课体总数
- 课例总数
- 出现频率最高的前 5 个课体

---

### 中间：起课参数输入区

#### 基本输入
1. **日干支**：60 甲子选择
2. **月将**：12 地支选择
3. **占时**：12 时辰选择
4. **农历月份**：1-12 月
5. **年支**：12 地支

#### 操作按钮
- **起课**：开始排盘
- **清空**：清空所有输入
- **快捷测试**：
  - 伏吟课（戊辰日 子将 子时）
  - 反吟课（丙寅日 戌将 辰时）
  - 普通课（甲子日 亥将 午时）

## 🎯 使用步骤

### 方法一：浏览课体

1. **查看课体列表**
   - 左侧自动显示所有课体，按课例数量排序
   - 例如："元首课"可能有 500 个课例，"伏吟课"有 200 个课例

2. **搜索课体**
   - 在搜索框输入关键词（如"伏吟"）
   - 点击"搜索"按钮
   - 列表只显示匹配的课体

3. **查看课体详情**
   - 点击某个课体（如"伏吟课"）
   - 右侧显示：
     - 该课体的课例总数
     - 前 20 个课例列表（日干支、月份、时辰、月将、评分）
     - 提示信息

4. **起课验证**
   - 记下感兴趣的课例（如：1. 甲子日 寅月 午时）
   - 在中间输入区输入对应参数
   - 点击"起课"按钮
   - 查看详细的课式排盘

### 方法二：直接起课

1. **选择日干支**
   - 从下拉列表选择（如"甲子"）

2. **选择月将**
   - 选择月将地支（如"亥"）

3. **选择占时**
   - 选择时辰地支（如"午"）

4. **设置辅助参数**
   - 农历月份（用于神煞计算）
   - 年支（用于年支神煞）

5. **点击"起课"**
   - 右侧显示完整课式
   - 自动匹配 64 课经

1. 在左侧搜索框输入"伏吟"

假设您对列表中的第 1 个课例感兴趣：

## ⚙️ 技术说明

### 数据来源
- **课例数据**：`data/720_ke_li.json`（8640 个课例）
- **课经数据**：`data/64_ke_jing_accurate.json`（64 条课经）
- **起课引擎**：`src/engine/complete_qi_ke_engine.py`

### 性能优化
- **课体统计**：启动时一次性计算完成
- **课例搜索**：内存中直接查找，响应迅速
- **起课计算**：< 10ms/课

### 界面设计
- **三栏布局**：课体选择 | 起课输入 | 结果显示
- **树形列表**：支持排序、搜索、点击选择
- **滚动文本**：支持大量内容显示
