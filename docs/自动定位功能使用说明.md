# 自动定位与真太阳时功能使用说明

## 📍 功能概述

**自动定位功能**可以自动获取您电脑的当前位置（通过 IP 定位、GPS 或 WiFi），并根据当地经纬度精确计算真太阳时和四柱信息。

### 核心特性

✅ **自动定位** - 无需手动输入，自动获取当前位置  
✅ **多种定位方式** - 支持 IP 定位、GPS 定位、WiFi 定位  
✅ **精确定时** - 根据当地经纬度计算真太阳时  
✅ **智能匹配** - 自动匹配最近的城市  
✅ **实时计算** - 获取当前时刻的四柱信息

## 🔧 定位方式说明

### 1. IP 定位（默认）

**原理**：通过 IP 地址数据库定位  
**精度**：城市级别（约 10-50 公里）  
**要求**：需要网络连接  
**优点**：无需特殊权限，所有设备可用  
**缺点**：精度相对较低

**使用的服务**：
- ipapi.co
- ip-api.com
- ipinfo.io

### 2. GPS 定位（如果可用）

**原理**：通过 GPS 卫星定位  
**精度**：米级别  
**要求**：设备有 GPS 硬件  
**优点**：精度最高  
**缺点**：需要 GPS 硬件支持

### 3. WiFi 定位（备选）

**原理**：通过附近 WiFi 热点定位  
**精度**：10-100 米  
**要求**：需要访问定位服务 API  
**优点**：室内也能定位  
**缺点**：需要 API 密钥

### 真太阳时计算

**计算公式**：
```
真太阳时 = 平太阳时 + 经度时差 + 均时差

其中：
- 平太阳时：北京时间（东八区标准时间）
- 经度时差：(当地经度 - 120°) × 4 分钟/度
- 均时差：地球轨道椭圆引起的时差（-14 到 +16 分钟）
```

**示例**（北京）：
```
北京时间：18:19
经度：116.40°E
经度时差：(116.40 - 120) × 4 = -14.4 分钟
均时差：-5.1 分钟（2026 年 3 月 15 日）

真太阳时 = 18:19 - 14.4 分 - 5.1 分 = 18:14
```

### 四柱计算

根据真太阳时自动计算时柱：

```python
# 北京 2026 年 3 月 15 日 18:19
# 真太阳时：18:14（酉时）
# 日干：戊（戊子日）
# 五鼠遁：戊癸何方发，壬子是真途
# 酉时天干：辛
# 时柱：辛酉
```

## 💻 实际应用场景

### 场景 1：异地客户同时咨询

```python
# 假设您在北京，客户在成都、上海、乌鲁木齐同时咨询
from auto_location import LocationAutoDetector

detector = LocationAutoDetector()

cities = ['北京', '成都', '上海', '乌鲁木齐']

print("2026 年 3 月 15 日 10:00（北京时间）各地四柱：\n")

for city in cities:
    # 获取城市经纬度
    coords = detector.calendar.get_city_coordinates(city)
    longitude, latitude = coords
    
    # 计算四柱
    sizhu = detector.calendar.get_sizhu_precise(
        2026, 3, 15, 10, 0,
        longitude=longitude,
        latitude=latitude,
        city_name=city
    )
    
    print(f"{city}: {sizhu['年柱']} {sizhu['月柱']} {sizhu['日柱']} {sizhu['时柱']}")

# 输出：
# 北京：丙午 癸卯 壬戌 癸卯
# 成都：丙午 癸卯 壬戌 壬寅  (真太阳时 8:55，寅时)
# 上海：丙午 癸卯 壬戌 癸卯
# 乌鲁木齐：丙午 癸卯 壬戌 壬寅  (真太阳时 7:49，寅时)
```

## ⚠️ 注意事项

### 1. 定位精度

- **IP 定位**：精度约 10-50 公里，适合城市级别应用
- **GPS 定位**：精度米级别，需要 GPS 硬件
- **WiFi 定位**：精度 10-100 米，需要 API 支持

### 2. 网络连接

IP 定位需要网络连接，如果离线则无法自动定位，需要手动设置位置。

### 3. 隐私保护

定位数据仅用于计算真太阳时，不会被存储或上传。

### 4. 时区问题

系统默认使用北京时间（东八区），如果在其他时区，需要手动调整。

### 定位流程

```
1. 尝试 GPS 定位（如果有 GPS 硬件）
   ↓
2. 尝试 WiFi 定位（如果需要）
   ↓
3. 使用 IP 定位（默认方式）
   ↓
4. 获取经纬度坐标
   ↓
5. 计算真太阳时
   ↓
6. 计算四柱信息
```

### 真太阳时计算

```python
def _calculate_true_solar_time(hour, minute, longitude, date_obj):
    # 1. 平太阳时
    local_time = hour + minute / 60.0
    
    # 2. 经度时差
    time_diff = (longitude - 120.0) * 4 / 60.0
    
    # 3. 均时差（天文算法）
    eot = calculate_equation_of_time(date_obj)
    
    # 4. 真太阳时
    true_solar = local_time + time_diff + eot
    
    return true_solar % 24
```
