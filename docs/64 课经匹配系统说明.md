## 二、匹配原理说明

### 2.1 九宗门起课流程

大六壬起课需要按以下步骤:

1. **月将加时** - 起天地盘
2. **四课** - 取干支上下神
3. **三传** - 按九宗门法则取初传、中传、末传
4. **天将** - 按昼夜贵人起十二天将
5. **神煞** - 计算各类神煞

### 2.2 课体判断层次

课体判断分为三个层次:

#### 第一层：基础课体 (已实现)
根据日干支、月将、时支直接判断:
- 伏吟、反吟
- 刚日/柔日起课
- 特殊关系 (月=时，月将=日支等)

#### 第二层：四课课体 (需完善)
需要分析四课结构:
- 贼克情况 (几上克下，几下贼上)
- 四课完备情况
- 干支上下关系

#### 第三层：三传课体 (需完善)
需要分析三传组合:
- 三传五行 (如三传皆土为游子)
- 三传结构 (如三传相连为连珠)
- 三传关系 (如三传递生为亨通)

#### 第四层：神煞课体 (需完善)
需要计算神煞:
- 太岁、月建、月将
- 孤辰寡宿、天鬼、天罡
- 旬首旬尾、德神等

## 五、技术说明

### 5.1 数据结构

每个课经包含:
```json
{
  "ke_name": "课名",
  "ke_type": "类型",
  "definition": "定义",
  "duanyu": ["断语 1", "断语 2", ...],
  "summary": "总断",
  "score": 评分，
  "level": "等级"
}
```

每个课例包含:
```json
{
  "ri_gan_zhi": "日干支",
  "yue": "月",
  "shi": "时",
  "yue_jiang": "月将",
  "matched_ke_jing": ["课经 1", "课经 2", ...],
  "primary_ke_jing": "主课经",
  "duanyu": {
    "duanyu": [...],
    "summary": "...",
    "score": 0,
    "level": "..."
  }
}
```

### 5.2 匹配算法

当前算法基于:
- 日干支阴阳 (刚日/柔日)
- 月将时支关系 (伏吟/反吟)
- 特殊组合 (月=时，月将=日支)
- 五行生克 (乱首、芜淫)

### 5.3 数据来源

- 课经内容：北海闲人《大六壬 64 课经解注》
- 课体特征：360 doc 等网络资源
- 断语评分：系统整理
