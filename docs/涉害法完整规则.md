# 涉害法完整规则

## 概述

**涉害法**是大六壬三传发用的第三法则，用于比用后仍有多课相克的情况。

---

## 使用条件

涉害法的使用前提是：

1. **四课中有两课或以上相克**（已通过贼克法判断）
2. **比用后仍有多课**（已通过比用法判断，但仍有多个候选）

即：贼克法 → 比用法 → **涉害法**

---

## 核心规则

### 基本原则

**取涉害深者为用**

涉害深浅的计算方法：
- 从本位归原位
- 数经过的克位数量
- 克位多者涉害深，取为初传

### 术语解释

**本位**：上神本身在地盘的位置

**原位**：上神在天盘所加临的地盘位置

**克位**：五行克上神的地支位置

**涉害深度**：从本位到原位，顺数经过的克位数量

---

## 涉害深度计算

### 计算步骤

1. **确定本位**
   - 上神本身的地支位置

2. **确定原位**
   - 上神在天盘所加临的地盘位置
   - 即：天盘上神落地盘何处

3. **顺数克位**
   - 从本位开始，顺时针数到原位
   - 统计经过的克位数量

4. **判断五行生克**
   - 地盘支的五行克上神五行 → 该支为克位
   - 例如：上神为金，经过火支 → 火克金，为克位

### 五行生克关系

```
金克木，木克土，土克水，水克火，火克金

金被火克，木被金克，水被土克，火被水克，土被木克
```

### 地支五行

```
寅卯木，巳午火，申酉金，亥子水，辰戌丑未土
```

### 计算示例

**示例**：上神为申（金）

1. 本位：申在地盘的位置
2. 原位：天盘申落地盘何处（假设为寅）
3. 从申顺数到寅：申→酉→戌→亥→子→丑→寅
4. 统计克位：
   - 申（金）：本位，不计
   - 酉（金）：比和，不计
   - 戌（土）：土生金，不计
   - 亥（水）：金生水，不计
   - 子（水）：金生水，不计
   - 丑（土）：土生金，不计
   - 寅（木）：金克木，不计（我克者）
   
   涉害深度 = 0

**示例**：上神为寅（木）

1. 本位：寅在地盘的位置
2. 原位：天盘寅落地盘何处（假设为申）
3. 从寅顺数到申：寅→卯→辰→巳→午→未→申
4. 统计克位：
   - 卯（木）：比和，不计
   - 辰（土）：木克土，不计（我克者）
   - 巳（火）：木生火，不计
   - 午（火）：木生火，不计
   - 未（土）：木克土，不计（我克者）
   - 申（金）：金克木 ✓ **克位**（克我者）
   
   涉害深度 = 1

## 特殊格局

### 1. 见机格

**条件**：涉害深度 > 3

**含义**：害深明显，当机立断

**特点**：
- 涉害很深，经历多次克害
- 事情复杂，需要果断处理
- 取涉害最深者为用

### 2. 涉害课

**条件**：涉害深度 ≤ 3

**含义**：普通涉害课式

**特点**：
- 涉害不深，事情相对简单
- 按正常涉害法处理

### 3. 缀瑕格

**条件**：两课涉害深度相同

**含义**：害深相同，取先见者

**特点**：
- 两课涉害深度相等
- 取第一课（先见者）为初传
- 如瑕疵相连，故名缀瑕

---

## 发用流程

### 完整流程

```
1. 检查比用结果
   ↓
2. 计算各候选的涉害深度
   ↓
3. 取涉害最深者
   ↓
4. 判断格局
   - 深度 > 3 → 见机格
   - 深度 ≤ 3 → 涉害课
   - 深度相同 → 缀瑕格
   ↓
5. 确定初传
   ↓
6. 中传 = 初传的天盘
   ↓
7. 末传 = 中传的天盘
```

### 代码实现

```python
def _she_hai_fa(self, bi_yong_results, tiandi_pan, ri_gan):
    """涉害法"""
    
    # 1. 计算每个候选的涉害深度
    hai_depths = []
    for ke_num, shang, xia in bi_yong_results:
        depth = self._calculate_she_hai_depth(shang, tiandi_pan)
        hai_depths.append((ke_num, shang, xia, depth))
    
    # 2. 取涉害最深者
    max_depth = max(h[3] for h in hai_depths)
    deepest = [h for h in hai_depths if h[3] == max_depth]
    
    # 3. 判断格局
    if len(deepest) == 1:
        chu_chuan = deepest[0][1]
        ke_ti = '见机格' if max_depth > 3 else '涉害课'
    else:
        # 涉害相同，取先见者（缀瑕格）
        chu_chuan = deepest[0][1]
        ke_ti = '缀瑕格'
    
    # 4. 确定三传
    zhong_chuan = tiandi_pan[chu_chuan]
    mo_chuan = tiandi_pan[zhong_chuan]
    
    return {
        '初传': chu_chuan,
        '中传': zhong_chuan,
        '末传': mo_chuan,
        '课体': ke_ti,
        '起法': '涉害法',
        '涉害深度': max_depth
    }
```

## 注意事项

### 1. 克位判断

**只计克我者，不计我克者**

- 上神为金，火支为克位（火克金）✓
- 上神为金，木支不为克位（金克木）✗

### 2. 顺数规则

**必须顺时针数**

- 从本位开始，顺数到原位
- 不可逆数
- 数一圈回到本位

### 3. 本位计算

**本位不计入克位**

- 从本位开始数
- 本位本身不计算为克位

### 4. 比和关系

**比和者不计为克位**

- 五行相同者为比和
- 如上神为金，酉金为比和
- 比和不为克位

## 与其他法则的关系

### 优先级顺序

```
1. 贼克法 ← 有克先取克
2. 比用法 ← 多课比和
3. 涉害法 ← 比用后仍多
4. 遥克法 ← 无克取遥克
5. 昂星法 ← 无克用昂星
6. 别责法 ← 四课不全
7. 八专法 ← 干支同位
8. 伏吟法 ← 天地盘同
9. 反吟法 ← 天地盘冲
```

### 涉害法的位置

涉害法在九法中排第 3 位：

1. 先用贼克法（有克贼直接用）
2. 贼克多课用比用（与日干比和）
3. 比用仍多用**涉害**（取害深者）
4. 无比用则用遥克（无克取遥克）
...
