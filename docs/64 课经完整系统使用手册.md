# 大六壬 64 课经完整系统使用手册

## 一、系统简介

本系统实现了大六壬 64 课经的完整提取、与 720 课例的精准匹配，以及便捷的查看功能。

### 核心功能
1. **64 课经完整数据库**: 包含所有 64 课经的课名、类型、定义、断语、评分
2. **720 课例匹配**: 8640 个基础课例与 64 课经精准关联
3. **便捷查看器**: 图形界面支持搜索、浏览、导出
4. **自动评价**: 起课后自动显示匹配的课经及断语

## 二、快速开始

### 2.1 启动课经查看器
```bash
python src/ui/comprehensive_ke_jing_viewer.py
```

### 2.2 查看课经信息
1. 在左侧列表选择课经
2. 右侧显示详细信息:
   - **课名**: 如"元首课"
   - **类型**: 如"贼克法"
   - **评分**: 如"85 分"
   - **等级**: 如"上吉"
   - **定义**: 课经的定义
   - **断语**: 多条原文断语
   - **匹配课例**: 显示匹配的课例列表

### 2.3 搜索课经
1. 在搜索框输入关键词 (课名、类型、断语等)
2. 点击"搜索"按钮
3. 列表显示相关课经

## 五、API 使用

### 5.1 查询课经信息
```python
from src.engine.accurate_ke_jing_matcher import AccurateKeJingMatcher

# 初始化匹配器
matcher = AccurateKeJingMatcher()

# 查询课经详细信息
ke_data = matcher.query_ke_jing('元首课')
print(f"课名：{ke_data['ke_name']}")
print(f"类型：{ke_data['ke_type']}")
print(f"定义：{ke_data['definition']}")
print(f"断语：{ke_data['duanyu']}")
print(f"评分：{ke_data['score']} ({ke_data['level']})")
```

### 5.2 查询匹配课例
```python
# 查询匹配某课经的所有课例
matched = matcher.query_ke_by_name('元首课')
print(f"匹配课例数：{len(matched)}")
for item in matched[:5]:
    print(f"  {item['ke_key']} - {item['ri_gan_zhi']}年{item['yue']}月{item['shi']}时")
```

### 5.3 获取统计信息
```python
stats = matcher.get_statistics()
print(f"课经总数：{stats['total_ke_jing']}")
print(f"课例总数：{stats['total_ke_li']}")
print(f"已匹配课例：{stats['matched_ke_li']}")
print("\n课经分布 (前 10):")
for ke_name, count in sorted(stats['ke_jing_distribution'].items(), 
                            key=lambda x: x[1], reverse=True)[:10]:
    print(f"  {ke_name}: {count} 课")
```

## 六、九宗门起课方法

### 6.1 九宗门总纲
九宗门是大六壬的起课方法，用于确定初传 (发用):

```
课经口诀：
元首重审比涉遥，昴星别责八伏反。
无禄绝嗣度厄芜，赘婿乱首和美欢。
玄胎三交并游子，铸印轩盖连珠盘，
亨通殃咎全局引；三光三阳时泰安。
```

### 6.2 起课步骤

1. **贼克法**: 四课中有克贼
   - 一上克下 → 元首课
   - 一下贼上 → 重审课

2. **比用法**: 有两课克贼
   - 取与日干相比者为用

3. **涉害法**: 比用后仍有多课
   - 计算涉害深度，取最深者

4. **遥克法**: 四课无克贼
   - 取遥相克者为用

5. **昴星法**: 四课无克贼无遥克
   - 取昴星为用

6. **别责法**: 四课中有两课相同
   - 取别支为用

7. **伏吟法**: 月将=占时
   - 取日干寄宫为用 → 伏吟课

8. **反吟法**: 月将冲占时
   - 取日干寄宫为用 → 反吟课

### 6.3 特殊课体判断

根据课传特征判断特殊课体:
- **三传相连** → 连珠课
- **三传合局** → 全局课
- **三传巳戌卯** → 铸印课
- **三传午卯子** → 轩盖课 (正七月) / 三交课 (他月)
- **年月日时四建在课传** → 盘珠课
- **干支旺相，吉将在传** → 三光课
- **太岁月建乘龙合发用** → 时泰课

## 七、实际应用

### 7.1 择日应用
在选择日期时:
1. 查看该日匹配的课经
2. 根据课经评分判断吉凶

4. 注意特殊格局

## 十、常见问题

### Q1: 为什么一个课例匹配多个课经？
A: 因为一个课例可能同时具备多个课经的特征。例如，一个课例可能既是元首课，又是盘珠课。

### Q2: 课经评分如何使用？
A: 
- 80 分以上：上吉，大吉之日
- 60-79 分：中平，可用
- 50-59 分：下吉，慎用
- 50 分以下：大凶，不用

### Q3: 如何理解九宗门与 64 课经的关系？
A: 
- 九宗门是起课方法，用于确定三传
- 64 课经是断法体系，用于判断吉凶
- 先以九宗门起课，再根据课体特征确定属于 64 课经中的哪一课

### Q4: 鬼墓课的断语在哪里？
A: 在查看器中搜索"鬼墓课"，可查看完整断语:
- 鬼墓入课，五行克贼，死墓之乡
- 鬼主伤残，墓主闭塞不通
- 人丁多耗，家宅不昌
- 谋为迟滞，捕盗深藏
