Docker Desktop 安装指南 - 简化版
============================================================

亲爱的用户，由于批处理文件编码问题，请按照以下简单步骤操作：

步骤 1: 下载 Docker Desktop (2-5 分钟)
----------------------------------------
1. 打开你的浏览器（Chrome/Edge/Firefox）
2. 访问：https://docs.docker.com/desktop/install/windows-install/
3. 点击页面上的 "Download for Windows" 按钮
4. 等待下载完成（文件约 500MB）

下载的文件名：DockerDesktopInstaller.exe

步骤 2: 安装 Docker Desktop (5-10 分钟)
----------------------------------------
1. 双击运行下载的 DockerDesktopInstaller.exe
2. 如果看到 UAC 提示，点击"是"
3. 在安装选项中，勾选：
   ☑ Use WSL 2 instead of Hyper-V (推荐)
4. 点击 "OK" 或 "Install"
5. 等待安装进度条完成
6. 看到 "Installation successful!" 后点击 "Close"

步骤 3: 重启电脑 (1-2 分钟)
----------------------------------------
安装完成后，重启你的电脑

步骤 4: 启动 Docker Desktop (1-2 分钟)
----------------------------------------
1. 重启后，打开 Docker Desktop
   - 从开始菜单找到 "Docker Desktop"
   - 或在桌面双击图标
2. 如果看到许可协议，点击 "Accept"
3. 等待右下角鲸鱼图标变绿 🐳
4. 看到 "Docker Desktop is running" 表示成功！

步骤 5: 验证安装 (30 秒)
----------------------------------------
打开 PowerShell（按 Win+X，选择 Windows PowerShell）
输入以下命令：

docker --version
docker-compose --version

如果看到版本号，说明安装成功！✅

步骤 6: 部署应用 (5-10 分钟)
----------------------------------------
在 PowerShell 中运行：

cd "d:\新建文件夹\仪度六壬择日\yiduluren"
.\docker-deploy.ps1

然后选择选项 1: 构建并启动容器

等待构建完成后，你的 API 就可以访问了！

访问地址：http://localhost:5000

============================================================
遇到问题？
============================================================

问题 1: Docker 无法启动
解决：重启电脑，确保虚拟化已启用

问题 2: 端口被占用
解决：编辑 docker-compose.yml，将端口改为 8080:5000

问题 3: 容器启动失败
解决：运行 docker-compose logs 查看详细错误

需要更多帮助？
查看：Docker Desktop 安装指南.md（详细版）
