# 六壬择日顾问插件 · 接口契约 v0.1（2026-08-17 憨爷拍板推进）

设计原则：**引擎零改动**——插件只做"调用壳"，事实全部来自 :5555 只读 API。
对齐《基于 DSH 的 AGI Harness 方案》：工具插件 = read-only 沙箱 + 白名单路径 + 顺序约束 + 审计留痕。

## 1. 工具插件（tools，read-only 沙箱）

| 工具名 | 包装的端点 | 入参 | 出参（固定） |
|--------|-----------|------|-------------|
| `zeri_consult` | GET/POST `/api/zeri/analyze` | date, shichen, mountain, type, zhanlei?, ben_ming?, lailong? | 排盘/score/评级/课体/三传/13吉课/杀师/达成矩阵/补救建议/批语 |
| `zeri_batch` | POST `/api/zeri/batch` | start_date, end_date, mountain, zetiri_type, jiri_count | 候选列表（含达成矩阵+补救建议） |
| `shashi_check` | 内嵌 analyze（不单设） | — | — |

白名单：仅 `http://127.0.0.1:5555/api/zeri/*`（只读评估端点）。
禁止：任何写端点（case_feedback 回填属人工，agent 不得调用）。

## 2. 顺序约束（order-table，防乱序）

```
zeri_consult 调用链固定：sizhu(四柱) → paipan(排盘) → score(评分) → shashi(杀师) → remedy(建议)
禁止：跳过 shashi 直接给结论；禁止 agent 自行"计算"课体/三传/天将（必须来自引擎）
```

## 3. 技能插件（knowledge，只读，带版本）

| 技能 | 内容 | 版本 |
|------|------|------|
| `bifa_100` | 毕法赋 100 法（法句+分类+应用） | v1（08-17 全量核对） |
| `jike_13` | 十三吉课 13 格定义（含引从） | v1 |
| `shashi_ge` | 杀师日时歌 12 月 + 犯雷日 + 四季 + 二字并用总则 | v1（08-17 憨爷逐句确认） |
| `zeri_matrix` | 达成矩阵/补救建议口径 | v1 |

agent 查知识只能读这些版本，不可编造口诀原文。
