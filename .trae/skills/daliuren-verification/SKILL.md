# 大六壬起课验证 Skill

## 功能说明

本 Skill 提供大六壬起课规则的完整验证功能，包括：
1. 天地盘排布
2. 四课起法
3. 三传发用（九种法则）
4. 涉害法详细计算（修正版）
5. 贵人盘和十二天将
6. 六亲排布

## 核心特性

### 1. 涉害法修正（最新版本）

**计算路径**：从天盘加临位顺时针数到天盘本身位

**示例**：天盘寅落地盘申位
- 路径：申→酉→戌→亥→子→丑→寅
- 统计：路径上克寅（木）的克位数量（申金、酉金）
- 涉害深度：2

### 2. 贼克法核心定义（重要！）

**贼与克的正确定义**：

> **贼（下贼上）**：地盘下神克天盘上神
> - 定义：**下克上**为贼
> - 位置：地盘（下）克 天盘（上）
> - 含义：卑犯尊，臣欺君，子逆父，妻凌夫
> - 性质：为逆，主急，主凶
> - 优先级：**高**（下贼上先用）

> **克（上克下）**：天盘上神克地盘下神
> - 定义：**上克下**为克
> - 位置：天盘（上）克 地盘（下）
> - 含义：尊制卑，君制臣，父教子，夫管妻
> - 性质：为顺，主缓，主吉
> - 优先级：**低**（无上贼下，再取上克下）

**记忆要点**：
- **贼 = 下克上**（地盘克天盘）
- **克 = 上克下**（天盘克地盘）
- **优先级：贼 > 克**（下贼上先用）

**常见错误**：
- ❌ 错误：把"下贼上"说成"下克上"
- ❌ 错误：把"上克下"说成"上贼下"
- ✅ 正确：贼专指下克上，克专指上克下

**乙丑日卯将丑时案例**：
```
第二课：上申 下午 (贼)
- 上神：申（天盘）
- 下神：午（地盘）
- 关系：午火克申金
- 类型：下克上 = 贼 ✓

第三课：上卯 下丑 (克)
- 上神：卯（天盘）
- 下神：丑（地盘）
- 关系：卯木克丑土
- 类型：上克下 = 克 ✓

结论：下贼上（申）优先于上克下（卯）
初传应取：申
```

### 3. 别责课判定规则（重要！）

**别责课判定核心规则**（根据《六壬大全》）：

> **四课中有两课完全相同（包括日干寄宫转换后），实际只有三课**

**十天干寄宫**：
- 甲寄寅、乙寄辰、丙戊寄巳、丁己寄未
- 庚寄申、辛寄戌、壬寄亥、癸寄丑

**判定方法**：
```python
def is_bie_ze(sike, ri_gan):
    """
    判定是否为别责课
    规则：四课中有两课相同（包括日干寄宫转换后），实际只有三课
    """
    if len(sike) < 4:
        return False  # 四课不全是八专课，不是别责课
    
    # 检查任意两课是否相同（转换日干后）
    for i in range(len(sike)):
        for j in range(i + 1, len(sike)):
            课 1 = sike[i]
            课 2 = sike[j]
            
            # 上神比较
            if 课 1[1] != 课 2[1]:
                continue
            
            # 下神比较：日干要转换为寄宫地支
            课 1 下神 = 课 1[2]
            课 2 下神 = 课 2[2]
            
            # 转换规则
            if 课 1 下神 == ri_gan:
                课 1 下神 = TIAN_GAN_JI_GONG[ri_gan]
            
            if 课 2 下神 == ri_gan:
                课 2 下神 = TIAN_GAN_JI_GONG[ri_gan]
            
            # 比较转换后的下神
            if 课 1 下神 == 课 2 下神:
                return True  # 找到两课相同，是别责课
    
    return False
```

**戊辰日巳将辰时案例**：
```
四课：
  第一课：上午 (火) 下戊 (土)  ← 戊寄巳
  第二课：上未 (土) 下午 (火)
  第三课：上巳 (火) 下辰 (土)
  第四课：上午 (火) 下巳 (火)

判定（按新规则）：
  检查任意两课：
  
  1. 第一课 vs 第二课：
     - 上神：午 ≠ 未 → 不同
  
  2. 第一课 vs 第三课：
     - 上神：午 ≠ 巳 → 不同
  
  3. 第一课 vs 第四课：
     - 上神：午 = 午 ✓
     - 下神：戊 vs 巳
     - 戊转换为巳（寄宫）
     - 下神：巳 = 巳 ✓
     → 相同！是别责课 ✓

  结论：第一课与第四课相同，实际只有三课

别责法起课：
  1. 戊癸合火 → 五合天干是癸
  2. 癸寄丑宫
  3. 丑的天盘是寅
  4. 初传：寅
  5. 中传：日干上神（戊寄巳上神）→ 午
  6. 末传：日干上神 → 午

三传：寅、午、午
```

**关键点**：
- **四课中有两课相同**，实际只有三课
- 下神比较时，**日干要转换为寄宫地支**
- 例如：戊日，第一课下戊，要转换为巳来比较
- **此规则仅用于别责课判定**，其他课式仍按原规则判断

## 涉害法修正说明

### 修正前（错误）
- 路径：从"本位"数到"原位"
- 寅涉害深度：1（错误）

### 修正后（正确）
- 路径：从天盘加临位顺时针数到天盘本身位
- 寅涉害深度：2（正确，申金 + 酉金克寅木）

### 验证案例

**甲子日午将子时**：
- 天地盘：午加子（天盘午落地盘子位）
- 四课：申寅午子
- 比用：寅、午、子（阳支）
- 涉害深度：
  - 寅：2（申、酉克）
  - 午：1（子克）
  - 子：2（未、戌克）
- 结论：缀瑕格，取寅为初传

## 输出格式规范

所有输出必须遵循以下规范：

1. **分隔线统一**：
   - 大标题：`=` × 70
   - 小标题：`-` × 70

2. **对齐格式**：
   - 地支：2 字符宽度（`:2s`）
   - 五行：2 字符宽度（`:2s`）
   - 数字：右对齐（`:2d`）

3. **涉害路径显示**：
   - 起点标注："起点（天盘加临位）"
   - 终点标注："终点（天盘本身位）"
   - 克位标注："↑ X(五行) 克 Y(五行)"

4. **颜色规范**（GUI）：
   - 背景：`#FAF0E6`（淡米色）
   - 标题：`#8B0000`（深红色）
   - 文字：黑色为主，灰色辅助
