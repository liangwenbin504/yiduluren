# 别责法专用起课技能

## 核心功能

专门处理**四课中有两课完全相同**（包括日干寄宫转换后）的情况，实际只有三课有效。

## 调用时机

**当总起课判断 SKILL 检测到四课中有两课相同时调用此 SKILL**。

## 别责课判定规则

### 核心规则

> 四课中有两课完全相同（包括日干寄宫转换后），实际只有三课

## 起课规则（传统规则 - 永久固定）

**别责课起课规则（固定规则，永久不变）**：

**起课原则**：
- **阳日**：取干合上神为初传
  - 取日干五合之天干的寄宫位置的天盘
- **阴日**：取支前三合为初传
  - 取日支的前三合地支（三合局的前一位）
- **中传**：皆取日干上神（日干寄宫的天盘）
- **末传**：皆取日干上神（与中传相同）

**日干五合**：
- 甲己合、乙庚合、丙辛合、丁壬合、戊癸合

**支前三合**（阴日专用）：
- 三合局按顺时针排列：长生→帝旺→墓库
- 取日支顺时针的下一个三合字
- 寅午戌三合：寅→午→戌（顺时针）
  - 寅的支前三合：午
  - 午的支前三合：戌
  - 戌的支前三合：寅
- 亥卯未三合：亥→卯→未（顺时针）
  - 亥的支前三合：卯
  - 卯的支前三合：未
  - 未的支前三合：亥
- 申子辰三合：申→子→辰（顺时针）
  - 申的支前三合：子
  - 子的支前三合：辰
  - 辰的支前三合：申
- 巳酉丑三合：巳→酉→丑（顺时针）
  - 巳的支前三合：酉
  - 酉的支前三合：丑 ✓
  - 丑的支前三合：巳

**阴阳日判定**：
- 阳日：甲、丙、戊、庚、壬
- 阴日：乙、丁、己、辛、癸

**注意**：此规则为别责课的传统起课法则，**永久固定，不得修改**。

## 处理流程

### 第一步：确定初传

```python
def determine_chu_chuan(ri_gan, ri_zhi, tiandi_pan):
    """确定初传（阳日取干合上神，阴日取支前三合）"""
    
    # 阴阳日判定
    yang_ri_gan = ['甲', '丙', '戊', '庚', '壬']
    
    if ri_gan in yang_ri_gan:
        # 阳日：取干合上神
        WU_HE_MAP = {
            '甲': '己', '己': '甲',
            '乙': '庚', '庚': '乙',
            '丙': '辛', '辛': '丙',
            '丁': '壬', '壬': '丁',
            '戊': '癸', '癸': '戊'
        }
        he_gan = WU_HE_MAP[ri_gan]
        
        TIAN_GAN_JI_GONG = {
            '甲': '寅', '乙': '辰', '丙': '巳', '丁': '未', '戊': '巳',
            '己': '未', '庚': '申', '辛': '戌', '壬': '亥', '癸': '丑'
        }
        ji_gong = TIAN_GAN_JI_GONG[he_gan]
        chu_chuan = tiandi_pan[ji_gong]
    else:
        # 阴日：取支前三合
        ZHI_SAN_HE_QIAN = {
            '寅': '寅', '午': '寅', '戌': '寅',  # 寅午戌三合，前三合为寅
            '亥': '亥', '卯': '亥', '未': '亥',  # 亥卯未三合，前三合为亥
            '申': '申', '子': '申', '辰': '申',  # 申子辰三合，前三合为申
            '巳': '巳', '酉': '巳', '丑': '巳'   # 巳酉丑三合，前三合为巳
        }
        chu_chuan = ZHI_SAN_HE_QIAN[ri_zhi]
    
    return chu_chuan
```

### 第二步：确定中末传

```python
def determine_zhong_mo_chuan(ri_gan, tiandi_pan):
    """确定中末传（皆用日干上神）"""
    
    TIAN_GAN_JI_GONG = {
        '甲': '寅', '乙': '辰', '丙': '巳', '丁': '未', '戊': '巳',
        '己': '未', '庚': '申', '辛': '戌', '壬': '亥', '癸': '丑'
    }
    
    # 日干寄宫
    ri_gan_ji_gong = TIAN_GAN_JI_GONG[ri_gan]
    
    # 日干上神
    ri_gan_shang = tiandi_pan[ri_gan_ji_gong]
    
    # 中末传相同
    return ri_gan_shang, ri_gan_shang
```

## 自我校验

### 校验规则

```python
def validate(result, info):
    """校别责法结果"""
    
    # 1. 检查课体
    if result['课体'] != '别责课':
        return False, '课体错误'
    
    # 2. 检查起法
    if result['起法'] != '别责法':
        return False, '起法错误'
    
    # 3. 检查中末传是否相同
    if result['中传'] != result['末传']:
        return False, '别责课中末传应该相同'
    
    # 4. 检查中传是否为日干上神
    ri_gan_shang = info['tiandi_pan'][TIAN_GAN_JI_GONG[info['ri_gan']]]
    if result['中传'] != ri_gan_shang:
        return False, '中传不是日干上神'
    
    return True, '校验通过'
```
