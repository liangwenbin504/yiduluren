# 重新启动服务器以应用修正

## 问题原因

你看到的网页显示**戊己庚**，是因为浏览器访问的是**旧版本的服务器**，使用的是修正前的代码。

## 解决步骤

### 1. 停止旧服务器

如果服务器还在运行，请先停止它：
- 在运行服务器的命令行窗口按 `Ctrl+C`
- 或者关闭该窗口

### 2. 重新启动服务器

```bash
cd "d:\新建文件夹\仪度六壬择日\yiduluren\zongmen"
python http_api_server.py
```

或者双击：
- `启动 API 服务器.bat`

### 3. 刷新网页

在浏览器中：
1. 打开 `http://localhost:5000/demo.html`
2. 按 `Ctrl+F5` 强制刷新（清除缓存）
3. 重新起课：甲申日 酉将 申时

### 4. 验证结果

**正确的三传应该显示：**
```
初传：[财] 壬辰 (六合)
中传：[子] 癸巳 (勾陈)
末传：[子] 甲午 (青龙)
```

**而不是错误的：**
```
初传：[财] 戊辰 (六合)  ← 错误
中传：[子] 己巳 (勾陈)  ← 错误
末传：[子] 庚午 (青龙)  ← 错误
```

## 如果仍然显示错误

如果重启服务器后仍然显示戊己庚，请检查：

1. **确认文件已保存**
   - `http_api_server.py` 第 276 行使用 `get_stem_for_branch`
   - `http_api_server.py` 第 29-74 行有正确的 `get_xun_shou` 函数

2. **清除 Python 缓存**
   ```bash
   # 删除所有.pyc 文件
   del /s *.pyc
   del /s __pycache__
   ```

3. **检查端口占用**
   ```bash
   # 查看 5000 端口是否被占用
   netstat -ano | findstr :5000
   ```
   
   如果被占用，杀掉旧进程或改用其他端口
