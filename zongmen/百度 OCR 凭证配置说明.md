# 百度 OCR API 凭证配置说明

## 问题诊断

当前错误：`invalid_client - unknown client id`

**原因**：使用了 IAM 用户的 AccessKey，而不是 OCR 应用级别的 API Key

## 解决方案

### 方法一：使用主账号创建 OCR 应用（推荐）

#### 步骤 1：切换到主账号
1. 退出当前子账号登录
2. 使用百度主账号登录：https://console.bce.baidu.com/

#### 步骤 2：进入文字识别控制台
1. 访问：https://console.bce.baidu.com/ai/#/ai/ocr/overview/index
2. 或者从控制台首页 → 产品与服务 → 人工智能 → 文字识别

#### 步骤 3：创建应用
1. 点击左侧菜单 **"应用管理"**
2. 点击 **"创建应用"** 按钮
3. 填写应用信息：
   - 应用名称：`六壬 OCR 提取`
   - 应用描述：`用于提取六壬大全 64 课内容`
   - 选择服务：**勾选"通用文字识别(高精度版)"**
4. 点击 **"创建"**

#### 步骤 4：获取 API 密钥
1. 应用创建成功后，在应用列表中找到刚创建的应用
2. 点击 **"管理"** 或 **"查看"**
3. 复制以下三个关键信息：
   - **AppID** (例如：12345678)
   - **API Key** (例如：abc123def456...)
   - **Secret Key** (例如：xyz789uvw012...)

⚠️ **重要**：
- AppID 是纯数字
- API Key 和 Secret Key 是长字符串
- **不是** IAM 的 AccessKey ID 格式（ALTAK-xxxxx）

#### 步骤 5：更新配置
将获取到的三个密钥更新到脚本中：

```python
# baidu_ocr_batch.py

APP_ID = '您的 AppID（纯数字）'
API_KEY = '您的 API Key'
SECRET_KEY = '您的 Secret Key'
```

## 常见问题

**Q: 为什么之前用 IAM AccessKey 不行？**

A: 百度 OCR API 有两种认证方式：
- **应用级认证**：使用 AppID + API Key + Secret Key（推荐）
- **IAM 认证**：使用 AccessKey + Secret Access Key（需要特殊配置）

我们之前混淆了两种方式。OCR 服务主要设计为使用应用级认证。

**Q: 主账号在哪里？**

A: 主账号是您最初注册百度云时使用的账号（通常是手机号或邮箱）

**Q: 创建应用需要付费吗？**

A: 不需要，有免费额度，足够本次使用
