## 一、项目概述

### 1.1 项目背景

《六壬大全》作为六壬学的经典著作，记载了 64 课完整体系。然而，由于历史原因，原著存在版本异文、表述模糊等问题，亟需进行系统性核对与整理。

同时，本项目已建立 720 课例（8640 课）的完整数据库，需要与 64 课课体建立精准映射关系，以实现理论与实践的结合。

### 1.2 项目目标

本项目旨在：
1. **文献核对**：以原著为唯一标准，逐课审核 64 课的核心要素
2. **从格整理**：建立主课与从格的完整关联体系
3. **课例匹配**：实现 64 课与 720 课例的精准匹配
4. **学术规范**：确保 100% 符合原著记载，误差率为零

### 1.3 技术路线

采用**Qwen Max API + 人工审核**的双轨模式：
- **Qwen Max API**：文献分析、数据提取、智能匹配
- **人工审核**：专家复核、争议裁决、质量把控
- **三级校验**：自动匹配 → 人工审核 → 原文回溯

## 六、风险管理

### 6.1 技术风险

**风险 1：API 分析误差**
- 可能性：中
- 影响：高
- 应对措施：
  - 人工复核所有 API 输出
  - 建立错误案例库
  - 优化 Prompt 设计

**风险 2：匹配算法偏差**
- 可能性：中
- 影响：高
- 应对措施：
  - 多级校验机制
  - 边界案例专项处理
  - 专家会诊制度

### 6.2 学术风险

**风险 1：原文理解偏差**
- 可能性：低
- 影响：高
- 应对措施：
  - 参考多家注释
  - 专家集体讨论
  - 存疑标注"待考"

**风险 2：版本选择争议**
- 可能性：低
- 影响：中
- 应对措施：
  - 以最早版本为准
  - 标注版本差异
  - 说明取舍理由

### 6.3 进度风险

**风险 1：工作量低估**
- 可能性：中
- 影响：中
- 应对措施：
  - 预留 20% 缓冲时间
  - 优先完成核心课目
  - 分阶段交付

**风险 2：人员变动**
- 可能性：低
- 影响：高
- 应对措施：
  - 建立标准化流程
  - 详细文档记录
