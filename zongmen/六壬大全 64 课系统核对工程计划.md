# 《六壬大全》64 课系统核对与整理工程

## 📚 项目概述

本项目以《六壬大全》原著为唯一权威标准，对 64 课进行系统性核对与整理，并建立与 720 课例（8640 课）的精准映射关系。

## 🎯 项目目标

1. **文献核对**：逐课审核 64 课的核心要素
2. **从格整理**：建立主课与从格的完整关联体系
3. **课例匹配**：实现 64 课与 720 课例的精准匹配
4. **学术规范**：确保 100% 符合原著记载

## 🔍 核对方法论

### 1. 文献核对阶段

**步骤 1：原文收集**
- 收集《六壬大全》各版本
- 扫描/录入相关章节
- 建立原文数据库

**步骤 2：逐课核对**
- 提取每课原文
- 分析构成要素
- 标注关键信息
- 记录异文情况

**步骤 3：标准化整理**
- 统一术语表述
- 规范格式体例
- 建立索引系统

### 2. 从格专项审核

**识别标准：**
- 课名中带有"从"、"化"、"变"等字样
- 原文中明确说明"从 XX 论"
- 特殊格局变体

**分析方法：**
1. 提取从格原文
2. 分析构成条件
3. 对比主课差异
4. 制定判断标准

### 3. 课体与课例匹配

**匹配流程：**
```
720 课例 → 课体特征提取 → 64 课条件匹配 → 三级校验 → 最终确认
```

**三级校验机制：**
- **一级校验**：自动匹配（程序算法）
- **二级校验**：人工审核（专家复核）
- **三级校验**：原文回溯（对照原著）
