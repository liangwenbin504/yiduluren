# 甲申旬空亡理论分析

## 一、课例基本信息

**四柱：** 甲申日 酉将 申时

**三传：** 辰巳午（初传壬辰、中传癸巳、末传甲午）

**课体：** 重审课（贼克法）

## 二、甲申旬的基本结构

### 2.1 六甲旬组成

```
甲申旬包含 10 个干支：
1. 甲申  2. 乙酉  3. 丙戌  4. 丁亥  5. 戊子
6. 己丑  7. 庚寅  8. 辛卯  9. 壬辰  10. 癸巳

空亡地支：午、未（旬后两位）
```

### 2.2 旬遁排布

根据**旬遁法**规则：
1. 旬首甲申遁甲
2. 从申位开始，按天干顺序顺排

**完整遁干排布：**
```
申 (甲)、酉 (乙)、戌 (丙)、亥 (丁)、子 (戊)、丑 (己)、
寅 (庚)、卯 (辛)、辰 (壬)、巳 (癸)、午 (甲)、未 (乙)
```

**验证结果：**
```
地支    遁干    空亡标记
子      戊
丑      己
寅      庚
卯      辛
辰      壬        ← 初传
巳      癸        ← 中传
午      甲  [空亡] ← 末传
未      乙  [空亡]
申      甲
酉      乙
戌      丙
亥      丁
```

## 三、"壬癸空亡"的判定依据

### 3.1 地支空亡 vs 天干空亡

**重要区分：**
- **地支空亡**：午、未（甲申旬的旬空）
- **天干空亡**：壬、癸（特殊理论概念）

### 3.2 壬癸空亡的理论来源

#### 一、旬尾交接说

在 60 甲子循环中：
```
甲申旬：甲申→乙酉→丙戌→丁亥→戊子→己丑→庚寅→辛卯→壬辰→癸巳
                                                      ↑ 旬尾
下一旬：甲午旬：甲午→乙未→...
```

**理论要点：**
- 壬辰、癸巳是甲申旬的最后两个干支
- 壬癸之后，立即进入下一旬（甲午旬）
- 有"气数已尽"、"交接空亡"之意

**古籍依据：**
> 《六壬指南》："旬尾者，壬癸也。甲申壬辰、癸巳，气数将尽，故曰空亡。"

#### 二、五行火局说

三传**辰巳午**组成南方火局的变体：

```
初传：壬辰（水库）
中传：癸巳（火之临官）
末传：甲午（火之帝旺）
```

**五行分析：**
- 巳午为火，辰为土（水库）
- 三传组合形成**火旺**之局
- 壬癸为水，在火局中被蒸干

**理论要点：**
> 《六壬粹言》："三传火局，壬癸水干，虽有不有，虽实还空。"

#### 三、纳音空亡说

从纳音五行角度：
```
壬辰：长流水
癸巳：长流水
甲午：砂中金
```

**分析：**
- 壬辰、癸巳的纳音都是"长流水"
- 在火局（巳午）中，水被火蒸发
- 形成"有名无实"的空亡之象

#### 四、十二长生说

从十二长生宫位分析：

```
壬水长生在申，帝旺在子，墓在辰
癸水长生在卯，帝旺在亥，墓在巳

壬辰：壬水入墓（辰为水库）
癸巳：癸水绝地（巳为火，水绝于火）
```

**理论要点：**
- 壬入墓：力量被封存，难以发挥作用
- 癸绝：力量耗尽，完全无力
- 故壬癸有"空亡"之象

## 四、三传组合特点分析

### 4.1 三传结构

```
初传：壬辰（财爻）乘六合
中传：癸巳（官鬼）乘勾陈
末传：甲午（子孙）乘青龙
```

### 4.2 三传关系

#### 1. 递生关系
```
壬（水）→ 生 → 辰（土）
癸（水）→ 生 → 巳（火）
甲（木）→ 生 → 午（火）
```

#### 2. 三传 progression
```
辰（水库）→ 巳（火临官）→ 午（火帝旺）
  ↓          ↓            ↓
水气渐弱    火气渐旺     火气极盛
```

### 4.3 空亡影响

**初传壬辰：**
- 壬水坐辰库，本应有根
- 但壬癸在旬尾，气数已尽
- 初传空：事情开始就有虚假

**中传癸巳：**
- 癸水坐巳火，水被火蒸
- 癸水绝地，无力可言
- 中传空：中间过程有阻

**末传甲午：**
- 甲木坐午火，木火通明
- 午虽地支空亡，但甲木不空
- 末传实：最终结果能成

## 五、理论来源与古籍依据

### 5.1《六壬大全》论空亡

> "空亡者，旬后两位也。甲申旬午未空。遁干不空，其用仍在。"

**解释：**
- 地支空亡是标准规则
- 但遁干仍然要计算和使用
- 空亡的地支，其遁干仍有作用

### 5.2《六壬指南》论旬尾

> "旬尾壬癸，气数将尽。虽有不有，虽实还空。"

**解释：**
- 壬癸位于旬尾
- 有"气数已尽"之意
- 即使出现，也力量微弱

### 5.3《六壬粹言》论三传空亡

> "三传逢空，事多虚诈。初传空，谋事不成；中传空，中间有阻；末传空，终无结果。"

**解释：**
- 初传空：开始就不实
- 中传空：过程有阻碍
- 末传空：最终无结果

### 5.4《六壬类聚》论火局水干

> "三传火局，壬癸水干。名曰'焦渴'，主事虚花。"

**解释：**
- 火局中，壬癸水被蒸干
- 形成"焦渴"格局
- 主事情虚而不实

## 六、实际应用意义

### 6.1 占断原则

#### 1. 事业财运
```
初传壬辰空：开始投资虚诈
中传癸巳空：中间经营受阻
末传甲午实：最终略有收获

断：先败后成，财来财去
```

#### 2. 婚姻感情
```
壬癸水主智，也主情
壬癸空：感情虚无

断：先热后冷，终不成
```

#### 3. 疾病健康
```
壬癸水主肾、膀胱
壬癸空：肾虚、泌尿系统问题

断：肾虚火旺之症
```

#### 4. 谋事求官
```
初传空：开始不被重视
中传空：中间有人作梗
末传实：最终能成

断：先难后易，终有成就
```

### 6.2 应期判断

#### 填实应期

**壬空填实：**
- 逢壬年、壬月、壬日、壬时
- 逢辰年、辰月（壬库）
- 逢申年、申月（壬长生）

**癸空填实：**
- 逢癸年、月、癸日、时
- 逢巳年、巳月（癸绝处逢生）
- 逢子年、子月（癸禄）

#### 出空应期

```
壬辰空：出空在 戌（冲辰）
癸巳空：出空在 亥（冲巳）
```

### 6.3 格局高低

#### 上格：填实有用
```
条件：岁运逢壬癸、辰巳
应验：空亡填实，反为大用
```

#### 中格：空而有救
```
条件：三传有金（生水）
应验：虽有阻碍，终有救助
```

#### 下格：空而无救
```
条件：三传纯火，无金水
应验：一事无成，虚花一场
```

## 七、影响空亡判定的因素

### 7.1 月将影响

**本课例：酉将**

```
酉为西方金，能生水
金为壬癸水的源头

影响：
- 酉将减轻壬癸空亡之力
- 有"绝处逢生"之意
- 空而不空，凶中有吉
```

### 7.2 占时影响

**本课例：申时**

```
申为甲申旬的旬首
申为壬水的长生之地

影响：
- 旬首发用，空亡减轻
- 长生救应，水有源头
- 先空后实
```

### 7.3 天将影响

**本课例天将：**
```
初传：六合（木将）
中传：勾陈（土将）
末传：青龙（木将）
```

**分析：**
- 六合木：泄壬水之气（凶）
- 勾陈土：克壬癸水（凶）
- 青龙木：生午火，火更旺（凶）

**结论：** 天将不利，加重空亡

### 7.4 年命影响

**占断时需考虑：**

```
年命天干：
- 逢壬、癸：填实，空亡减轻
- 逢丙、丁：火更旺，空亡加重

年命地支：
- 逢申、子、辰：水局，救应壬癸
- 逢巳、午、未：火局，加重空亡
```

### 7.5 季节影响

**四季五行旺衰：**

```
春（寅卯月）：木旺，生火，空亡加重
夏（巳午月）：火旺，水干，空亡最重
秋（申酉月）：金旺，生水，空亡减轻
冬（亥子月）：水旺，填实，空亡全解
```

## 八、综合判定与结论

### 8.1 壬癸空亡的判定依据总结

**1. 旬遁规则：**
- 甲申旬中，辰遁壬、巳遁癸
- 壬辰、癸巳位于旬尾
- 气数已尽，有空亡之意

**2. 五行生克：**
- 三传辰巳午为火局
- 壬癸水被火蒸干
- 五行失衡，水被耗尽

**3. 十二长生：**
- 壬入墓于辰
- 癸绝于巳
- 水气全无

**4. 纳音五行：**
- 壬辰、癸巳纳音长流水
- 在火局中被蒸发
- 有名无实

### 8.2 实际应用要点

**占断口诀：**
```
甲申壬癸水空亡，
三传火局水被伤。
初传谋事多虚诈，
中传阻隔事难成。
末传虽实难救应，
填实之年方见功。
```

**关键要点：**
1. 区分地支空亡（午未）和天干空亡（壬癸）
2. 理解"空而不空"的辩证关系
3. 综合考虑月将、占时、年命等因素
4. 应期判断以填实、出空为准

## 九、延伸思考

### 9.1 空亡的辩证观

**空亡不是绝对的凶：**

1. **空而有救**：有五行生助，空而不空
2. **空而待用**：等待填实，反为大用
3. **空而避凶**：凶事逢空，反不为凶

### 9.2 现代应用

在现代占断中，空亡理论可应用于：

1. **投资决策**：初传空，不宜早期投资
2. **项目评估**：中传空，注意中期风险
3. **人生规划**：末传空，调整最终目标

## 十、总结

**甲申旬壬癸空亡的核心理论：**

1. **旬尾气尽**：壬癸位于旬尾，气数已尽
2. **火局水干**：三传火局，壬癸水被蒸干
3. **墓绝无力**：壬入墓、癸绝，水气全无
4. **辩证应用**：空而不空，待时而用

**学习要点：**
- 掌握旬遁排布规则
- 理解空亡的多层含义
- 灵活运用填实、出空理论
- 综合考虑各种影响因素
