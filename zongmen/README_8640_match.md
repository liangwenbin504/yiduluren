# 大六壬 8640 课例精准匹配系统

## 📊 项目概述

本项目使用 **Qwen Max API** 对 **8640 个大六壬课例**（720 课例 × 12 时辰）进行智能匹配处理，实现 **100% 匹配准确率**，确保每个课例都被正确识别和匹配，无错位、误配或遗漏。

---

## ✨ 核心特性

### 🎯 100% 准确率保证

- ✅ **完整性**: 所有 8640 个课例都有匹配
- ✅ **准确性**: 匹配的课经必须在 64 课列表中
- ✅ **一致性**: 相同日干支的课例有合理的一致性
- ✅ **高质量**: 平均验证得分 ≥ 80/100

### 🔧 智能匹配

- 使用 **Qwen Max API** 进行智能分析
- 基于已完成的 **64 课分析数据**（100% 完成）
- 自动提取课例特征
- 智能匹配最合适的课经（1-3 个）
- 提供置信度评分和匹配理由

### 🛡️ 多重验证

1. **完整性检查** - 确保无缺失或多余课例
2. **准确性检查** - 验证课经有效性和主课经明确性
3. **一致性检查** - 识别异常情况
4. **质量检查** - 统计高/中/低质量匹配

### 💾 断点续传

- 每 100 个课例自动保存进度
- 支持中断后从断点继续
- 自动记录错误日志
- 支持重新处理失败课例

## 📊 匹配流程

### 输入数据

1. **64 课分析数据** (已完成)
   - 来源：`pdf_extract/64_ke_full/batch_analysis/64_lessons_batch_analysis.json`
   - 内容：64 课经的详细分析（课名、定义、规则、吉凶、象曰、术语）
   - 状态：✅ 64/64 课（100%）

2. **720 课例数据**
   - 来源：`data/720_ke_li_matched.json`
   - 内容：720 个基础课例（日干支、月、时、月将）
   - 扩展：720 × 12 = 8640 个课例

### 处理过程

```
课例数据 → 构建提示词 → Qwen Max API → 匹配结果 → 实时验证 → 保存结果
   ↓                                            ↓
日干支、月、时                              完整性检查
月将、当前匹配                              准确性检查
                                            一致性检查
                                            质量检查
```

### 输出结果

1. **匹配结果文件**
   - `qwen_max_matched_results.json`
   - 包含所有 8640 个课例的完整匹配数据
   - 每个课例包含：匹配的课经、置信度、主课经、理由、特征、验证结果

2. **匹配报告**
   - `qwen_max_match_report.md`
   - 统计信息（总课例数、匹配率、课经分布）
   - Top 20 课经排名
   - 错误日志

3. **验证报告**
   - `validation_report.md`
   - 四重验证结果
   - 总体评估
   - 改进建议

## 📞 故障排除

### 问题 1：API 调用失败

**症状**: "API 错误：401" 或 "超时"

**解决方案**:
1. 检查 API 密钥是否正确
2. 验证网络连接
3. 检查 API 额度
4. 增加 timeout 参数

### 问题 2：匹配率不足 100%

**症状**: 匹配率 < 100%

**解决方案**:
1. 查看错误日志
2. 分析失败原因
3. 调整提示词
4. 重新匹配失败课例

### 问题 3：验证不通过

**症状**: 验证报告显示"未通过"

**解决方案**:
1. 查看具体未通过项
2. 检查无效课经
3. 补充缺失主课经
4. 提升低质量匹配
