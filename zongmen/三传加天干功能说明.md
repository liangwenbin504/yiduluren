# 天将功能完善 - 三传加天干

## ✅ 开发完成

已为三传显示添加天干信息，使显示更完美！

### 实现方式

使用**五鼠遁元法**（日上起时法）计算三传天干。

### 修改文件

1. **`http_api_server.py`**
   - 添加 `get_stem_for_branch()` 函数 - 五鼠遁元计算
   - 为三传添加 `三传天干` 和 `三传干支` 字段

2. **`demo.html`**
   - 显示带天干的三传干支
   - 格式：`初传：丙寅 (青龙)`

### 五鼠遁元口诀

```
甲己还加甲（甲己日起甲子时）
乙庚丙作初（乙庚日起丙子时）
丙辛从戊起（丙辛日起戊子时）
丁壬庚子居（丁壬日起庚子时）
戊癸何方发（戊癸日起壬子时）
壬子是真途
```

### 返回数据示例

```json
{
  "sanchuan": {
    "三传": ["寅", "巳", "申"],
    "三传天干": ["丙", "己", "壬"],
    "三传干支": ["丙寅", "己巳", "壬申"],
    "三传天将": ["青龙", "朱雀", "天后"]
  }
}
```

### HTML 显示效果

**甲子日 子将子时（伏吟课）：**

三传：
- 初传：丙寅 (青龙)
- 中传：己巳 (朱雀)
- 末传：壬申 (天后)

**甲子日 戌将子时（涉害课）：**

三传：
- 初传：甲戌 (玄武)
- 中传：壬申 (天后)
- 末传：庚午 (螣蛇)
