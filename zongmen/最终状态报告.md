## 💡 解决方案

### 方案 1：简化提示词（推荐）

使用更短的提示词，减少 API 处理时间：

```python
prompt = f"""{ke_li['ri_gan_zhi']} {ke_li['yue']} {ke_li['shi']} {ke_li['yue_jiang']}
匹配课经，返回：{{"matched_ke_jing":["课经"],"primary_ke_jing":"课经"}}
"""
```

**优点**：
- 减少 token 消耗
- 加快响应速度
- 降低超时风险

### 方案 2：分批次处理

先处理少量课例（如 100 个），验证成功后再处理全部：

```python

        break
    # ... 处理逻辑
```

**优点**：
- 快速验证可行性
- 易于调试
- 降低风险
