## 技术实现

### 使用工具

1. **PyMuPDF (fitz)** - PDF 页面渲染
   - 版本：1.27.2.2
   - 功能：将 PDF 页面转换为高分辨率图片
   - 优势：不需要 Poppler 库

2. **Tesseract-OCR** - 光学字符识别
   - 功能：从图片中识别中文文字
   - 语言：简体中文 + 英文
   - 输出：纯文本格式

3. **Pillow** - 图像处理
   - 功能：支持图片保存和处理

### 提取流程

```
PDF 文件 → PyMuPDF 渲染 → PNG 图片 → Tesseract OCR → 文本文件
```

### 分辨率设置

- 缩放比例：2.0 倍
- 输出格式：PNG
- 确保文字清晰可辨

## 技术挑战与解决方案

### 挑战 1: Poppler 依赖问题

**问题**: pdf2image 需要 Poppler 库，但 Windows 安装复杂

**解决**: 改用 PyMuPDF (fitz)，不需要额外依赖

### 挑战 2: OCR 识别准确率

**问题**: 扫描版古籍存在字体模糊、排版复杂等问题

**解决**: 
- 提高渲染分辨率（2 倍缩放）
- 使用 Tesseract-OCR 中文识别
- 提供人工校对版本

### 挑战 3: 文件路径编码

**问题**: 中文文件名导致路径识别失败

**解决**: 
- 使用动态查找文件名
- 使用原始字符串（r-string）避免转义
