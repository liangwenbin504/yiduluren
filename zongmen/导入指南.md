# 宗门九课模块导入指南

本指南帮助您将宗门九课起课法模块集成到另一个 HTML 版本的仪度六壬择日系统中。

## 📦 模块位置

```
zongmen/  ← 整个文件夹就是模块包
```

## 🔧 集成方式

### 方式一：使用 HTTP API（推荐）

这是最简单的方式，适合任何 HTML/JavaScript 项目。

#### 1. 启动 API 服务器

```bash
cd zongmen
python http_api_server.py
```

或者双击：
```
zongmen/快速启动.bat
选择选项 1
```

#### 2. 在 HTML 中调用 API

```html
<script>
async function qike() {
    // 调用起课 API
    const response = await fetch('http://localhost:5000/api/qike', {
        method: 'POST',
        headers: {
            'Content-Type': 'application/json'
        },
        body: JSON.stringify({
            ri_gan: '甲',
            ri_zhi: '子',
            yue_jiang: '丑',
            shi_chen: '子'
        })
    });
    
    const result = await response.json();
    
    if (result.success) {
        // 获取四课
        const sike = result.data.sike;
        // 获取三传
        const sanchuan = result.data.sanchuan.三传;
        // 获取起法
        const qifa = result.data.sanchuan.起法;
        
        console.log('四课:', sike);
        console.log('三传:', sanchuan);
        console.log('起法:', qifa);
    }
}

qike();
</script>
```

#### 3. API 端点

| 端点 | 方法 | 说明 |
|------|------|------|
| `/api/qike` | GET/POST | 起课 |
| `/api/ke_li` | GET | 查询课例 |
| `/api/stats` | GET | 统计信息 |

详细 API 文档请访问：`http://localhost:5000/`

### 方式三：使用 Flask/Django 集成

如果您使用 Web 框架，可以将 API 集成到您的后端：

#### Flask 示例

```python
from flask import Flask, jsonify, request
from flask_cors import CORS
from sike_sanchuan_engine import SiKeSanChuanCalculator

app = Flask(__name__)
CORS(app)

calculator = SiKeSanChuanCalculator()

@app.route('/api/qike', methods=['GET', 'POST'])
def qike():
    if request.method == 'POST':
        data = request.json
    else:
        data = request.args
    
    ri_gan = data.get('ri_gan')
    ri_zhi = data.get('ri_zhi')
    yue_jiang = data.get('yue_jiang')
    shi_chen = data.get('shi_chen')
    
    # 计算
    tiandi_pan = calculator.get_tiandi_pan(yue_jiang, shi_chen)
    sike = calculator.qi_sike(ri_gan, ri_zhi, tiandi_pan)
    sanchuan = calculator.fa_sanchuan(sike, ri_gan, ri_zhi, tiandi_pan)
    
    return jsonify({
        'success': True,
        'data': {
            'ri_gan': ri_gan,
            'ri_zhi': ri_zhi,
            'yue_jiang': yue_jiang,
            'shi_chen': shi_chen,
            'sike': sike,
            'sanchuan': sanchuan
        }
    })

if __name__ == '__main__':
    app.run(port=5000)
```

async function searchKeLi(riGanZhi, yue, shi) {
    const url = `http://localhost:5000/api/ke_li?ri_gan_zhi=${riGanZhi}&yue=${yue}&shi=${shi}`;
    const response = await fetch(url);
    const data = await response.json();
    
    if (data.success) {
        console.log(`找到 ${data.count} 个课例`);
        data.results.forEach(item => {
            console.log(`课例：${item.key}`);
            console.log(`四课：`, item.data.sike);
            console.log(`三传：`, item.data.sanchuan.三传);
            console.log(`起法：`, item.data.jiu_zong_men_method);
        });
    }
}

// 示例：查询甲子日子月子时的课例
searchKeLi('甲子', '子', '子');

## 🔍 故障排除

### 问题 1：无法连接到 API

**解决方案：**
1. 确保 `http_api_server.py` 已启动
2. 检查端口 5000 是否被占用
3. 防火墙是否阻止连接

### 问题 2：跨域错误（CORS）

**解决方案：**
API 已启用 CORS，如果仍有问题，检查：
- 浏览器控制台的具体错误信息
- 确保使用 `http://` 而不是 `file://` 协议

### 问题 3：数据文件不存在

**解决方案：**
确保 `data/720_ke_li_jiu_zong_men.json` 文件存在，如不存在可重新生成：
```bash
python src/engine/jiu_zong_men_720_matcher.py
```
