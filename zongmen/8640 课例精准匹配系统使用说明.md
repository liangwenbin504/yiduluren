# 8640 课例精准匹配系统使用说明

## 📋 系统概述

本系统使用 Qwen Max API 对 8640 个大六壬课例（720 课例 × 12 时辰）进行精准匹配处理，确保 100% 匹配准确率。

### 核心功能

1. **智能匹配** - 使用 Qwen Max API 分析每个课例特征并匹配最合适的课经
2. **多重验证** - 实现完整性、准确性、一致性、质量四重验证
3. **断点续传** - 支持中断后从断点继续执行
4. **错误恢复** - 自动记录错误日志，支持重新处理失败课例
5. **详细报告** - 生成匹配报告和验证报告

## 📊 匹配流程

### 步骤 1：加载数据

系统会自动加载：
- 64 课分析数据（64 课经的详细特征）
- 720 课例数据（基础课例框架）
- 进度文件（如果存在，用于断点续传）

### 步骤 2：构建提示词

对每个课例，系统会构建包含以下信息的提示词：
- 日干支
- 月份
- 时辰
- 月将
- 当前匹配课经
- 主课经

### 步骤 3：调用 Qwen Max API

发送提示词到 Qwen Max API，要求：
1. 分析课例特征
2. 从 64 课经中选择 1-3 个最匹配的课经
3. 给出置信度评分（0-100）
4. 说明匹配理由

### 步骤 4：验证匹配结果

对每个匹配结果进行四重验证：

#### 4.1 完整性检查
- ✓ 检查所有 8640 个课例是否都有匹配
- ✓ 检查是否有缺失或多余的课例

#### 4.2 准确性检查
- ✓ 检查匹配的课经是否在 64 课列表中
- ✓ 检查是否有主课经
- ✓ 检查置信度是否合理

#### 4.3 一致性检查
- ✓ 检查相同日干支的课例是否有合理的一致性
- ✓ 识别异常情况

#### 4.4 质量检查
- ✓ 计算平均验证得分
- ✓ 统计高/中/低质量匹配数量

### 步骤 5：保存结果

系统会保存：
- 完整匹配结果（JSON 格式）
- 匹配统计报告（Markdown 格式）
- 验证报告（Markdown 格式）
- 进度文件（用于断点续传）

## 🔧 故障排除

### 问题 1：API 调用失败

**症状**: 出现 "API 错误" 或 "超时" 错误

**解决方案**:
1. 检查网络连接
2. 验证 API 密钥是否正确
3. 增加 timeout 参数值
4. 检查 API 额度是否充足

### 问题 2：匹配率低

**症状**: 匹配率 < 100%

**解决方案**:
1. 检查错误日志 `match_progress.json`
2. 查看失败课例的原因
3. 调整提示词或匹配策略
4. 重新运行脚本处理失败课例

### 问题 3：验证不通过

**症状**: 验证报告显示 "未通过"

**解决方案**:
1. 查看验证报告中的具体问题
2. 检查无效课经、缺失主课经等问题
3. 手动修正或重新匹配问题课例
4. 再次运行验证程序

### 问题 4：进度丢失

**症状**: 程序中断后从头开始

**解决方案**:
1. 确保 `match_progress.json` 文件存在
2. 程序会自动从断点继续
3. 不要手动删除进度文件
