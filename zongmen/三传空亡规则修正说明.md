# 三传空亡排盘规则修正

## ✅ 修正完成

已根据新需求修正三传排盘规则，实现以下功能：

## 📋 新规则

### 规则 1：空亡时天干位置保留空字符占位
- **旧规则**：遇到空亡的地支，不显示天干（遁干）
- **新规则**：即使地支空亡，也要计算遁干，天干位置保留实际遁干值

### 规则 2：不显示【空亡】提示信息
- **旧规则**：在三传显示中添加 `[空亡]` 标记
- **新规则**：完全移除空亡提示信息的显示

## 🎯 关键变化

1. **遁干计算**：空亡的地支也计算遁干（使用旬遁法）
2. **干支显示**：所有三传都显示完整的天干 + 地支
3. **空亡标记**：完全移除空亡提示信息的显示
4. **数据结构**：`三传空亡` 数组全部为空字符串

## 📝 技术说明

### 旬遁法规则
即使地支空亡，也要按照旬遁法计算遁干：
- 甲子旬：戌亥空，但戌位遁甲，亥位遁乙
- 空亡不影响遁干的计算

### 空亡数据处理
- 后端仍然计算空亡信息（用于内部逻辑）
- `三传空亡` 数组保留但全部填充空字符串
- 前端不再读取和显示空亡标记
