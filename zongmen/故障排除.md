# PDF 提取故障排除

## 问题 1: Poppler 未安装

### 错误信息
```
✗ 提取失败：Unable to get page count. Is poppler installed and in PATH?
```

### 解决方案

Poppler 是一个 PDF 渲染库，pdf2image 需要它来将 PDF 转换为图片。

#### Windows 安装步骤：

1. **下载 Poppler for Windows**
   - 访问：https://github.com/oschwartz10612/poppler-windows/releases/
   - 下载最新版本（如：Release-24.08.0-0.zip）

2. **解压到合适的位置**
   - 建议解压到：`C:\Program Files\poppler`
   - 或者直接解压到项目目录：`d:\新建文件夹\仪度六壬择日\yiduluren\zongmen\poppler`

3. **添加到 PATH 环境变量**
   
   **方法 1：临时添加（当前会话有效）**
   ```python
   import os
   os.environ['PATH'] = r'C:\Program Files\poppler\Library\bin;' + os.environ['PATH']
   ```

   **方法 2：永久添加**
   - 右键"此电脑" → "属性" → "高级系统设置"
   - 点击"环境变量"
   - 在"系统变量"中找到"Path"
   - 点击"编辑" → "新建"
   - 添加：`C:\Program Files\poppler\Library\bin`
   - 点击"确定"保存
   - **重启终端或 IDE**

4. **验证安装**
   
   打开新的终端窗口，运行：
   ```bash
   pdftoppm -h
   ```
   
   如果显示帮助信息，说明安装成功。

## 问题 2: Tesseract-OCR 未安装

### 错误信息
```
✗ OCR 失败：Tesseract is not installed
```

### 解决方案

#### Windows 安装步骤：

1. **下载 Tesseract-OCR**
   - 访问：https://github.com/UB-Mannheim/tesseract/wiki
   - 下载 Windows 安装程序（如：tesseract-ocr-w64-setup-5.x.x.exe）

2. **安装时选择中文语言包**
   - 运行安装程序
   - 在选择语言包时，勾选"Chinese (Simplified)"（简体中文）
   - 完成安装

3. **添加到 PATH（如果安装时未自动添加）**
   - 默认安装路径：`C:\Program Files\Tesseract-OCR`
   - 按照上述相同步骤添加到 PATH 环境变量

4. **验证安装**
   ```bash
   tesseract --version
   ```

## 快速解决方案（推荐）

如果以上步骤太复杂，可以使用以下简化方案：

2. 右键第 290 页 → "复制文件"

```bash

```

然后使用 fitz 库直接提取页面为图片。
