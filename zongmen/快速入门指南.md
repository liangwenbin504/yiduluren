## 🛠️ 实用技巧

### 原文阅读技巧

**1. 断句技巧**
```
原文：「三光课者谓干支上神得旺相又三传皆阳」

正确断句：「三光课者，谓干支上神得旺相，又三传皆阳」

技巧：
- 找虚词（者、也、谓、曰）
- 找并列结构（或...或...）
- 找因果关系（故、是以）
```

**2. 关键词识别**
```
定义词：谓、曰、名曰、名为
条件词：若、苟、如、使
结果词：故、是以、遂、乃
转折词：然、而、但、顾
```

**3. 异文处理**
```
版本 A：「三光课者，谓干支上神得旺相」
版本 B：「三光课者，谓干支上神旺相」

处理：
1. 记录差异
2. 分析原因（衍文/脱文）
3. 判断正误
4. 说明理由
```

### Qwen Max API 使用技巧

**1. Prompt 设计**

❌ 错误示例：
```
分析三光课
```

✅ 正确示例：
```
请分析《六壬大全》中"三光课"的构成条件：

原文：「三光课者，谓干支上神得旺相，又三传皆阳，或三传皆阴...」

请按以下结构分析：
1. 必要条件（必须同时满足）
2. 充分条件（满足任一即可）
3. 条件之间的逻辑关系
4. 边界情况

请提供原文依据。
```

**2. 结果验证**
```
API 输出后，必须：
1. 对照原文验证
2. 检查逻辑是否自洽
3. 与相邻课目对比
4. 请教专家确认
```

**3. 迭代优化**
```
第一次输出 → 发现不足 → 优化 Prompt → 第二次输出 → 对比选择最佳
```

## ⚠️ 常见错误与避免

### 错误 1：原文理解偏差

**表现：**
```
原文：「三传皆阳」
误解：三传都是阳干
正解：三传都是阳支（子寅辰午申戌）
```

**避免方法：**
- 仔细研读上下文
- 参考多家注释
- 请教专家
- 查证其他文献

### 错误 2：条件混淆

**表现：**
```
把充分条件当必要条件
把必要条件当充分条件
```

**避免方法：**
- 明确标注"必须"vs"或"
- 使用逻辑符号（∧ ∨）
- 画逻辑关系图
- 举反例验证

### 错误 3：从格遗漏

**表现：**
```
只识别明显从格
忽略隐性从格
```

**避免方法：**
- 逐句分析原文
- 注意"若...则..."结构
- 关注变体情况
- 对比他课从格

### 错误 4：课例匹配错误

**表现：**
```
边界案例处理不当
忽略特殊条件
```

**避免方法：**
- 严格执行匹配规则
- 边界案例集体讨论
- 多级校验
- 原文回溯验证
