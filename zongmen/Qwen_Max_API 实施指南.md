# 利用 Qwen Max API 执行《六壬大全》64 课核对实施指南

## 📋 概述

本指南说明如何利用 Qwen Max API 对《六壬大全》64 课进行系统性核对与整理。

## 🎯 工作流程总览

```
文献数字化 → API 分析 → 人工审核 → 数据库构建 → 课例匹配 → 质量验证
```

## 最佳实践

### Prompt 设计原则

1. **明确具体**
   - 清楚说明任务目标
   - 指定输出格式
   - 提供必要背景

2. **分步进行**
   - 复杂任务分解为多个简单任务
   - 逐步深入，层层递进
   - 每步验证后再继续

3. **提供上下文**
   - 引用原文
   - 说明用途
   - 标注重要性

4. **设定约束**
   - 字数限制
   - 格式要求
   - 质量标准

### 质量控制

1. **双重验证**
   - API 分析 + 人工审核
   - 程序匹配 + 原文回溯

2. **抽样检查**
   - 随机抽取 10% 详细检查
   - 重点课目 100% 检查

3. **版本管理**
   - 每次修改记录版本
   - 重要变更标注日期
   - 定期备份数据

### 效率提升

1. **批量处理**
   - 相似任务合并
   - 模板化 Prompt
   - 自动化流程

2. **知识积累**
   - 建立 Prompt 库
   - 整理常见问题
   - 形成标准答案

3. **工具辅助**
   - JSON 验证工具

## 常见问题解答

### Q1: 如何处理原文异文？
**A:** 使用 Qwen Max API 进行校勘，原则如下：
1. 以最早版本为准
2. 标注各版本差异
3. 说明取舍理由
4. 存疑处标注"待考"

### Q2: 从格识别的标准是什么？
**A:** 从格识别标准：
1. 原文明确提及"从 XX 论"
2. 课名带"从"、"化"、"变"等字
3. 构成条件与主课有差异
4. 吉凶判断有特殊规则

### Q3: 课例匹配出现争议如何处理？
**A:** 争议处理流程：
1. Qwen API 分析争议点
2. 对照原文详细比对
3. 专家会诊（如有必要）
4. 标注"争议案例"并说明
5. 提供多种观点

### Q4: 如何保证学术规范性？
**A:** 学术规范保障措施：
1. 所有结论有原文依据
2. 原文引用注明出处
3. 异文处理有说明
4. 存疑问题标注"待考"
5. 建立完整的审核轨迹
