### 遁干规律

1. **确定旬首**：根据日干支确定所属的旬
2. **从旬首开始**：旬首地支遁甲（甲 X）
3. **顺排天干**：按天干顺序（甲乙丙丁戊己庚辛壬癸）顺排到各地支
4. **空亡判断**：一旬 10 个干支，12 个地支，最后 2 个地支为空亡

## 🔧 修正内容

### 问题

之前的旬首计算逻辑有误，导致同一旬内的不同日干支被计算出不同的旬首。

**错误示例：**
- 甲子日 → 旬首甲子 ✓
- 乙丑日 → 旬首甲丑 ✗（应该是甲子，因为乙丑也在甲子旬）

### 修正方法

使用正确的 60 甲子序号计算公式：

```python
# 60 甲子序号计算
ganzhi_index = (gan_index * 6 - zhi_index * 5) % 60

# 旬首序号 = 60 甲子序号 // 10 × 10
xun_shou_index = (ganzhi_index // 10) * 10

# 旬首地支 = 旬首序号 % 12
xun_shou_zhi = branches[xun_shou_index % 12]
```

## 🔧 修改文件

### 1. `http_api_server.py`

修正 `get_xun_shou()` 函数：

```python
def get_xun_shou(ri_gan: str, ri_zhi: str) -> tuple:
    """计算日干支的旬首和空亡（旬遁法）"""
    stems = ['甲', '乙', '丙', '丁', '戊', '己', '庚', '辛', '壬', '癸']
    branches = ['子', '丑', '寅', '卯', '辰', '巳', '午', '未', '申', '酉', '戌', '亥']
    
    gan_index = stems.index(ri_gan)
    zhi_index = branches.index(ri_zhi)
    
    # 60 甲子序号计算
    ganzhi_index = (gan_index * 6 - zhi_index * 5) % 60
    if ganzhi_index < 0:
        ganzhi_index += 60
    
    # 旬首序号 = 60 甲子序号 // 10 × 10
    xun_shou_index = (ganzhi_index // 10) * 10
    
    # 旬首地支 = 旬首序号 % 12
    xun_shou_zhi = branches[xun_shou_index % 12]
    
    # 计算空亡
    kong_wang_index1 = (xun_shou_index % 12 + 10) % 12
    kong_wang_index2 = (xun_shou_index % 12 + 11) % 12
    kong_wang = [branches[kong_wang_index1], branches[kong_wang_index2]]
    
    return '甲', xun_shou_zhi, kong_wang
```

## 📝 技术说明

### 60 甲子序号公式

60 甲子的序号计算使用以下公式：
```
序号 = (天干索引 × 6 - 地支索引 × 5) % 60
```

这个公式的原理：
- 天干有 10 个，地支有 12 个
- 最小公倍数是 60，形成 60 甲子循环
- 天干索引 × 6 和地支索引 × 5 的组合可以唯一确定 60 甲子中的位置

### 旬遁 vs 五子遁

- **旬遁法**：根据日干支所属的旬，从旬首开始排天干
  - 优点：符合传统六壬规则
  - 应用：三传遁干、六壬排盘

- **五子遁元法**（日上起时法）：根据日干起时干
  - 口诀：甲己还加甲，乙庚丙作初...
  - 应用：时辰天干计算

**本系统使用旬遁法计算三传天干，符合传统六壬规则。**
