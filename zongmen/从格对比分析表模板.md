#### 三、特殊从格专项分析：三光失明

##### 3.1 特殊性说明

**为何称为"特殊从格"？**

1. **表面与实质相反**
   - 表面：具备三传纯一的三光特征
   - 实质：干支上神失陷，吉中藏凶
   - 特点：具有欺骗性，容易误判

2. **构成条件的特殊性**
   ```
   必要条件：
   - 三传必须纯一（满足三光的基本条件）
   
   否定条件（满足任一即为三光失明）：
   - 干上神失陷
   - 支上神失陷
   - 三传逢空亡
   - 干支上神处死绝之地
   ```

3. **判断规则的独立性**
   - 不能按三光课的"凡占皆遂"判断
   - 必须详察干支上神及空亡情况
   - 作"先吉后凶"断

##### 3.2 与主课的全面对比

| 对比项 | 三光课（主） | 三光失明（从） | 差异分析 |
|--------|------------|--------------|---------|
| **课名含义** | 三光并照 | 三光失辉 | 光明 vs 黑暗 |
| **五行状态** | 旺相 | 死绝 | 生气 vs 死气 |
| **神将关系** | 吉神加临 | 凶神暗藏 | 显吉 vs 隐凶 |
| **时空特征** | 得时得地 | 失时失地 | 得势 vs 失势 |
| **发展趋势** | 渐入佳境 | 先成后败 | 上升 vs 下降 |
| **应验速度** | 快速应验 | 延迟应验 | 即应 vs 缓应 |
| **吉凶性质** | 纯吉 | 吉中藏凶 | 单一 vs 复杂 |

##### 3.3 判断要点口诀

```
三光失明判断歌诀：

三传虽纯上神陷，
名曰失明吉藏凶。
莫道三光皆遂意，
详察空亡与死绝。

干支上神若失陷，
纵然三传亦徒然。
初看似成终有阻，
先吉后凶仔细推。
```
